# PLUGIN — Rift of the Sky (Unity 스타터)

첨부한 대화의 최종 기획을 C#으로 다시 구성한 PC용 프로토타입입니다. 기존 Godot 원본, 타이틀 이미지, hero.glb는 제공되지 않아 원본 파일 변환이 아닌 새 구현입니다.

## 실행
1. Unity Hub에서 설치된 Unity 6000.6.6f1을 선택하세요. 이 프로젝트의 기준 버전은 6000.6.6f1입니다.
2. Hub → Add → Add project from disk에서 이 폴더(Assets, Packages, ProjectSettings가 있는 UnityProject)를 선택하세요.
3. Assets/Scenes/Main.unity를 열고 Play를 누르세요. 빈 씬에서도 런타임 부트스트랩이 동작합니다.
4. NEW GAME / SELECT SLOT → 슬롯 선택 → START NEW GAME. 저장된 슬롯은 CONTINUE로 이어합니다.
5. 입력 오류가 나면 Edit → Project Settings → Player → Other Settings → Active Input Handling을 Input Manager (Old) 또는 Both로 설정하고 에디터를 재시작하세요. 이 프로젝트는 기존 Input API를 사용합니다.
6. 배포는 File → Build Profiles에서 PC 플랫폼 모듈을 설치하고 Main 씬을 포함해 Build하세요. 메뉴 PLUGIN/Create Starter Scene으로 씬을 다시 만들 수도 있습니다(기존 씬 저장 여부 확인).

## 구현 범위
- 256×256m 노이즈 지형, 지형 충돌, 조명과 안개, 나무 160개, 바람에 흔들리는 잔디 1,000개.
- 임시 도형 캐릭터: 흰 상의, 어두운 머리/바지, 파란 망토, 오른손 푸른 건틀릿. 검 없음.
- 3인칭 이동/카메라 회전/줌/벽 충돌, 달리기, 점프, 구르기 중 무적.
- 좌클릭 짧게: 자원 소모 없는 3연타, 마지막 타격은 주변 범위 공격.
- 좌클릭 길게: 0.25초 뒤 초당 에너지 22 소비, 최대 1.6초 충전 후 범위 타격. 차지 중 구르기/피격으로 취소. 에너지는 비충전 중 초당 15 회복. 현재 충격파는 즉시 범위 판정과 푸른 구체 이펙트입니다.
- 적 12마리: 배회, 추적, 공격 전 0.65초 예고, 피격 경직, 체력 0 시 한 번만 경험치 지급 및 제거.
- 나무에 공격 판정 9회 적중 시 쓰러지고 재료 목재 3 지급.
- I 인벤토리: 장비/방어구/재료/음식 4페이지, 좌우 화살표 전환. 현재 실제 획득 아이템은 목재뿐입니다.
- 3개 세이브 슬롯: F5 수동 저장, 위치/체력/에너지/목재/레벨/경험치 유지. 저장 위치는 Application.persistentDataPath 아래 rift_slot_0~2.json입니다. 새 게임은 메모리에서 초기화하며 F5 저장 시 선택 슬롯을 덮어씁니다.
- 처치한 적/베어낸 나무 상태는 저장하지 않으며 이어하기 시 월드가 다시 생성됩니다.

## 조작
WASD 이동, Shift 달리기, Space 점프, C 구르기, 좌클릭 공격/홀드 차지, 휠 줌, I 인벤토리, F5 저장, Esc 마우스 해제, 우클릭 마우스 캡처.

## 검증 및 한계
이 제작 환경에는 Unity 에디터가 없어 컴파일/Play Mode/빌드를 실행하지 못했습니다. 실제 실행 검증이 필요한 스타터이며 완성 게임이 아닙니다. ZIP 구조, JSON, 씬 참조를 정적으로 확인했습니다.
메뉴는 영어 IMGUI 프로토타입이며 고품질 최종 UI나 원본 타이틀 이미지는 포함하지 않습니다. 그래픽은 단순 도형과 생성 텍스처로, 사실적 아트/애니메이션/사운드/청크 스트리밍/퀘스트/장비 착용/음식 사용은 구현하지 않았습니다. 무적 구르기와 전투/수확 수치는 Hero.cs, RiftEnemy.cs에서 조절합니다.
Unity에서 이동·점프·3연타·차지 소비/회복·적 처치/경험치·나무 9회/목재·4페이지·F5 저장 후 재실행/이어하기를 확인하세요.

클라우드 태스크는 이미 격리되어 있으므로 기존 체크아웃을 사용하고 별도 Git worktree를 만들 필요가 없습니다.
