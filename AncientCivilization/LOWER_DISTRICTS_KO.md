# 하층 두 구역 — v0.25.0

최하층에 해당하는 **하층 생산구**와 그 위의 **하부 생활구**를 한 흐름으로 진행한다. 시작부터 표시되는 주인공 호칭은 백 경위다. 생산구에서 코어를 회수하고 범인을 검거하지만, 그 수량으로 설명되지 않는 미수령 기록 때문에 생활부까지 수사를 이어간다. 최상층의 흑막은 아직 확정해서 말하지 않는다. 고대 문명 지역과 저격수의 친구 정체 공개는 2회차에 남긴다.

## 첫 플레이 목표와 실제 측정

**합계 150분은 콘텐츠 조정 목표다. 현재 Unity에서 측정한 완주 시간은 없다.** 맵의 좌표 길이를 플레이 시간으로 환산하거나, 검사 개수로 완성도를 계산하지 않는다. 숙련자는 와이어·스윙·선택 현장 생략으로 빠르게 진행할 수 있다. 강제 대기, 자동으로 막히는 시간 제한, 느린 이동, 보스 체력 부풀리기로 150분을 강제하지 않는다.

## 하나의 임무로 이어지는 사건

생산구는 재고 120기와 현물 117기의 차이를 보고하던 중 벽을 뚫고 도주하는 코어 운송 트럭으로 시작한다. 차량을 훔친 사건이 아니라 생산구의 코어를 실어 나르는 절도다. 오토바이는 이 추격 구간에서 자동 주행하고, Space로 잔재·폭탄을 피한 뒤 적의 공격이 멎은 승선 기회에 와이어로 트럭 위에 오른다. 체력 구간을 두 차례 넘기면 세 번째 탑승에서 짐칸을 분리하고 트럭을 파괴한다. 코어는 폭발 전에 확보되고 운송대장은 생존 검거된다.

검거 뒤 소장에게 돌아가지 않는다. 사령관이 무전으로 회수품의 운송 기록을 확인하라고 지시하면 동쪽 수사로가 바로 열린다. 교대표에 없는 출고 도장, 주민 배급과 별도로 움직이는 계량기, 같은 번호의 다른 수령처가 이어진다. 전력 차단과 구조 요청이 서로 다른 승인선을 타고, 재하는 실제로 안에 남아 있는데 문서에서는 대피 완료로 처리돼 있다. 사람을 구조하고 수정 전 기록의 사본을 남기는 것이 승진 포인트와 별개인 백 경위의 선택이 된다.

권한이 열려도 자동으로 윗층에 이동하지 않는다. 동쪽 엘리베이터에서 생활부를 선택한다. 생활부에서는 코어를 든 도둑이 지나갔다는 길을 따라간다. 새 차량 추격은 없다. 배급 줄·진료소·폐차장·감시 구역·창고로 이어지는 같은 맵에서 흔적과 증언을 모은다. 코어 포장을 바꾼 흔적은 조직의 범죄를 가리키지만, 진료소에 코어가 오지 않은 날짜는 오늘의 절도보다 앞선다.

조직 본거지에서는 부하들을 먼저 제압한 뒤 두목의 거대 로봇과 싸운다. 로봇을 무너뜨린 후 조종사는 현장에 남아 진술한다. 회수 코어와 거래 원장을 합쳐도 모든 미수령량이 설명되지 않고, 수령처 수정 기록이 행정구 승인선으로 이어진다. 회수품은 주민에게 먼저 돌리고, 백 경위는 원장을 가지고 다음 엘리베이터로 간다.

## 맵과 현장 구성

두 구역의 연속 수사로는 각각 **10,400단위**다. 각 층의 이정표 네 개는 폭 2,496단위이며, 이정표마다 세 구간과 64단위 연결 통로를 유지한다. 한 구간은 208단위 블록 네 개로 나눈다. 앞의 두 블록에는 필수 현장, 세 번째에는 선택 현장, 마지막에는 기존 주요 단서·복구·구조 목표를 둔다. 생산구 도입 362단위와 별도 추격 터널은 이 수사로 길이에 포함하지 않는다.

- 필수 48곳: 주 진행의 증언·위협·복구·접속을 담당한다. 브리핑 → 실제 행동 → 결과 확인 순서이며, 대화만으로 끝나는 증언도 있다.
- 선택 24곳: 음식·가족·의료·작업 기록 등 주민 생활을 보여 준다. 건너뛰어도 주요 목표가 열리고, 완료한 이정표에 돌아와 진행할 수 있다.
- 일반 경로는 바닥 중심이다. 생산구의 `교체 승인실`과 생활부의 `경비 로봇 구역`은 높이가 다른 발판 네 묶음과 중간 착지대, 상부 접속대, 천장 와이어를 사용한다. 생산구는 이동 크레인, 생활부는 블레이드 반동 부유체로 구분한다.
- 생활부 뒤편 배경은 주거·진료소, 폐차장·압축기, 감시 외벽, 코어 보관고의 도트 8종으로 구분한다. 배경 장식은 충돌하지 않으며, 상자·자동차·엄폐물 등 게임 장치는 별도로 둔다.
- 현장 장치는 베는 고정판의 노란 절단선, 레이저 수광부의 세로 슬롯, 상부 접속점의 기둥, 투척 고정판의 중심 과녁으로 구분한다. 모두 실제 작동 좌표를 중심으로 표시하며, 복구한 접속점과 수광부는 녹색으로 남는다. 도트 미리보기는 C# 픽셀 데이터의 검토 이미지이며 Unity 플레이 화면은 아니다.
- 경비전은 현장당 두 명이다. 도입의 근접병·사격병에서 후반의 방패병·폭탄병·드론 조합으로 바뀐다. 생활부 탐조등은 가까운 경비 수를 함께 세어 증원을 제한하고, 엄폐물은 실제 광선과 충돌한다. 넓은 맵 전체에 적을 한꺼번에 활성화하지 않는다.
- 필수 현장 완료 시 8HP, 선택 현장 완료 시 16HP와 TECH 3을 한 번만 지급한다. 최대 체력을 넘지 않는다. 입자 수광부는 예비판에서 에너지를 다시 얻을 수 있고 큰 투척 물체도 재생성되므로 실패 뒤 다시 시도할 수 있다.
- 브리핑·현장 행동 성공·결과 확인은 별도 상태로 저장한다. 베기·접속·투척·레이저·경비 제압 직후 종료해도 성공한 행동은 복원하고, 주민의 결과 대화부터 잇는다. 보상과 길 개방은 결과 확인 뒤 한 번만 적용한다. 아직 제압하지 않은 경비를 사망/이동으로 정리한 것은 성공으로 기록하지 않는다.
- 같은 이름의 새 주민은 하나의 표시 인물을 공유한다. 배달·의료·기록·생산 역할에 맞는 복장을 쓰고, 아동 외형은 아이로 작성한 아린에게만 사용한다. 대화 뒤 그 자리에 남고, 다음 장소로 재배치할 때는 이전 위치가 화면 밖인지 확인한다. 기록 메뉴는 들은 증언과 확인한 결과만 공개한다.

구버전 저장을 옮길 때는 완료한 수사와 보스 제압을 따로 판정한다. 수사는 끝났지만 보스가 남아 있으면 잠긴 출구 뒤가 아니라 전투 입구 앞에서 이어진다. 생활부 전투 입구 앞에는 실제 이동 엘리베이터를 둔다. 네 수사를 끝낸 뒤 다른 층을 다녀와도 보스를 제압하기 전에는 이 터미널로 복귀하며, 제압한 뒤에는 동쪽 출구로 복귀한다.

와이어로 던진 물체는 한 프레임의 이동 경로에서 벽·적·운송문 고정판 중 가장 먼저 닿은 곳을 맞힌다. 적이나 고정판의 판정 반경이 얇은 벽 앞으로 튀어나와도 벽 뒤로 피해가 전달되지 않는다. 충돌한 자리에서 물체가 부서지고 입자가 나온다.

## 개발용 배치 검토

실제 C# 규칙과 대사에서 JSON을 추출하고, 로컬 HTML 도면으로 확인할 수 있다. 이는 Unity 게임 변환본이 아니라 위치·발판·통제선·대사의 개발용 검토 화면이다.

```sh
dotnet run --project Tools/LowerRouteExport.csproj --configuration Release --no-launch-profile > lower-routes.json
python Tools/preview_lower_routes.py lower-routes.json --output lower-route-preview.html
```

브라우저에서 생성한 HTML을 열어 이정표·구간·현장을 선택한다. 파일 열기를 제한하는 환경에서는 로컬 개발 서버를 사용한다. 도면의 가로·세로 축척은 다르며, 실제 물리 이동·화면 효과·플레이 시간은 검증하지 않는다. 전체 자동 검사와 native 실행 여부는 [VALIDATION.txt](VALIDATION.txt)에 기록한다.
