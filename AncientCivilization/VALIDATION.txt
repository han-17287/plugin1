SUPPLEMENTAL COMPILATION
141 runtime scripts and 12 Editor scripts compile with warnings as errors using
Unity 2021.3 reference assemblies and narrow Editor stubs. Temporary copies substitute
the older Rigidbody2D.velocity name for linearVelocity. The shipping source targets
6000.6.7f1. The runtime also compiles with the official Input System 1.11.2 source
reference and ENABLE_INPUT_SYSTEM. Unity 6 native-only paths require the Unity Editor.

The generated source atlas and background were visually inspected. Inspection of the
actual atlas rectangles confirmed six non-overlapping RGBA frames, the unchanged
standing world scale, measured foot pivots, and the background floor cut and import
limits. Key shot margins were checked at 4:3, 16:9 and 21:9. The intro FX component's
service-double sample exercised 600 updates and cleanup without spawning renderers
per frame. Native Unity 6000.6.7f1 import, Play, physics, shader output, FPS and complete
cutscene playback still require the Editor. See ENFORCER_BOSS_KO.md for direct access.
