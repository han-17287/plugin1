formal-coat sprites, blade and wire interrupts, and light layers are shipping code.

SUPPLEMENTAL COMPILATION
139 runtime scripts and 12 Editor scripts compile with warnings as errors using
Unity 2021.3 reference assemblies and narrow Editor stubs. Temporary copies substitute
the older Rigidbody2D.velocity name for linearVelocity. The shipping source targets
6000.6.7f1. The runtime also compiles with the official Input System 1.11.2 source
reference and ENABLE_INPUT_SYSTEM. Unity 6 native-only paths require the Unity Editor.

The drawn enforcer poses were rasterized directly from the production sprite code and
inspected as pixel art. Native Unity 6000.6.7f1 import, Play, physics, shader output, FPS
and end-to-end play time still require Editor or build verification. The preview menu
provides direct access to those checks. See ENFORCER_BOSS_KO.md for the procedure.
