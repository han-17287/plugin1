v0.29.0 P2-A straight grapple and M3.5 traversal room prototypes

SCOPE AND LIMITS
Implemented: fixed/one-use/moving anchors, solid-wall/ceiling targets, straight dash,
collision preflight, traversal-hazard immunity, arrival momentum/jump/dash reset,
one-consumption strike readiness, two Room Prefabs and three difficulty profiles.
Main.unity retains the existing story controller/layout. The proposed five-stage
75/25 rhythm is a design, not a replaced Main map. Ten of the twelve challenge
designs require later room/mechanic services. C02 is the Hard gauntlet variation.
No new P3-P6 weapons/particles/rewards or boss systems are claimed as complete.
M1 is a provisional mathematical envelope, not a native movement measurement.
Unity 6000.6.7f1 Editor is unavailable: package import, native Play/physics/input,
rendering, FPS, real success rates and five-second retry timing were NOT measured.

New grapple controller suite executes the shipping PlayerGrapple and anchor classes
with a narrow movement-owner/engine double and one vertical wall. It tests straight
steps at 30/50/60/120/240Hz, moving-target reservation, arrival grants, one-use success
and retry, an introduced wall, Hurt/Dead priority, pause, target disable, mode/dash
cancellation policies, out-of-range/occluded input, primary routing, traversal-only
immunity timing and one-time Zip Strike consumption. The movement owner is a double;
this does NOT simulate the actual PlayerStateMachine or Unity physics.
New layout suite checks bounded no-overshoot steps, worst-case moving endpoints,
whole-capsule roof room, camera/range reserve and five proposed 75/25 stage lengths.
Asset/design contracts check all five actual prefabs, scene/data GUIDs, profiles,
hazard mask, twelve tile diagrams, two alternatives each and blueprint body bounds.
Runtime puzzle logic for P3-P6-dependent rooms remains unimplemented/unvalidated.

SUPPLEMENTAL TYPE CHECK
127 runtime scripts compile with warnings-as-errors against Unity 2021.3.33
reference assemblies, with .linearVelocity changed to .velocity only in temporary
copies. Shipping source uses Unity 6 APIs. The ENABLE_INPUT_SYSTEM branch also
compiles against an assembly built from official Input System 1.11.2 runtime sources.
All runtime + 10 Editor fixtures compile together using older Unity references
and narrow Editor API stubs. This is NOT a native Unity 6 build; the Unity 6-only
Tilemap CompositeOperation branch still needs native verification.
GrappleRoomSmokeChecks is authored to wait for actual flights in the Play scene;
it checks straight travel, fixed moving targets, arrival rewards, one-use spend and
interruption priority. It was type-checked but NOT executed in Unity.
