# 소환형 블레이드 3연격과 입자

Q로 샤프심 전구 블레이드를 소환하고 손잡이에 파란 플러그를 맞혀 장착합니다. 좌클릭을 이어 누르면 **세로 → 가로 → 사선 마무리**로 벱니다. 각 동작에 별도로 그린 16프레임을 사용해 총 48프레임을 표시합니다. 노란 칼날은 기계팔에 연결되어 있으며, 잔광은 각 자세에서 측정한 실제 칼끝을 따라갑니다. 캐릭터 전체를 회전시켜 베기를 대신하지 않습니다.

| 동작 | 전체 길이 | 베기 표시 시작 | 타격 판정 | 베기 표시 종료 |
|---|---:|---:|---:|---:|
| 세로 | 0.36초 | 0.11초 | 0.14초 | 0.21초 |
| 가로 | 0.34초 | 0.10초 | 0.135초 | 0.205초 |
| 사선 | 0.44초 | 0.14초 | 0.19초 | 0.27초 |

마지막 0.16초 안에 누른 다음 짧은 입력은 한 번만 예약합니다. 동작이 끝난 뒤 0.48초 안에 다시 누르면 다음 연격으로 이어지고, 그보다 늦으면 세로부터 시작합니다. 사선의 기존 강화 피해와 방어 붕괴는 유지합니다. 각 타격의 기본 피해는 35, 35, 55입니다.

장착한 채 F를 누르면 조준하고, 충전 신호 뒤에 놓으면 레이저를 쏩니다. E로 칼을 바닥에 설치하면 좌클릭으로 다시 플러그를 돌릴 수 있습니다. 피격·대화·탑승 중인 포탑·재시작이 진행 중인 공격을 정리합니다.

베기가 보이는 동안 들어오는 일반 투척물·저격수 수류탄/압축판·비서실장 침도 파괴합니다. 적/포탑의 피해는 접촉 시점에 한 번만 주며, 한 베기에 여러 물체를 부숴도 공중 반동은 한 번만 적용합니다. v0.20.0에서는 프레임이 접촉 시각과 회복 구간을 함께 건너뛰어도, 취소되지 않은 베기의 예약 타격을 현재 위치에서 한 번 해결합니다. 다음 베기가 시작되기 전에도 이전 예약 타격을 처리하며, 취소한 공격을 되살리거나 과거 이동 경로를 재구성하지 않습니다. 물체 파괴는 기존의 실제 베기 시간창을 유지합니다.

물체를 부수면 **노란 일반 입자**가 나오고 장착 여부에 관계없이 우클릭으로 모읍니다. 밝은 중심과 작은 픽셀 후광을 가진 48개 풀을 재사용합니다. 칼날과 베기 잔광은 노란색입니다. 저장 상한 100, 40/80의 단계 경계와 최대 3단계는 기존 규칙입니다.

## 백 경위의 베기 자세와 칼끝 궤적

본편 `Main`과 순찰 플레이어는 `FieldBladeDetail.png`의 원화 48프레임을 함께 씁니다. 세로·가로·사선 시트에서 투명 여백만 잘라 넣었고, 각 프레임의 발 피벗과 월드 크기를 보존했습니다. 재생 중인 자세의 기계 손목에 칼자루를 연결하고, 왼손이나 허리 쪽 감개에서 짧은 전선을 그립니다. 지상에서는 앞발 쪽으로 하중을 싣고, 공중에서는 허리를 중심으로 기울어집니다. 정비용 재생성 도구는 `Tools/pack_field_blade.py`입니다.

헛베기에서는 `BladeSwish` 풍절음과 짧은 노란 궤적이 보입니다. 궤적의 앞끝은 해당 프레임의 칼끝에 붙습니다. 적에게 맞으면 접촉 지점에 불티가 튀고, 칼날이 지형에 닿으면 `BladeWall` 금속음이 한 번 납니다. 일반 베기를 연계할 때는 다음 준비 자세로 바로 넘어갑니다. 저격수 조커의 6페이즈는 포탑 준비 구간부터 기존 자세·궤적·음향을 재생합니다.

직접 확인하려면 Unity에서 `Assets/Scenes/PlayerMovementPractice.unity`를 열어 ▶를 누릅니다. 평지에서 Q로 소환한 뒤 손잡이에 플러그를 꽂아 장착하고, 허공과 벽을 향해 왼쪽·오른쪽으로 좌클릭 3연격을 시도합니다. 공중에서는 점프 직후 같은 순서를 반복합니다. 본편에서는 `Assets/Scenes/Main.unity`의 새 게임 또는 이어하기에서 같은 조작을 사용합니다.

## v0.21 명중과 조준 피드백

베기를 시작할 때 몸도 실제 공격 방향으로 돌아섭니다. 거의 수직인 조준은 직전 방향을 유지해 팔 위치 차이 때문에 좌우가 뒤집히는 현상을 줄입니다. 베기 타이밍·예약 입력·피해량은 기존 규칙을 사용합니다.

적이 실제 피해를 받은 위치에 짧은 흰색 명중 표시를 더합니다. 보스의 회복 중 공격 기회를 맞히면 금색으로 표시하며, 위로 떠오르는 피해 숫자와 명중 위치를 따로 유지합니다. 허공에는 명중 표시나 임의의 접촉 폭발을 만들지 않고 노란 베기 잔광을 남깁니다. 물체 파괴의 입자와 공중 반동은 유지합니다.

입자가 없으면 유지 조준 중 「입자 없음 · 우클릭 수집」과 주황 조준선을 표시합니다. 실제 입자가 있고 충전이 끝났을 때만 준비 완료 안내와 소리를 냅니다. 커서 옆 안내는 한국어 글자 폭과 화면 크기를 반영하고, 화면 끝에서는 위치를 옮겨 조준점을 가리지 않도록 합니다. 준비 안내는 현재 조준 상태에 붙어 있어 발사·취소 후 별도 팝업으로 남지 않습니다.

대화·승강기·연출·종료·장소 이동에서는 이전 명중 숫자와 상황 안내를 정리합니다. 일반 일시정지는 진행 중이던 표시를 보존합니다. 실제 마우스 유지 중 수집·모드 전환, 수직 조준, 공중 연격 및 화면 모서리 가독성은 Unity 실기 확인 대기 항목입니다. 블레이드 검사 메뉴에 실제 명중/허공 베기와 방향·표시 정리 검사를 추가했으며, 여기서는 실행하지 않았습니다.

## 확인 범위

v0.21에서 순수 타이밍·입력 연결·긴 프레임 예약 타격·방향·충전 안내 배치 규칙 4,600개를 검사했습니다. 기존 48프레임의 영역·피벗·칼끝·색·연결된 실루엣과 보조 타입 검사도 통과했습니다. 이전 Canvas 미리보기에서 확인한 측정 좌표와 원본의 중복 팔·칼날 수정은 유지합니다. 이것은 Unity의 실제 렌더링·충돌·프레임 시간 검증을 대신하지 않습니다.

Unity에서 `PLUGIN → 검사 → 소환형 블레이드 3연격과 입자`를 실행하면 임시 저장 프로필로 구조 검사를 할 수 있습니다. 타격 시점 뒤에 실제 풀 물체를 놓아 파괴되는지, 회복 중에는 그대로 남는지, 한 베기의 반동이 중첩되지 않는지도 검사합니다. 이 환경에서는 해당 Editor 검사를 실행하지 못했습니다. 실제 마우스 누름/떼기, 움직이며 방향 전환, 공중 연격, 스윙 직후 공격, 30/60/120FPS 표시와 저격수 포탑 전환은 수동으로 확인해야 합니다.
