# 1회차 완성도 — v0.12.0 중간본의 실제 상태

요청 목표는 앞선 작업을 포함한 총 10시간 개발로 주민 대화까지 갖춘 완성도 높은 1회차를 만드는 것이다. 이전의 90% 요청도 이 목표에 포함한다. 기존에 합의한 완성판 약 9시간을 기준으로 본다. **이번 결과를 90% 완성 또는 9시간 플레이 가능으로 표시하지 않는다.** 실제 제작한 내용과 아직 남은 내용을 아래처럼 구분한다.

| 항목 | 이번에 구현한 범위 | 남은 확인·제작 |
| --- | --- | --- |
| 주인공 | 백명으로 이름/호칭/메인 대화 반영 | 최종 초상화·연출의 전 구간 실기 확인 |
| 1회차 줄거리 | 순찰·절도·검거·도시 수사·샛길·저격수·비서실장·회장실·마지막 추격·추락 연결 | 장편 장면 전환과 이야기 호흡 다듬기 |
| 주민 | 도시 주민 25명, 사건 전후 대화, 도트 인물, E 대화, 한국어 순차 표시 | 25명 고유 외형·구조 대상 4명 걷기 16프레임을 추가. 전체 대화/동작 가독성 실기 검증은 남음 |
| 주요 현장 | 5층 × 4사건 = 20개, 별도 현장 구역 20개, 각 3목표와 확보 자료 | 현재는 블록아웃. 실제 첫 플레이의 경로·전투·퍼즐 밀도와 독자적인 구역 디테일 확대 |
| 사건 방식 | 기록 조사 / 봉인 파괴 / 주민 보호 / 입자 레이저 복구 | 모든 구역의 첫 플레이 동선·난도·반복감 검증 |
| 진행 | 조사 후 보스·권한·실제 엘리베이터, 마지막 회장실 대조, 저장·중단·재개 | 구버전 세이브와 신규 세이브 전 구간 실기 회귀 |
| 저격수 | 1회차는 같은 처지만 확인. 친구 대사/기록 제거 | 2회차에서 과거 관계 공개. 고대 문명 맵은 이번 범위 밖 |
| 조커 | 5개 구역에 각 한 번의 주민 언급 | 발견률과 단서 강도가 과하거나 약하지 않은지 외부 플레이 확인 |
| 전투 | 기존 5개 보스 고유 패턴/30포즈, 비서실장 1페이즈/6포즈, 현장 위협·방패병·드론 | 시계 벡터·순간이동·낙하 침 실기 검증, 2페이즈는 추후 요청 범위 |
| 성능 | 현장별 장식/조명/기믹 생략, 기존 풀/와이어 최적화 유지 | 실제 Unity 6000.6.7f1 프레임·GC·메모리와 빌드 측정 |
| 9시간 목표 | 장별 시나리오와 콘텐츠 예산 | 현재 구현은 목표보다 짧다. 실제 9시간에 필요한 질적 콘텐츠 확장과 첫 플레이 실측이 남음 |

숫자만 채우기 위해 같은 대사를 반복하거나 대기 시간을 강제하지 않았다. 현장·인물 수는 구현 수량이지 플레이 시간 또는 품질 보증 비율이 아니다.

이 환경에는 실행 가능한 Unity Editor가 없어 Play Mode와 실행 빌드를 확인하지 못했다. 독립 규칙·에셋·구문 검사와 보조 타입 검사의 결과는 VALIDATION.txt, 실기 확인 절차는 PLAYTEST_KO.md에 있다. 실제 90% 판정에는 최소한 새 게임부터 임시 엔딩까지의 외부 완주 기록, 9시간 콘텐츠 기준 대조, 저장/입력/전투 결함 수정과 플레이어 빌드 확인이 필요하다.
