# Ancient Civilization — 스토리와 복선 설계

## 현재 플레이되는 첫 장

수직 도시에서 하층 치안경찰이 순찰·장비 훈련 후 코어 절도 사건을 추격한다. 상층 출신 용의자는 자신의 도주 트럭에 하층 생산 에너지 코어를 싣는다. 코어 회수와 화물 수호기 미니 보스전 뒤 검거에 성공한다.

검거 보상으로 시민 포인트 1,000점을 받고 바로 위 도시의 출입 권한이 열린다. 자동 이동하지 않으며, 이동 엘리베이터에서 목적 층을 골라 왕복한다. 승진과 출입 권한이 사건의 진상을 해결해 주지는 않는다.

대사는 한국어 한 글자씩 표시된다. 생활구·행정구·거주구·최상층의 이동/전투와 저격수 재회는 후속 맵에 연결했다. 회장실 조사·두 번째 트럭 추격·최종 반전은 아직 구현하지 않았다.

## 작가용 장기 방향 — 플레이어에게 직접 공개하지 않을 정보

최상층의 통제 세력이 코어 배정과 기록 접근, 층간 관제를 장악한 흑막이다. 일반 상층 주민 전체를 가해자로 취급하지 않는다. 통신관은 접근 권한이 제한된 조력자이며 초반에는 진상을 모른다. 도둑의 최종 동기와 하층 폐쇄 계획의 구체 내용은 후속 장에서 확정한다.

## 초반에 구현된 복선 / 후반 회수 계획

| 초반 단서 | 처음에는 이렇게 보임 | 후반에 드러낼 의미 |
| --- | --- | --- |
| 순찰 중 C-00 예비 코어는 점검 제외 지시 | 정기 배정 물량 예외 | 최상층 직할 배정이라 현지 경찰의 감사를 받지 않음 |
| 생산소의 ‘예비 동력 배정 / C-00’ 표지 | 공장 관리 번호 | 하층에서 빠져나가는 별도 물량의 경로 |
| 운송장 수량은 보이지만 최종 수령처는 공란 | 서류 누락 또는 열람 등급 차이 | 수령처가 의도적으로 숨겨짐. 후반에 원본과 사본을 대조 |
| 용의자가 운송장 마지막 칸을 보라고 함 | 검거를 피하려는 변명 | 용의자가 정상 유통 경로의 이상을 알고 있었음 |
| 현장 수사 도중 C-00 승인으로 용의자·회수품 별도 이송 | 중요한 사건의 인계 절차 | 증언과 증거가 같은 통제 체계로 수거됨 |
| 통신관이 사본을 남겨 둠 | 성실한 업무 처리 | 중반 기록 조작을 입증할 비교 자료. 아직 인벤토리 아이템은 아님 |
| 첫 상층 도착 시 엘리베이터에도 C-00 발견 | 공용 설비 규격 | 코어 배정과 도시 이동 통제의 주체가 같음 |

C-00의 정체를 초반 인물의 입으로 확정하지 않는다. 한 장면에서 악역·최상층·음모라는 표현으로 설명하지 않고, 반복되는 코드와 권한 제한만 보여 준다. 후속 장에서는 중층 기록실에서 코드의 오래된 사용 기록을 찾고, 최상층에서 동일한 서명으로 최종 연결한다.

## 후속 장 집필 방향 — 수사 세부 사건은 미구현

하부 생활구의 실종·불법 포인트 거래 → 중층 행정구의 기록 조작 → 상층 코어 유통과 하층 폐쇄 계획 조사 → 최상층 통제 세력과 충돌. 층간 이동은 엘리베이터로 왕복하며, 위에서 얻은 정보와 아래에서 남긴 증거를 연결한다.


## 현재 맵 버전과 2회차 범위

도시 다섯 층에 각기 다른 이동 구간과 구역 전투를 구현했다. 구역 보스 제압으로 다음 층 출입 권한이 열리지만 자동으로 이동하지 않는다. 최상층은 승진에서 제외되며 거주구의 외벽 샛길로 침입한다. 저격수는 옛 친구임을 알아본 뒤 생존 상태로 헤어진다. 고대 문명 자체의 맵과 플레이는 2회차 스토리로 유보하며 이번 버전에는 생성하지 않는다. 전체 현재 범위는 FLOOR_DESIGN_KO.md를 기준으로 한다.
