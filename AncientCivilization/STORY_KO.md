# 도시 1회차 이야기 — 백명 / v0.13.0 설정 기준

## 확정 설정

주인공은 한국인 하층 치안경찰 **백명**이다. 주민과 통신에서는 백 경위로 부른다. 얼굴을 가린 흰색/검은색 도트 복장과 고대 기계팔, 노란 필라멘트 블레이드·입자 수집기·와이어 발사기를 사용한다.

위로 갈수록 상류층의 도시이며 포인트와 승진으로 더 높은 층의 통행·거주 자격을 얻는다. 자격은 자동 이동이 아니다. 실제 엘리베이터를 이용해 해금된 층을 왕복한다. 최상층은 포인트로 진입할 수 없고 외벽 정비 샛길로 침입한다.

1회차 최상층의 저격수는 **포인트가 동결되고 정식 출입을 거부당한 또 다른 침입자**다. 백명은 자기와 비슷한 처지임을 확인하고 싸움을 멈춘다. 상대의 실명, 과거 관계, 사격 습관에 대한 회상은 보여 주지 않는다. 마지막 추격의 지원 사격도 관계를 설명하지 않는다.

**두 사람이 옛 친구라는 사실은 2회차에서만 공개한다.** 얼굴을 가린 장비와 변조된 통신, 오랜 단절 때문에 1회차에서 알아보지 못한다. 2회차에서 과거를 입증하는 기록과 개인적인 기억을 함께 확인하는 장면을 만들 예정이다. 해당 재회 장면과 고대 문명 플레이 맵은 이번 버전에 만들지 않는다.

## 1회차 인과관계

| 장 | 백명이 처음 믿는 것 | 현장에서 확인하는 것 | 다음 행동 |
| --- | --- | --- | --- |
| 하층 생산구 | 코어를 회수하고 절도범을 잡으면 안전이 돌아온다 | 야간 출고와 이송 승인은 검거 이전에 이미 진행됐다. 피난 확인서도 실제 대피보다 먼저 작성됐다 | 인계를 마치되 사본을 보관하고 윗층 수령 기록을 조사 |
| 하부 생활구 | 도난 때문에 진료소의 전력이 부족하다 | 미수령은 도난 전부터 시작됐다. 용의자는 반환 신청을 거절당한 운송 기술자였고, 지역 밀매 조직도 일부 물량만 다뤘다 | 지역 경비장의 원장으로 행정구 수정 이력 추적 |
| 중층 행정구 | 정식으로 신고하고 원본을 대조하면 바로잡을 수 있다 | 신고가 분리되고 원본의 수령처가 삭제됐다. 조회한 직원과 경찰이 오히려 조사 대상이 된다 | 직원과 사본을 보호하고 상층 일괄 승인선으로 이동 |
| 상층 거주구 | 더 높은 권한이면 기록과 주민을 지킬 수 있다 | 공용 전력은 회수 작전으로 갈라지고 주민 명단은 설비 재배치 계약에 묶였다. 점수는 승인돼도 백명의 이동 심사는 보류된다 | 보안 병기를 제압한 뒤 최상층 샛길 침입 |
| 최상층 통제구 | 자신만 기록에서 막혔다 | 정비 노동자와 이의 신청자도 기록 밖으로 밀려났다. 저격수 역시 같은 방식으로 통행을 잃었다 | 대치를 끝내고 각자의 기록을 찾는다. 백명은 회장실 자료를 대조하고 비서실장과 싸운 뒤 그가 살아서 물러난 회장실로 진입 |
| 마지막 하강 추격 | 오늘의 회수 작전을 막아야 한다 | 회장은 코어를 싣고 최하층으로 향한다. 지원 총탄이 백명을 구하지만 기동 준비된 코어의 보호부를 파손한다 | 코어 연쇄 활성화·대폭발·추락으로 1회차 종료 |

용의자의 동기는 범행의 면죄부가 아니다. 그는 진료소에 코어를 돌려보내려 했지만 도주 중 다른 주민을 위험에 빠뜨렸다. 백명은 검거를 취소하는 대신 그 동기와 실제 피해를 둘 다 기록한다. 통신관은 흑막을 처음부터 아는 인물이 아니라, 권한 제한과 사본 대조를 경험하며 백명을 돕는 조력자다. 상층 주민 전부가 공모자는 아니다.

## 조커 복선 — 드문 언급, 1회차 신원 확정 금지

현재 주민 대화에 다섯 군데만 배치했다. 듣지 않고 지나갈 수 있는 대화이며 강제로 반복 재생하지 않는다.

| 구역 / 화자 | 듣게 되는 조각 | 1회차에서 확정하지 않는 것 |
| --- | --- | --- |
| 생산구 / 정비사 한석 | 검문 안내의 설명 없는 조커 항목 | 사람인지 장비인지 |
| 생활구 / 배급 담당 미루 | 배급함 잠금에 남은 조커 표식 | 실제 행위자와 소문 진위 |
| 행정구 / 관제 수습 태린 | 미분류 호출명과 교체된 교육 자료 | 호출명 소유자 |
| 거주구 / 경비 통신원 수현 | 발신지 없는 조커 신호와 응답 금지 명령 | 기관이 위험하다고 부르는 근거 |
| 통제구 / 폐쇄망 정비사 도하 | 주인이 없어서 삭제 승인조차 못 받는 호출명 | 저격수와의 직접적인 연결 |

제작 기준상 이 단서들은 저격수를 향한다. 최상층 전투에서는 모자에 반쯤 가린 조커 가면을 직접 볼 수 있지만, 첫 대사나 순찰 기록에서 호출명의 소유자·실명·과거 관계를 설명하지 않는다. 2회차에서 과거 관계가 드러났을 때 이전의 단서들이 재해석돼야 한다.

## 주민과 플레이의 연결

각 층에 네 개씩 총 20개의 주요 현장 사건을 두었다. 주민 25명은 사건 이전/이후의 말을 따로 갖고, 실제 들은 대화를 Tab 기록에서 다시 확인한다. 사건별 확보 자료 세 항목도 완료 뒤 다시 읽을 수 있다. 전문은 CAMPAIGN_SCRIPT_KO.md에 실제 런타임 데이터 기준으로 정리했다.

- 생산구: 야간 배정 → 작업장 전력 → 갇힌 작업자 구조 → 사본 보관.
- 생활구: 진료소 본선 복구 → 배달원 보호·용의자 동기 → 불법 심사 설비 → 빈 수령처 원장.
- 행정구: 분리된 신고 접수 → 폐기 장치 차단 → 원본/사본 대조 → 직원 보호.
- 거주구: 회수 전력 분기 → 재배치 계약·명단 → 이송 예정자 보호 → 승진 보류와 외벽 경로.
- 통제구: 감시 회선 → 삭제된 이의 신청 → 미승인 통로 → 저격수 대치 → 회장실 자료 대조.

사건은 기록·증언 E 조사, 블레이드 봉인 해제, 주민 동행 보호, 입자 레이저 수동 복구로 나눈다. 모든 층을 같은 스위치 퀘스트로 채우지 않는다. 중간 층에는 추격전을 추가하지 않는다. 마지막 회장실 창밖에는 회장/특수부대의 트럭 탑승을 간략한 도트 인물 이동으로 표시한다.

## 분량 목표와 실제 구현의 구분

완성판의 보통 난이도 첫 플레이 목표는 여전히 약 9시간이다. 장별 예산은 생산구 60분 / 생활구 100분 / 행정구 110분 / 거주구 110분 / 통제구 100분 / 마지막 추격 60분으로 합계 540분이다.

이 배정은 콘텐츠 제작 예산이다. 현재 20개 현장 블록아웃의 실제 분량을 그 숫자로 간주하지 않는다. 맵을 크게 늘리거나 대사를 반복하거나 느린 호위를 강제해서 시간을 맞추지 않는다. 실제 Unity 완주·첫 플레이 난이도·프레임과 빌드 검증은 아직 수행하지 못했으며, 현재 버전을 “9시간 90% 완성”으로 표시하지 않는다. 남은 범위는 COMPLETION_KO.md에 공개한다.

## 최상층 저격수 대치 — 4페이즈

저격수는 가벼운 검정·흰색 복장에 긴 저격소총을 들고, 조커 가면의 반쪽을 모자 아래에 가린다. 1페이즈는 2초 조준·5발 후 재장전과 멀리서 던지는 수류탄을 사용한다. 수류탄은 지면을 부숴 입자를 만들며, 깨진 바닥은 복구된다. 2페이즈에는 다른 위치의 푸른 에너지 분신 한 명이 같은 패턴을 더한다. 3페이즈는 분신 총 세 명 중 둘이 압축 포탑을 조종하고 본체와 나머지 한 명이 기존 패턴을 계속한다. 포탑의 조종 분신을 제압하면 백명이 E로 탈취해 조종할 수 있다.

파이널에서는 분신이 사라지고 저격수는 피해를 받지 않는 충전에 들어간다. 포탑 두 개를 파괴해 나온 입자를 우클릭으로 모아 게이지를 채우면 양쪽 레이저가 자동으로 충돌한다. Space와 좌클릭 연타로 밀어내면 대치가 끝나고, 실패하면 포탑 파괴·입자 수집부터 다시 시도한다. 세부 구현은 SNIPER_BOSS_KO.md에 정리한다.

전투 승리는 사망 처리로 연결하지 않는다. 저격수는 살아서 백명과 같은 처지임을 확인하고 헤어지며, 실명이나 과거 관계는 여전히 공개하지 않는다. 이후 하강 추격의 지원 사격과 2회차 관계 공개가 이어진다.

## 회장실 앞 최종보스 — 비서실장 (v0.12.0 추가)

저격수와는 같은 처지라는 점만 확인하고 헤어진다. 마지막 보관 자료를 대조한 백명은 회장실 앞에서 비서실장과 대치한다. 비서실장은 이의 신청과 동결 기록을 정해진 절차라는 말로 막는다. 회장실로 들어가는 길은 이 전투를 마쳐야 열린다. 회장은 여전히 그곳에 없으며, 노트와 회수 계획을 본 뒤 1분 카운트다운과 하강 추격으로 이어진다.

1페이즈 순환: 3초간 감속 회전하는 시침·분침의 힘을 합친 방향으로 창 발사(첫 두 번 1개, 세 번째 합성·시침·분침 방향 3개) → 옆으로 순간이동하는 광역 시계 2회 → 중앙 공중으로 이동해 반대 회전하는 대형 시계 1회(바로 아래 안전) → 시침·분침·초침 비 → 반격 시간. 합성 방향 화살표는 표시하지 않는다. 창은 발사 시점까지만 주인공을 조준하며 발사 뒤에는 꺾이지 않는다. 바닥에 박힌 침은 블레이드로 파괴해 나온 입자를 우클릭으로 수집한다.

1회차의 비서실장은 1페이즈만 싸우고 살아서 퇴장한다. 사망·시체·처치 보상은 없고 퇴장 대사 후 시계의 빛과 함께 사라진다. 비서실장은 2회차에 다시 등장한다. 1회차에 2페이즈를 덧붙이지 않는다.
