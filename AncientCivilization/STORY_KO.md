# 도시 1회차 스토리 기준안

이 문서는 현재 구현과 앞으로 제작할 이야기를 구분하는 시나리오 기준안이다. 사건을 추가하더라도 사용자와 합의한 코어 절도, 엘리베이터 왕복, 최상층 불법 침입, 저격수 재회와 지원 사격, 마지막 트럭 추격의 흐름을 보존한다. 고대 문명 탐험은 2회차로 유보한다.

## 분량과 현재 상태

- 완성판 1회차 설계 목표: 보통 난이도 첫 플레이 기준 메인 스토리 약 9시간. 현재 구현된 시간이 아니다. 숙련자의 빠른 재플레이 시간은 별도로 본다.
- 현재 v0.10.0은 도시 다섯 구역의 짧은 이동·전투, 선택 수사 세 개, 마지막 하강 추격과 임시 엔딩을 연결한 프로토타입이다. 실제 첫 플레이 시간은 측정하지 않았다. 예전 30~60분 추정은 마지막 추격 추가 전의 참고값이며 최신 완주 시간을 보장하지 않는다.
- 현재 구현: 튜토리얼, 첫 코어 트럭 추격, 코어 회수/미니 보스, 승진과 실제 엘리베이터, 층별 기믹·범죄자·보스, 최상층 샛길, 저격수 재회, 회장실 조사, 마지막 하강 추격, 지원 사격/코어 보호부 파손/폭주/추락의 짧은 종료 연출.
- 현재 선택 수사: 생활구 비상 전력 복구, 행정구 원본 캐시와 사본 대조, 거주구 경비 단말 기록. 결과는 순찰 기록에 저장한다. 아래 표의 장편 수사 전체를 구현한 것은 아니다.
- 후속 제작: 여러 하위 구역과 주민 사건, 용의자의 구체 동기 확인, 저격수의 과거/구조 신호, 재배치 명단의 현장 대조와 계약 수사, 관제실 잠입, 회장과 특수부대 탑승의 상세 연출. 현재 창밖에는 작전 트럭을 간략 표시한다.
- 같은 공간의 단순 왕복, 체력만 높은 적, 반복 잡몹 처치로 시간을 채우지 않는다. 각 재방문에는 새 증거나 바뀐 상황이 있어야 한다.

## 중심 갈등과 인물의 목적

주인공은 하층의 안전을 지키는 한국인 치안경찰이다. 포인트와 승진 제도가 공정하다고 믿으며, 위로 올라가면 더 많은 사람을 지킬 권한을 얻을 수 있다고 생각한다. 사건을 따라가면서 자신의 검거와 승진이 증거를 회수하고 하층을 통제하는 절차로 이용됐음을 알게 된다. 마지막에는 승진보다 주민의 안전과 증거를 선택한다.

초반 용의자는 위층 운송 설비 기술자로 설정한다. 정상 배정분이 사라진 하층 진료소에 코어를 돌려보내려 했지만 합법적인 정정 요청이 거절돼 코어를 훔쳤다. 급한 도주 과정에서 다른 하층 설비의 전력까지 끊었고, 물체를 던져 민간인을 위험에 빠뜨렸으므로 범행 자체가 정당화되지는 않는다. 이 동기는 초반 검거 장면에서 전부 설명하지 않고, 생활구의 진료소 기록으로 확인한다.

통신관은 제한된 권한 안에서 일하는 조력자다. 초반에는 규정을 믿고 따르지만, 접근 차단과 사본/원본의 불일치를 직접 확인한 뒤 주인공을 돕는다. 최상층 흑막을 처음부터 알고 있는 안내자가 아니다.

저격수는 주인공의 옛 동료이자 친구다. 하층 주민 강제 이송 명령에 불복한 뒤 포인트가 동결되고 기록상 범죄자가 됐다. 동료들의 이송 기록을 찾으려고 최상층에 잠입한다. 얼굴을 가린 주인공을 기관의 추격자로 오해해 먼저 싸우며, 전투 중 드러난 옛 구조 신호와 목소리로 서로 알아본다. 재회 후 같은 편이 되지만 즉시 동행하지 않고 각자 조사한다.

중앙행정정보처리기관 회장은 코어 배정, 포인트 심사, 층간 관제를 장악한 최상층 세력의 중심이다. 도시 아래에 매몰된 문명의 동력원을 독점하려고 하층 코어를 회수 작전에 전용한다. 안전을 위한 정비·재배치라고 발표하면서 주민의 포인트와 이동 권한을 조정해 현장을 비운다. 일반 상층 주민 모두가 공모자는 아니다.

## 장별 인과관계와 콘텐츠 목표

각 장은 여러 플레이 구역으로 구성한다. 현재의 짧은 층별 경로 하나가 완성된 장 하나를 대신하지 않는다.

| 장 | 사건과 얻는 증거 | 다음 장으로 가는 이유 | 완성판 시간 배정안 |
| --- | --- | --- | --- |
| 0 하층 생산구 | 일상 순찰과 주민 구조, 장비 훈련, 코어 절도 신고, 첫 트럭 추격과 검거. 운송장 사본에 C-00과 빈 수령처 | 검거 보상으로 윗층 출입 권한을 얻고 운송 이력을 확인하러 감 | 약 60분 |
| 1 하부 생활구 | 진료소의 정전, 주민 실종, 불법 포인트 거래를 수사. 용의자가 코어를 보낼 목적지와 배정 삭감 기록을 확인. 밀매 조직 보스 제압 | 지역 조직은 사라진 물량을 전부 설명할 수 없고, 승인 원본이 행정구에 있음 | 약 100분 |
| 2 중층 행정구 | 증거 접수, 운송 원본 조회, 현장 봉쇄, 기록 보관소 잠입. 통신관의 사본과 대조해 수령처가 삭제됐음을 입증. 기록 집행관과 충돌 | C-00 승인권자가 상층 회수 계약과 연결됨. 증거를 확보한 뒤 정식 사건 해결 보상으로 거주구 출입 해금 | 약 110분 |
| 3 상층 거주구 | 기술자/계약 담당자 조사, 코어 저장시설 침투, 하층 재배치 명단 확인. 아래 진료소에 돌아가 이송 예정자와 번호 대조. 코어 보안 병기 제압 | 최상층 직할 승인임을 확인하지만 포인트를 충분히 얻어도 출입 신청은 거절됨 | 약 110분 |
| 4 최상층 샛길·통제구 | 외벽 정비로 불법 침입, 저격수 보스전과 옛 친구 재회. 각자 헤어진 뒤 관제실과 회장실 조사. 노트와 회수 계획을 발견 | 작전 개시까지 1분. 창밖에서 회장과 특수부대가 코어 운송 트럭에 타는 모습을 확인 | 약 100분 |
| 5 도시 하강 추격 | 회장 트럭을 최상층부터 최하층까지 추격. 차량 옮겨 타기, 와이어 이동, 트럭 위 전투. 저격수 지원으로 생존하지만 코어가 폭주 | 지반 붕괴와 추락에서 1회차 종료. 고대 문명에서의 조작/탐험은 제공하지 않음 | 약 60분 |

배정 합계는 540분, 약 9시간이다. 보통 난이도의 첫 조우 패턴 학습과 자연스러운 재시도를 포함한 메인 진행 예산이며, 선택 수사 전체 완료나 반복 실패를 필수로 계산하지 않는다. 이는 설계 예산이며 제작 후 외부 플레이테스트로 조정한다. 1회차에는 초반과 마지막 두 번의 추격전만 둔다.

각 장에는 도입 조사 → 새로운 기믹을 익히는 이동 구역 → 범죄자/증거 구역 → 기믹 응용 → 패턴 보스 → 짧은 사건 정리를 둔다. 실종 수사, 기록 잠입, 저장시설 침투는 서로 다른 목표이며 모두 같은 스위치를 누르는 퀘스트로 만들지 않는다.

## 복선과 회수 시점

| 단서 | 처음의 해석 | 회수 |
| --- | --- | --- |
| C-00 예비 코어는 현지 점검 제외 | 정기 배정의 예외 규정 | 행정구 원본에서 최상층 직할 회수 물량임을 확인 |
| 운송장 수령처 공란 | 누락 또는 열람 권한 문제 | 통신관의 사본과 원본의 수정 시각을 대조해 삭제 사실 입증 |
| 용의자가 운송장 마지막 칸을 보라고 함 | 체포를 피하려는 변명 | 생활구 진료소의 미수령 기록으로 의문이 실제임을 확인 |
| 용의자·회수품 별도 이송 | 중요한 사건의 인계 | 이송 차량과 코어가 같은 C-00 현장으로 향함 |
| 엘리베이터에도 C-00 관제 코드 | 공용 설비 규격 | 층간 통제와 물량 회수의 승인 주체가 같음을 관제실에서 확인 |
| 저격수의 구조 신호/사격 간격 | 낯선 적의 습관 | 싸움 후 주인공이 옛 친구의 습관임을 알아봄 |
| 코어는 충격 시 보호 장치를 먼저 해제해야 함 | 작업 안전 수칙 | 마지막 총탄이 이미 작동 준비 중인 코어의 보호부를 관통했을 때 폭주하는 원인 |

현재 게임에는 C-00 점검 예외·표지·공란 운송장·별도 이송·엘리베이터 코드 외에 선택 수사의 진료소 미수령 기록·운송장 원본 대조·최상층 직할 물량 기록을 넣었다. 회장실 계획에는 기동 준비된 코어의 보호부 파손 경고가 나오며, 마지막 지원 총탄이 보호부를 관통한 뒤 코어가 점멸한다. 저격수의 구조 신호와 과거를 보여 주는 별도 장면은 후속 제작이다.

## 마지막 추격전의 원인과 결과

회장실에 노트가 남은 이유는 작전 중 사용하는 개인 연구 원본을 보관해 두었고, 회장은 정식 출입이 봉쇄된 집무실에 하층 경찰이 도달할 것으로 예상하지 못했기 때문이다. 노트 하나가 모든 설명을 대신하지 않는다. 앞서 얻은 진료소 기록·운송장·계약 승인과 대조하면서 계획의 의미가 확정된다.

작전 개시 1분은 회장실 계획을 확인한 뒤 시작하는 연출이다. 플레이어가 긴 글을 읽는 동안 상황을 놓치는 실패 조건으로 만들지 않는다. 창밖의 탑승 장면과 작전 개시가 추격의 직접적인 계기다.

저격수는 친구를 죽이려는 특수부대의 사격 장치/구속 장치를 관통해 주인공을 구한다. 같은 탄환이 이미 기동 상태인 코어의 보호부까지 손상시킨다. 코어는 트럭에 실렸다는 이유만으로 폭발하는 것이 아니라, 회수 작전의 기동 상태와 보호부 파손이 겹쳐 연쇄 활성화된다. 사전에 안전 수칙과 충격 반응을 보여 주어 우연으로만 보이지 않게 한다.

폭발로 최하층 지반이 붕괴하고 주인공은 아래로 떨어진다. 검은 화면과 짧은 미지의 빛으로 1회차를 마친다. 고대 문명 플레이 구역을 이번 제작 범위에 포함하지 않는다. 회장의 생사, 저격수의 재등장과 회수 작전의 진짜 규모는 후속 이야기로 남긴다.

## 분량 검증 원칙

현재 구현은 약 660유닛의 도시 수평 구간과 600유닛의 마지막 하강 도로, 튜토리얼·두 추격, 총 다섯 보스, 소수 범죄자와 짧은 수사 대사로 구성한다. 거리가 늘어났다는 이유로 9시간 분량이 확보된 것은 아니다. 맵 길이만으로 플레이타임을 산출하거나, 보스 체력과 재시도 횟수를 강제해 시간을 늘리지 않는다.

다음 제작에서는 장별 실제 진행 시간, 대화 시간, 이동 구간 최초 성공/재도전, 보스 학습/전투 시간을 분리해 기록한다. 숙련 개발자 완주와 처음 하는 외부 플레이어 완주를 별도로 측정한 뒤 목표 시간을 조정한다. 산나비의 완성된 분량을 현재 프로토타입의 구현 분량으로 오인하지 않는다.
