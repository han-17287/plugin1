# 도시 1회차 — 현재 맵과 다음 제작 설계

이번 버전은 초반 학습과 하층 진행 흐름을 바꿉니다. 베기·입자 수집·수광부 레이저로 실제 검수문을 열고, 필수 행동 현장은 접근 안내 후 해결 즉시 다음 길로 이어집니다. 경비는 등장 전에 위치를 예고하며, 고정된 안전 발판에 착지하면 재도전 지점이 저장됩니다. 기존 지형·이야기·보스는 유지합니다. **실제 Unity 플레이와 난이도·완주 시간 검증은 아직 남아 있습니다.** [변경 내용과 확인할 점](GAMEPLAY_FLOW_KO.md)

이번 버전은 도시 다섯 구역의 플레이용 블록아웃이다. 기존 도트 에셋과 새 지형·기믹을 조합했다. 고대 문명은 2회차 범위로 남겨 두며 맵·입구·엘리베이터 목적지를 만들지 않는다.

생활부는 v0.24.0에서 목격 경로·감시 구역·거대 로봇전으로 교체했다. 아래의 구현 범위와 별개로 실제 Unity 완주 검증은 남아 있다.

## 이동과 저장

승진은 자동 이동이 아니라 출입 권한 해금이다. 하층부터 거주구까지는 입구 엘리베이터에서 해금된 목적지를 골라 왕복한다. 최고 포인트를 모아도 최상층은 엘리베이터로 진입할 수 없다. 거주구 보스를 제압하고 동쪽 외벽 샛길에서 E로 침입한다. 최상층 입구의 E는 거주구 귀환이다.

기존 upperCity 저장은 첫 윗층인 하부 생활구로 이관한다. 새 cityFloor와 cityCleared로 현재 층과 구역 해결 기록을 보존한다. 층 이동은 전투 잔여물과 투사체를 정리한다. 보스 진입 시 전투 입구를 재도전 지점으로 저장한다. 재접속·사망은 현재 층의 저장 지점에서 이어지며, 이동 구간의 단순 추락은 해당 층의 안전 발판으로 회수한다.

## 전투 범위

후속 구역 보스는 기존 도트 에셋을 재사용한 첫 구현이다. 생활구는 아래의 전용 거대 로봇, 행정구는 연속 사격, 거주구는 고철 투척, 최상층은 조준 후 사격과 긴 장전 빈틈으로 구분한다. 와이어의 보스 피해 저항을 적용하고 보스 전조를 와이어로 취소하지 않는다. 저격수는 살해 보상 없이 전투를 끝낸다.

추격전은 초반과 마지막 두 번만 둔다. v0.10.0은 최상층 동쪽 회장실의 노트 조사와 최상층→최하층 600유닛 하강 화물 도로를 연결했다. 연속 경사 도로·와이어 천장·다섯 배치 오토바이·트럭 지붕 경비·투척 장치와 구간 재도전을 구성한다. 트럭에 레이저를 맞히면 투척이 잠깐 멈추고, 끝에서 실제 트럭 지붕에 올라서면 지원 사격·코어 폭주·추락 연출이 시작된다. 고대 문명 추락 이후 플레이는 2회차 작업으로 유보한다.

## 탐색과 선택 수사

각 도시 층의 높은 경로에 두 개씩 총 열 개의 일회성 보급품을 놓았다. 생활구는 공중 절연판 베기, 행정구는 셔터 위 원본 캐시 회수 후 대조, 거주구는 경비 제압 후 단말 조사로 구분한다. 선택 수사는 보스 진입을 강제로 지연시키지 않는다. Tab 기록에서 발견한 단서와 층별 보급품 현황을 볼 수 있다.

## 검증 한계

정적 발판 폭·간격·머리 공간, 권한·샛길 규칙, 셔터 주기·상승류 규칙을 독립 C# 검사로 확인한다. 실제 Unity에서 전체 층을 완주하거나 셔터/환기/붕괴 발판과 보스 난이도를 플레이 테스트한 결과는 아니다.


## 현재 현장 경로

하층 8개 수사 이정표는 폭 2,496단위·3구간, 상부 12개는 폭 624단위·3구간이다. 같은 층은 64단위 연결 통로로 이어지고 실제 엘리베이터로만 다른 층에 간다. 하층의 새 필수/선택 현장과 대화 목록은 [하층 확장 문서](LOWER_DISTRICTS_KO.md)에 있다. 구간·현장별 확보 상태를 저장하고, 뒤처진 보호 대상은 열린 지상 통로에서만 따라온다.

## 생활부 와이어 투척과 거대 로봇

v0.27.0까지의 소스 구현이다. 런타임 동선·입력·피격·패턴·저장·전용 도트 부품과 전투 후 진술을 연결했다. 실제 Unity Play/빌드에서 전 구간을 검증한 결과는 아니다.

### 이동 경로

한 번 임무를 받은 뒤 도둑이 지나간 주거 골목 → 폐차 적치장 → 스포트라이트 감시 구역 → 코어 밀매 창고 → 로봇 격납고까지 직접 이동한다. 목격 흔적에 도달하면 기록이 순차 확보된다. 생활부의 옛 전력 복구·호위·봉인 파괴·증거 퀴즈는 이 진행에서 제외했다. 네 이정표와 제자리 안전 저장은 같은 긴 맵 안에서 이어지며, 소장 복귀·타이머·자동 전진·차량 추격은 없다.

폐차 적치장 첫 이정표는 실제 와이어 투척을 한 번 사용해야 열린다. 사용 기록은 저장한다. 일반 길은 지붕·폐차 더미·낮은 통로를 오르내리고 감시 구역 가운데에는 기존 와이어·블레이드 반동 점프 경로가 남는다. 상자와 차는 실제 바닥/발판 높이에 배치한다. 구역 배경은 진료소 주변 주거지, 폐차 더미, 보안 격벽, 코어 적재함으로 구분했다.

### 물체 와이어

- 와이어 모드 좌클릭: 표시된 큰 물체를 잡아 0.62초 동안 한 바퀴 돌린 뒤 마우스로 정한 방향으로 투척한다. 지형 대상의 직선 견인과 가운데 버튼 스윙은 유지한다.
- 물체가 백 경위 주변을 회전하며, 와이어는 직선 중심과 이중 나선을 그린다. 회전 중 조준선은 바꿀 수 있고 발사 뒤 방향은 고정이다. 한 번에 하나만 잡는다.
- 적/지형 첫 충돌에서 한 번만 피해·파괴·파란 입자를 발생시킨다. 상자 피해 42, 차량 65, 일반 보스에 던질 때는 전용 보스 피해 보정을 따른다. 생활부 로봇에는 상자 36/차량 52/반사 주먹 68을 기준으로 회복 빈틈 보정과 체력 경계를 적용한다.
- 정적 상자·차량은 소진 6초 뒤 재보급한다. 미사일과 상자는 블레이드로도 분해해 입자를 얻을 수 있다. 입자는 우클릭으로 수집한다.
- 로켓주먹은 3초 충전 후 추적한다. 와이어로 반격할 수 있다. 3페이즈의 첫 반격 주먹은 보스가 붙잡아 0.7초 전조 뒤 빠른 직선으로 재투척한다. 다시 와이어로 되돌리면 명중하며 무한 주고받기를 강제하지 않는다.

### 감시와 본거지 경비

스포트라이트는 회전하는 시야와 실제 지형 가림을 검사한다. 발각되면 1.1초 전조 뒤 레이저 또는 경비 로봇이 나온다. 레이저는 잠긴 조준점을 향하고 엄폐에 막힌다. 로봇은 인접 구역 최대 2명, 재경보 간격은 로봇 8초/레이저 5초다. 발각은 즉시 실패 조건이 아니다.

격납고에서 두목의 대사 후 경비 2명씩 두 무리를 제압한다. 마지막 경비를 제압하면 `livingGuardsCleared`를 저장하고 로봇에 탑승한다. 사망·재접속 후 완료된 조직원전을 반복하지 않으며 보스는 1페이즈부터 재도전한다. 기존 세이브의 생활부 클리어 비트는 보존한다.

### 체력 전환과 외형

두목 기체 체력은 960, 2페이즈는 68%, 3페이즈는 34%다. 경계 전까지 현재 페이즈를 반복한다. 한 번의 큰 피해는 경계에서 멈춰 다음 페이즈를 건너뛰지 못한다. 짧은 전환 중 피해를 막고 남은 투사체·잡힌 상태를 정리한다. 비서실장 1페이즈 생존 퇴장과 저격수의 마지막 승리 조건은 유지한다.

기체는 조종석·분리된 큰 팔과 주먹·무거운 다리를 가진 거대 로봇이다. 캐시한 픽셀 부품으로 관절을 움직이며 돌진/주먹 준비/붙잡기/후경 축소 이동을 표현한다. 3페이즈에서는 중앙 코어가 푸른 X로 켜지고 기체에서 에너지가 방출된다.

| 페이즈 | 반복 패턴 | 대응 |
| --- | --- | --- |
| 1 | 총알 10발 → 도약 강타 → 3초 충전 추적 로켓펀치 → 미사일 8발 | 총알 회피, 착지 범위 밖으로 이동, 주먹 와이어 반격, 미사일 베기·수집 |
| 2 | 후경 대포 포격 → 총알 20발 → 배리어 접근·긴 팔 붙잡기 | 낙하 예고 회피, 탄막 회피, 배리어 파괴·스턴 |
| 3 | 더블 로켓펀치 → X 블래스트 → 입자 흡입 → 결과에 따른 추가 공격 → 전방위 미사일 16발 | 로켓 재투척 회피/재반격, X 사이 안전 공간, 지형 와이어 버티기 또는 열린 코어 레이저 |

총알과 포탄은 입자화 불가능하다. 예전 F 직접 흡수는 제거했으며, 분해 가능한 물체를 블레이드로 부순 뒤 우클릭으로 입자를 수집한다. 미사일은 입자화 가능하고 모든 미사일은 발사 순간 목표점을 향한 직선으로 날아간다. 전방위 미사일은 방향별 점화 전조와 발사 간격을 둔다.

### 배리어와 흡입 분기

배리어 내구도는 70. 입자 게이지 100의 레이저 1회(70), 물체 투척 10회(회당 7), 근접 7회(회당 10)로 파괴하며 혼합 피해도 누적한다. 부분 게이지 레이저는 소비한 에너지에 비례해 방어막을 깎는다. 보통 와이어 견인 피해로는 파괴할 수 없다. 파괴 공격이 본체 체력까지 중복해서 깎지 않고 3.2초 스턴을 준다. 같은 레이저/베기/물체는 한 번만 집계한다. 좌클릭 유지로 발사 준비를 마친 것과 입자 게이지가 가득 찬 것은 구분한다.

긴 팔에 잡히면 조작을 막고 끌어당긴 뒤 주먹 한 번으로 풀어 준다. 사망·이동·페이즈 전환에서도 물리 시뮬레이션과 입력을 복구한다.

3페이즈는 1 더블 로켓 → 2 X 광선 → 3 흡입 순으로 시작한다.

- 열린 코어에 레이저 명중: 과부하 스턴 → 4 전방위 미사일 → 1.
- 흡입 완료: 1 추가 로켓 → 2 추가 X 광선 → 4 전방위 미사일 → 1. 추가 X 뒤에 흡입을 다시 반복하지 않는다.

흡입은 실제 입자를 코어로 끌어들이고 플레이어 이동에 힘을 가한다. 흡입 중 천장·벽을 좌클릭하면 견인 대신 와이어 고정으로 버틴다. 적을 향한 와이어는 버팀으로 취급하지 않는다. 레이저가 없어도 지형 고정으로 대응할 수 있다. X 광선의 넓은 전조와 실제 폭을 맞추고 교차점 아래·위·양옆에 피할 공간을 둔다.

### 저장·검사와 남은 확인

생활부 규칙은 `LivingChecks.cs`에서 체력 경계·반복·배리어 혼합·흡입 분기·투사체 경로·X 안전 공간을 검사한다. Unity에는 `PLUGIN/검사/생활부 와이어와 거대 로봇` 메뉴를 추가해 임시 저장 프로필로 컴포넌트 연결을 확인하게 했다. 보통 플레이 저장은 해당 검사에 사용하지 않는다.

이 환경에는 Unity Editor가 없어 새 메뉴와 실제 플레이를 실행하지 못했다. 이동 경로의 체감 밀도, 투척 모션/벽 충돌, 경보 회피, 후경 포격 가독성, 잡힘 해제, 전체 보스 난도, 저장 후 재도전, 다양한 화면비와 실제 FPS는 실기 확인이 남아 있다. 9시간 또는 완성 비율로 환산하지 않는다.
