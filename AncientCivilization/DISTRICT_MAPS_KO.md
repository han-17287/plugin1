# 지역 맵 v0.31 — 건물 안팎을 지나가는 이동 경로

메인 화면에서 **이동 연습장**를 누릅니다. Unity에서는 `Assets/Scenes/TraversalRhythmPractice.unity`를 직접 Play해도 같습니다. 첫 화면은 생산구의 실제 위험 설비가 켜진 경로입니다. 오른쪽 위 **지역 / 도움말**에서 다른 층, 장치 난도, 안전 바닥을 고릅니다. 설정을 연 동안 이동·장치 시간은 멈춥니다. Esc 일시정지도 가능합니다.

이 버전은 새 이동 컨트롤러가 사용하는 **다섯 개의 지역 이동 맵**을 구현합니다. 기존 Main 순찰의 모든 현장·주민·무기·보스를 이 좌표로 옮긴 버전은 아닙니다. 메인 순찰의 기존 저장과 이야기는 별도로 유지됩니다. 다음 구역 문은 이동 맵 선택으로 연결되며 스토리 승진·엘리베이터 해금을 대체하지 않습니다. 고대 문명 지역은 만들지 않았습니다.

## 장소와 경로

거리·높이는 월드 1 = 타일 1입니다. `DistrictRouteLayout.cs`가 실제 지형·앵커·재시작 지점과 HTML 배치도의 공통 원본입니다.

| 층 | 이어지는 장소 | 길이 | 천장 높이 | 높낮이와 핵심 장치 |
|---|---|---:|---:|---|
| 생산구 | 교대문 / 컨베이어 정비소 / 코어 검수동 | 112 | 18 | 하역 도크, 크레인 정비교, 운송 레일, 전력·하역 원화 |
| 생활부 | 공동 주택 / 진료소 앞뜰 / 감시 외벽 | 120 | 20 | 2층 발코니, 폐차장 캐노피, 배관 보행교, 움직이는 탐조등 |
| 행정구 | 접수 회랑 / 원본 대조실 / 감사 기록실 | 114 | 18 | 보관함, 셔터 대기 섬, 높이 10의 점검 덕트, 시간 셔터 |
| 거주구 | 정원 관리동 / 환기 온실 / 계약 전시관 | 116 | 24 | 높이 8의 테라스와 높이 13의 화단 보행교, 상승 환기류 |
| 최상층 | 폐쇄 승강구 / 미승인 외벽 / 직할 통제동 | 118 | 22 | 외벽 접속대, 높이 9·12의 정비교, 시간제 이동 앵커 |

각 층은 다른 지형 좌표를 사용합니다. 단순히 같은 방의 색을 바꾸지 않습니다. 다섯 구역 모두 닫힌 천장, 지상 진입·회복 공간, 건물 위 경로, 중앙의 한 필수 난관, 연결문을 갖습니다. 지상 길에는 작은 단차만 두고 높은 통과 동작을 중앙 정비 시설에 모았습니다. 정비교에는 지지대와 뒤쪽 난간을, 앵커에는 케이블·브래킷·이동 레일을 그립니다. 후벽과 창문은 어둡게, 실제 발을 딛는 면은 밝게 구분합니다. 배경 설비는 충돌하지 않습니다.

시험장 사각형 주인공을 기존 백 경위 원화로 교체했습니다. 전면 시험 패널은 접힌 상태로 시작하며, 상태·속도는 도움말에서만 봅니다. 카메라는 수평·수직으로 따라가며 낮은 길에서도 위험 설비 윗부분이 보이도록 아래 여백을 확보합니다. 이는 코드 배치이며 실제 Unity에서 최종 미술·가독성을 확인해야 합니다.

## 이동·실패·복구

- A/D 이동, Space 점프, Shift 대시, Q/휠 모드, 갈고리 모드 좌클릭 직선 견인입니다. 현재 새 지역 맵에는 P3~P6 무기·입자·레이저가 연결되어 있지 않습니다.
- 각 층의 재시작 지점 3곳은 그 위치에 **착지하면** 활성화됩니다. 공중으로 위를 통과한 것만으로 저장되지 않습니다. 이후 실패하면 가장 최근 지점으로 돌아옵니다. 이 지도 선택 씬의 체크포인트는 세션용이며 본편 저장을 변경하지 않습니다.
- 재시도 시 일회용 앵커·이동 앵커·탐조등 노출·셔터 위상·시간 접속 장치를 복원합니다.
- 안전 바닥에서는 아래 배수로에 떨어져도 걸어서 상시 복구 앵커 아래로 갈 수 있습니다. 복구 앵커를 이용해 일회용 앵커가 소모된 뒤에도 고정 앵커 경로에 복귀할 수 있습니다.
- 닫힌 천장으로 우회할 수 있지만 먼저 중간 앵커를 타고 사거리 안으로 올라가야 하는 곳이 있습니다. 바닥에서 모든 천장에 닿도록 사거리를 늘리지 않았습니다.
- 장치 난도는 이동 앵커 진폭·주기를 바꿉니다. 세 설정은 서로 다른 세 개의 완성 스테이지가 아닙니다. 안전/위험 옵션도 같은 지형을 공유합니다.

## 구성과 인스펙터

| 스크립트 | GameObject / 필요한 컴포넌트 | 설정 |
|---|---|---|
| TraversalRhythmPractice | 씬의 기존 Bootstrap | DefaultMovement, CapsuleCollider2D 0.72×1.8, Rigidbody2D Continuous/Interpolate를 실행 중 구성 |
| TraversalRoom + TraversalDistrictRoom | 기존 층별 Room Prefab | FloorTraversalProfile, precision, 선택한 TraversalDifficultyData. `BuildDistrict`가 실제 지역 생성. `Build`는 예전 기초 방 코드로 유지 |
| DistrictRouteLayout | 컴포넌트 아님 | 지형·앵커·휴식 공간의 단일 좌표 원본. 브리지 두께 0.65, 지상 기초 하단 -5 |
| DistrictPlayerPresentation | 백 경위 | PlayerStateMachine/InputReader/ModeController. 판정과 원화 크기·발 피벗을 분리 |
| DistrictWorldSign | 장소 표지판 | 2D 월드 좌표를 화면에 투영. 별도 3D 물리·MeshRenderer 사용 없음 |
| TraversalFloorMechanism | 탐조등 / 셔터 / 환기류 / 시간 앵커 | 기존 FloorTraversalProfile 재사용. 고정 틱·일시정지·예약 보호 유지 |

실제 고체는 레이어 8, 플레이어는 9, 위험 설비는 10입니다. 장식에는 Collider를 붙이지 않습니다. 프리팹과 부모 Transform 스케일은 1을 유지합니다. 월드는 Play 중 생성되므로 Edit 화면에 지형이 안 보이는 것은 현재 구조의 특성입니다.

## 검사와 남은 확인

실행 환경에 Unity Editor가 없어 네이티브 임포트·Play·조명·체감·FPS는 확인하지 못했습니다. 아래 자동 검사는 그 대체가 아닙니다.

- `DistrictRouteChecks.csproj`: 다섯 실제 좌표의 앵커 연결, 이동 장치 위상 조합, 사거리 2타일 여유, 캡슐 외접 범위의 지형 간섭, 닫힌 천장, 재시작 발판, 안전 배수로 복구 경로를 검사합니다. 배치 오류를 찾아 생활부 발코니·행정구 덕트 앞 앵커를 수정했습니다.
- `DistrictMapPreview.html`: 위 코드 원본에서 내보낸 **배치도**입니다. Unity 스크린샷이 아닙니다. 다섯 층·진입/난관/출구·안전 바닥·연결선 표시를 검토할 수 있습니다.
- Unity에서 Play하고 `PLUGIN > 맵 > 현재 지역 전체 앵커 경로 실물 검사`를 실행하면 현재 층의 전 앵커를 Rigidbody2D로 연결하는 검사 코드를 제공합니다. **이 환경에서는 실행하지 않았습니다.** Game 뷰에 포커스를 두고 설정을 닫은 상태로 실행합니다.

### 테스트 체크리스트

1. Main 메뉴에서 새 지역 지도로 들어가고 도움말에서 Main으로 돌아오기. 저장된 순찰 진행이 유지되는지 확인.
2. 각 층에서 기본 앵커 경로·건물 위 우회·천장 우회를 직접 걷고 견인해 완주.
3. 재시작 지점 착지 활성화, 공중 통과 비활성화, 실패 후 최근 지점 복귀.
4. 안전 배수로에 떨어지고 일회용 앵커를 소모한 상태에서도 상시 복구 앵커로 탈출.
5. 셔터 안에서 닫힘 유예, 탐조등 경고 후 재시도, 환기류에서 이동, 시간 앵커 예약 중 비활성화 방지.
6. 지역 설정·Esc·포커스 이탈에서 이동/장치가 멈추고 복귀 때 보류 클릭이 오발하지 않는지 확인.
7. 16:9·4:3에서 다음 앵커와 낙하 위험의 시야, 표지판·HUD 겹침, 원화 발 피벗과 벽 접촉 확인.

### 흔한 버그

- 예전 맵이 뜨면 다운로드 태그와 프로젝트 폴더를 확인합니다. 새 배치는 메인 메뉴의 별도 지역 맵 버튼에 있습니다.
- 분홍색/누락 원화는 Unity 임포트와 `Resources/Art`를 먼저 확인합니다. 현재 환경에서는 URP 2D 실기 호환성을 검증하지 못했습니다.
- 입력이 안 되면 Input System 1.11.2 복원, Active Input Handling Both, Game 뷰 포커스를 확인합니다.
- 일회용 앵커가 회색으로 남거나 셔터가 끼면 현재 지점 재시도를 사용하고 해당 위치를 기록합니다. 자동 검사는 실제 충돌 솔버·키 입력·카메라 지연까지 증명하지 않습니다.
