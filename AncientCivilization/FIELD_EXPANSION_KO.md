# v0.16.0 연속 챕터 — 한 번의 임무와 동쪽 목적지

도시 다섯 층은 각각 **하나의 물리적인 연속 맵**이다. 담당자에게 한 번 임무를 듣고 도입부 → 네 수사 이정표 → 동쪽 목적지까지 진행한다. 별도 사건 방 입장·복귀 문·매번 소장에게 보고하는 동선은 사용하지 않는다.

한 층의 길이는 **도입부 128 + 이정표 624×4 + 연결 통로 64×3 + 목적지 96 = 2,912단위**다. 층 좌표 간격은 4,096단위이며 다른 층은 실제 엘리베이터나 최상층 외벽 샛길로 이동한다. 길이는 구현 수치이며 실제 완주 시간이나 9시간 분량을 뜻하지 않는다.

| 층 | 한 번 받는 임무 | 동쪽으로 이어지는 네 이정표 |
| --- | --- | --- |
| 하층 생산구 | 회수 운송로의 끝 | 야간 배정 → 작업장 전력 → 작업자 구조 → 사본 보관 |
| 하부 생활구 | 끊긴 배급선 | 진료소 → 배달원 → 위조 심사 → 수령처 원장 |
| 중층 행정구 | 지워진 승인 | 신고 연결 → 보관소 → 원본 대조 → 직원 보호 |
| 상층 거주구 | 보류된 승진 | 전력 분기 → 재배치 계약 → 이송 예정자 → 승진 보류 |
| 최상층 통제구 | 중앙 관제의 침묵 | 감시 회선 → 삭제 신청 → 미승인 통로 → 저격수 연결 다리 → 마지막 자료 |

생산구의 기존 초반 훈련·추격은 0–118단위 구간에 유지한다. 검거 뒤 순찰소장에게 임무를 받으면 동쪽 128단위부터 수사로가 열린다. 시작 대화와 이정표 전환은 플레이어를 다른 방으로 옮기지 않는다. 최상층의 저격수와 비서실장은 서로 다른 실제 전투장에 있으며, 마지막 자료 뒤 비서실장·회장실 노트로 이어진다. 마지막 추격은 별도의 24,000–24,600단위 도로를 사용한다.

## 이정표 진행과 저장

- 이정표 20개는 각각 폭 624단위·208단위씩 3구간, 세 목표와 여섯 적을 사용한다. 현재 구간의 적은 최대 2명이다. 조사 기록·봉인 앞·구조 출구·전력 패널/수광부에 맞춰 근접 경비와 물체 투척 적을 배치한다.
- 목표·위협을 해결하면 구간 문이 열린다. 세 목표와 여섯 제압 기록을 모두 확보하고 동쪽 완료 지점에 도착하면 자동으로 다음 이정표를 활성화한다. 위치·속도·와이어를 초기화하지 않고 64단위 연결 통로로 계속 이동한다.
- 완료 결과 → 관련 인물 반응 → 단서 정리는 작은 한국어 순차 표시 무전 말풍선으로 재생한다. 이동·점프·공격을 멈추지 않으며 긴 문장은 자동으로 페이지를 넘긴다. 주민과의 선택 대화와 일곱 자료 대조 선택은 유지한다.
- 안전 단말 E는 현재 위치에서 진행을 저장한다. 새 구간의 거점도 확보한다. 낙하·재도전·저장 복원은 확보 거점으로 회수할 수 있으나, 일반 진행과 저장 단말 사용은 복귀 동작을 만들지 않는다.
- 20개 이정표의 목표·거점·제압 상태를 각각 보존한다. 완료 비트와 구버전 목표를 저장 버전 2로 이관하고 층 왕복 뒤에도 부분 진행을 유지한다. 이전의 분리 방 좌표를 새 맵 위치로 그대로 복사하지 않는다.
- 층 입구·동쪽 목적지에 엘리베이터가 있다. 끝낸 층은 동쪽 출구, 진행 중인 층은 입구로 도착한다. 최상층에는 정식 승진/엘리베이터 승인을 주지 않고 거주구 샛길을 사용한다.
- 보호 대상은 제압한 지상 통로에서 빠르게 뒤따르되 미제압 구간·미해결 문 앞에서 멈춘다. 실제 출구 동행 없이 보호 목표를 완료하지 않는다. 전력 수광부에서 입자가 비면 재채취 패널을 안내하고 수집 뒤 수광부로 안내를 돌린다.

## 지정 점프 구간과 재방문

일반 경로는 지상 통로다. 아래 다섯 이정표의 **두 번째 구간**에는 층별 점프·와이어 기믹을 배치하며 적은 착지 발판에 둔다. 사건 번호는 대사집 순서이며 내부 ID는 0부터 시작한다.

| 층 | 지정 이정표 | 가운데 구간 기믹 |
| --- | --- | --- |
| 하층 생산구 | 4. 사본을 남기는 이유 (ID3) | 이동 크레인·양방향 운송 벨트 |
| 하부 생활구 | 7. 포인트를 파는 골목 (ID6) | 블레이드 반동 부유체·와이어 재연결 |
| 중층 행정구 | 10. 닫힌 보관소 (ID9) | 경고 후 닫히는 셔터 |
| 상층 거주구 | 16. 보류된 승진 (ID15) | 상승류·높은 이동 경로 |
| 최상층 통제구 | 19. 누구도 승인하지 않은 길 (ID18) | 무너지는 높은 발판·와이어 이동 |

모든 경로 위쪽은 와이어를 걸 수 있는 단단한 천장이다. 배경·조명·기믹은 실제 카메라와 인접 구간을 따라 표시하며, 완료한 곳으로 되돌아가도 기믹이 남는다. 연결 통로에서 배경이 끊기거나 이정표 전환 때 패럴랙스가 재시작하지 않도록 구성했다. 주민은 도입부·통로·목적지에 분산하고 선택 조사와 보급품도 진행 방향에 맞춰 옮겼다. 오토바이는 초반·마지막 추격전에만 사용하며 1회차 고대 문명 맵은 만들지 않는다.

독립 규칙·에셋·구문·보조 타입 검사 결과는 VALIDATION.txt 기준이다. 실제 Unity 6000.6.7f1의 임포트·충돌·렌더링·FPS·전체 완주는 미검증이다. `PLUGIN → 검사 → 확장 현장 3구간`의 Editor 점검 절차도 이 환경에서는 실행하지 않았다.
