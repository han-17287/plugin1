# v0.27.0 연속 챕터 — 한 번의 임무와 동쪽 목적지

도시 다섯 층은 각각 **하나의 물리적인 연속 맵**이다. 담당자에게 한 번 임무를 듣고 도입부 → 네 수사 이정표 → 동쪽 목적지까지 진행한다. 별도 사건 방 입장·복귀 문·매번 소장에게 보고하는 동선은 사용하지 않는다.

하층 두 곳은 **128 + 2,496×4 + 64×3 + 96 = 10,400단위**, 상부 세 곳은 **128 + 624×4 + 64×3 + 96 = 2,912단위**다. 층 시작 좌표는 0 / 12,288 / 24,576 / 28,672 / 32,768이며 다른 층은 실제 엘리베이터나 최상층 외벽 샛길로 이동한다. 길이는 구현 수치이며 실제 완주 시간이나 9시간 분량을 뜻하지 않는다.

| 층 | 한 번 받는 임무 | 동쪽으로 이어지는 네 이정표 |
| --- | --- | --- |
| 하층 생산구 | 회수 운송로의 끝 | 야간 배정 → 작업장 전력 → 작업자 구조 → 사본 보관 |
| 하부 생활구 | 끊긴 배급선 | 골목·진료소 → 폐차장 투척 → 감시 통로 → 조직 본거지·로봇 |
| 중층 행정구 | 지워진 승인 | 신고 연결 → 보관소 → 원본 대조 → 직원 보호 |
| 상층 거주구 | 보류된 승진 | 전력 분기 → 재배치 계약 → 이송 예정자 → 승진 보류 |
| 최상층 통제구 | 중앙 관제의 침묵 | 감시 회선 → 삭제 신청 → 미승인 통로 → 저격수 연결 다리 → 마지막 자료 |

생산장까지의 도입 튜토리얼과 40,000–41,600단위의 초반 추격 터널은 별도 공간이다. 검거 뒤 무전 지시로 동쪽 128단위부터 수사로가 바로 열린다. 시작 대화와 이정표 전환은 플레이어를 다른 방으로 옮기지 않는다. 최상층의 저격수와 비서실장은 서로 다른 실제 전투장에 있으며, 마지막 자료 뒤 비서실장·회장실 노트로 이어진다. 마지막 추격은 별도의 44,000–44,600단위 도로를 사용한다.

## 이정표 진행과 저장

- 하층 이정표 8개는 각각 폭 2,496단위·832씩 3구간, 나머지 12개는 폭 624단위·208씩 3구간이다. 하층의 각 구간에는 필수 현장 두 곳·선택 현장 한 곳·기존 주요 목표가 이어진다. 경비전은 한 무리 2명이며 생활부의 기존 고정 여섯 적 대신 경비·탐조등을 사용한다. 조사 기록·봉인 앞·구조 출구·전력 패널/수광부에 맞춰 근접 경비와 물체 투척 적을 배치한다.
- 목표·위협을 해결하면 구간 문이 열린다. 세 목표와 해당 위협 제압 기록을 확보하고 동쪽 완료 지점에 도착하면 자동으로 다음 이정표를 활성화한다. 위치·속도·와이어를 초기화하지 않고 64단위 연결 통로로 계속 이동한다.
- 완료 결과 → 관련 인물 반응 → 단서 정리는 작은 한국어 순차 표시 무전 말풍선으로 재생한다. 이동·점프·공격을 멈추지 않으며 긴 문장은 자동으로 페이지를 넘긴다. 주민과의 선택 대화와 여섯 자료 대조 선택은 유지한다.
- 안전 단말 E는 현재 위치에서 진행을 저장한다. 새 구간의 거점도 확보한다. 낙하·재도전·저장 복원은 확보 거점으로 회수할 수 있으나, 일반 진행과 저장 단말 사용은 복귀 동작을 만들지 않는다.
- 20개 이정표의 목표·거점·제압 상태를 각각 보존한다. 완료 비트와 구버전 목표를 저장 버전 3로 이관하고 층 왕복 뒤에도 부분 진행을 유지한다. 이전의 분리 방 좌표를 새 맵 위치로 그대로 복사하지 않는다.
- 층 입구·동쪽 목적지에 엘리베이터가 있다. 끝낸 층은 동쪽 출구, 진행 중인 층은 입구로 도착한다. 최상층에는 정식 승진/엘리베이터 승인을 주지 않고 거주구 샛길을 사용한다.
- 보호 대상은 제압한 지상 통로에서 빠르게 뒤따르되 미제압 구간·미해결 문 앞에서 멈춘다. 실제 출구 동행 없이 보호 목표를 완료하지 않는다. 전력 수광부에서 입자가 비면 재채취 패널을 안내하고 수집 뒤 수광부로 안내를 돌린다.

## 지정 점프 구간과 재방문

하층 일반 구간은 구조물 단차와 낮은 통로, 상부 지름길을 이용한다. 주민 호송 길은 평지를 유지한다. 아래 다섯 이정표의 **두 번째 구간**에는 층별 점프·와이어 기믹을 배치하며 적은 착지 발판에 둔다. 사건 번호는 대사집 순서이며 내부 ID는 0부터 시작한다.

| 층 | 지정 이정표 | 가운데 구간 기믹 |
| --- | --- | --- |
| 하층 생산구 | 4. 사본을 남기는 이유 (ID3) | 이동 크레인·양방향 운송 벨트 |
| 하부 생활구 | 7. 감시하는 빛 (ID6) | 블레이드 반동 부유체·와이어 재연결 |
| 중층 행정구 | 10. 닫힌 보관소 (ID9) | 경고 후 닫히는 셔터 |
| 상층 거주구 | 16. 보류된 승진 (ID15) | 상승류·높은 이동 경로 |
| 최상층 통제구 | 19. 누구도 승인하지 않은 길 (ID18) | 무너지는 높은 발판·와이어 이동 |

모든 경로 위쪽은 와이어를 걸 수 있는 단단한 천장이다. 배경·조명·기믹은 실제 카메라와 인접 구간을 따라 표시하며, 완료한 곳으로 되돌아가도 기믹이 남는다. 연결 통로에서 배경이 끊기거나 이정표 전환 때 패럴랙스가 재시작하지 않도록 구성했다. 주민은 도입부·통로·목적지에 분산하고 선택 조사와 보급품도 진행 방향에 맞춰 옮겼다. 오토바이는 초반·마지막 추격전에만 사용하며 1회차 고대 문명 맵은 만들지 않는다.

독립 규칙·에셋·구문·보조 타입 검사 결과는 VALIDATION.txt 기준이다. 실제 Unity 6000.6.7f1의 임포트·충돌·렌더링·FPS·전체 완주는 미검증이다. `PLUGIN → 검사 → 연속 챕터 진행`, `PLUGIN → 검사 → 하층 확장 사건과 저장`의 Editor 점검 절차도 이 환경에서는 실행하지 않았다.

하층의 필수 48곳·선택 24곳과 대화·시간 배분은 [LOWER_DISTRICTS_KO.md](LOWER_DISTRICTS_KO.md)를 따른다. 지정 점프 구간은 하층에서 네 개의 208단위 발판 묶음을 이어 붙인다. 발판 사이 간격을 네 배로 벌리지 않으며 묶음 사이마다 안전 착지대를 둔다.

선택 현장을 건너뛰어도 구간 목표는 열리며, 완료한 이정표로 돌아와 미해결 선택 현장을 진행할 수 있다. 새 화자는 이름마다 한 개의 실체를 공유한다. 대화가 끝나도 현장에 남고, 다음 장소로 이동할 때는 이전 위치가 화면 밖에 있을 때만 재배치한다.

배경 메시를 128단위 묶음으로 나눠 긴 이정표 안에서도 Unity의 화면 밖 메시 제거가 작동하도록 했다. 콜라이더와 넓은 천장·바닥의 실제 영역은 유지한다. 이는 구현 변경이며 실측 FPS 상승 수치는 없다.
