# 3구간 현장 확장

20개 수사 현장을 각각 폭132에서432로 늘렸다. 기존 세 조사 목표를 서로 다른 구간에 배치하고 각 구간에 이름을 붙였다. 목표 수는 여전히 총60개다. 실제 완주 시간은 아직 측정하지 않았으며, 이 확장이 9시간 플레이를 보장하지 않는다.

- 현장마다144단위 구간3개. 일반 이동 현장은27개 기본 발판과9개 높은 지름길, 보호 현장은 연속 지면과 높은 지름길을 사용한다.
- 모든 구간의 위쪽은 와이어를 걸 수 있는 단단한 천장이다. 구간 사이에는 넓은 바닥을 연결해 긴 낙하 틈이 생기지 않게 했다.
- 생산구는 이동 크레인과 양방향 운송 벨트, 생활구는 블레이드 반동 부유체, 행정구는 경고 후 닫히는 셔터, 거주구는 상승류, 최상층은 무너지는 높은 발판을 배치했다.
- 적은 한 구간에 최대2명만 등장한다. 다음 구간으로 넘어가면 이전 구간 적을 정리하고 현재 구간 적만 활성화한다. 처치한 적은6비트 기록에 저장되어 재도전 때 되살아나지 않는다.
- 다음 구간 문은 앞 구간 조사 목표와 두 위협을 해결해야 열린다. 강제로 문을 넘어도 미완료 목표나 안전 거점을 얻지 않는다.
- 새 구간에 들어가면 안전 거점을 저장한다. 추락·재도전·재접속은 획득한 거점에서 재개하며, 거점 가까이에서E를 누르면 도시로 복귀할 수 있다. 긴 현장을 되돌아 걸어야만 중단할 수 있는 구조를 피했다.
- 보호 대상은 두 번째 구간에서 합류해 연속 지면을 따라 출구로 이동한다. 재도전 때는 확보한 거점 가까이에서 동행을 재개한다. 거점 복귀만으로 보호 목표를 완료하지 않는다.
- 전력 현장에는 각 구간의 보조 전력 패널이 있다. 앞에서 만든 입자가 사라져도 수광부 근처에서 다시 채취할 수 있다. 재채취는 레이저 목표를 대신 완료하지 않는다.
- 기존 완료 사건과 조사 목표는 보존한다. 예전 저장에 거점/처치 기록이 없으면 해당 현장 첫 입구로 안전하게 복귀한다. 이전 폭132 현장의 좌표를 새 현장 좌표로 그대로 사용하지 않는다.

저장 항목 `campaignCheckpoint`, `campaignDefeated`를 추가했고 새 게임의 삭제 목록에도 포함했다. 넓은 현장 천장 장식도 현재 방에 따라 렌더링을 생략한다.

순수 데이터 검사23,010개와 기존 전투·퀘스트 규칙3,211개를 통과했다. Unity2021 참조 DLL과 임시 API 이름 치환을 이용한 보조 타입 검사도 통과했다. 이 결과는 실제 Unity6000.6.7f1 실행, 충돌·렌더링·FPS·플레이 완주 검증을 대신하지 않는다.

Unity에서 `PLUGIN → 검사 → 확장 현장 3구간`을 실행하면 별도 임시 저장 프로필로 적 활성화, 거점 저장/복귀, 강제 진입 차단, 재도전, 전력 재채취와 보호 대상 복구를 검사한다. 자동 검사는 위치 이동과 일부 조사 목표를 직접 지정하므로 점프·와이어 구간의 사람 완주 검증은 따로 해야 한다. 결과는 프로젝트 `Diagnostics/field-smoke-last.txt`에 기록된다. 이 환경에서는 해당 Play Mode 검사를 실행하지 않았다.
