# v0.15.0 현장 경로 — 지상 통로와 지정 점프 구간

도시 5개 층의 수사 현장 20개는 각각 **폭 624단위·208단위씩 3구간**이다. 세 조사 목표를 구간별로 배치하며 총목표는 60개다. 실제 완주 시간은 측정하지 않았고, 넓어진 길이만으로9시간 플레이를 보장하지 않는다.

일반 도시와 일반 현장 구간은 끊기지 않은 지상 통로를 사용한다. 점프·와이어 이동은 아래 다섯 현장의 **두 번째 구간**에 따로 배치한다. 표의 사건 번호는 대사집 순서이며 내부 ID는0부터 시작한다.

| 층 | 지정 현장 | 가운데 구간 기믹 |
| --- | --- | --- |
| 하층 생산구 | 4. 사본을 남기는 이유 (ID3) | 이동 크레인·양방향 운송 벨트 |
| 하부 생활구 | 7. 포인트를 파는 골목 (ID6) | 블레이드 반동 부유체·와이어 재연결 |
| 중층 행정구 | 10. 닫힌 보관소 (ID9) | 경고 후 닫히는 셔터 |
| 상층 거주구 | 16. 보류된 승진 (ID15) | 상승류·높은 이동 경로 |
| 최상층 통제구 | 19. 누구도 승인하지 않은 길 (ID18) | 무너지는 높은 발판·와이어 이동 |

모든 구간 위쪽에는 와이어를 걸 수 있는 단단한 천장이 있다. 좌클릭은 충돌을 검사하는 즉시 직선 견인, 가운데 클릭은 기존 스윙이다. 지정 점프 구간의 실제 착지 여유와 숙련 경로는 Unity에서 완주 확인이 필요하다.

- 적은 현재 구간에 최대 2명만 활성화한다. 처치 기록 6비트를 저장하므로 제압한 적은 재도전 때 다시 생성하지 않는다.
- 다음 문은 앞 구간 조사 목표와 두 위협을 해결하면 열린다. 문을 강제로 넘어도 미완료 목표나 거점을 부여하지 않는다.
- 새 구간에 들어가면 안전 거점을 저장한다. 추락·재도전·재접속은 획득한 거점에서 재개하며, 거점 근처 E로 도시로 복귀할 수 있다.
- 보호 대상은 두 번째 구간에서 합류해 지상 통로로 출구까지 동행한다. 재도전은 확보 거점 가까이에서 동행을 재개하며 보호 목표를 자동 완료하지 않는다.
- 전력 현장은 각 구간의 보조 패널에서 입자를 재채취할 수 있다. 입자 소실 뒤에도 레이저 복구를 끝낼 수 있어야 하며, 재채취 자체가 목표를 대신 완료하지 않는다.
- 기존 완료 사건과 조사 목표를 보존한다. 거점/제압 기록이 없는 예전 저장은 안전한 입구에서 재개한다. 폭이 달랐던 현장의 좌표를 새 좌표로 그대로 사용하지 않는다.

현장 안내는 화면 밖 목표의 방향·거리를 표시하고, 뒤처진 주민과 다음 문을 막는 현재 위협을 우선 안내한다. 일반 구간에서는 통로와 조사 대상을 읽기 쉽게 유지한다. 오토바이는 이 현장들에 배치하지 않으며 초반·마지막 추격전에서만 사용한다.

생산소·주거/진료소·기록보관소·실내 정원·중앙 통제 홀의 배경은 층마다 다르다. 모두 닫힌 천장을 사용하며1회차 고대 문명 맵을 추가하지 않는다. 방별 장식 표시 생략과 저장 항목 `campaignCheckpoint`, `campaignDefeated`를 유지한다.

현재 실행한 독립 규칙·에셋·구문 검사는 VALIDATION.txt를 기준으로 한다. 이 결과와 보조 타입 검사는 실제 Unity6000.6.7f1의 충돌·렌더링·FPS·완주 검증을 대신하지 않는다.

Unity의 `PLUGIN → 검사 → 확장 현장 3구간`은 임시 저장 프로필로 구간 활성화·거점·재도전·전력 복구·주민 보호를 검사한다. 자동 위치/목표 지정은 사람이 점프·와이어 구간을 완주한 결과가 아니다. 이 환경에서는 해당 Play Mode 검사를 실행하지 않았다.
