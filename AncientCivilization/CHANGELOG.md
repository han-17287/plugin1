# v0.21.0 — 이동 시야·명중 피드백·하층 전력 복구

- 빠른 와이어 이탈 뒤 반대 방향을 눌러도 실제 공중 이동 방향을 따라 카메라 시야를 유지. 공중 속도에 따라 시야를 완만하게 넓히며 일반 지상·차량·보스 카메라 규칙은 유지.
- 대화·일시정지 전환에서 남은 수평 입력을 정리해 재개 첫 물리 갱신의 의도하지 않은 반대 가속을 방지.
- 실제 피해가 들어간 위치에만 짧은 흰색/금색 명중 표시. 베기와 몸의 방향을 맞추고 거의 수직인 공격의 방향 흔들림을 줄임.
- 레이저 준비 표시는 현재 입자량과 충전 상태를 읽고 화면 안에 배치. 입자가 없으면 우클릭 수집을 안내하며 발사 뒤 남는 준비 완료 팝업 제거. 대화·장면 전환 시 전투 표시 정리.
- 추격 장애물을 실제로 뛰어넘었을 때만 연속 회피 기록. 실제 피해 후 장애물별 점프 타이밍 안내, 승선 실패와 지붕 이탈 뒤 복귀·재승선 안내 및 고리 점멸 추가. 피해량·승선 시간·보스 전투 순서 유지.
- 하층 작업장 전력을 복구하면 연결 배선·조명·수광부가 켜지고 저장 후에도 유지. 복구 파동은 처음 켤 때만 재생하며 장식은 충돌 없이 실제 카메라 주변에서 표시. 현장 안내에 작은 어두운 배경 추가.
- 독립 규칙 검사와 실제 오브젝트용 Unity 검사 항목을 확장. 이 환경에서 Unity 실행·조작·FPS는 확인하지 않았으며 별도 실기 확인 필요.
