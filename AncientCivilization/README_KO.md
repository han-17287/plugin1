# PLUGIN — ANCIENT CIVILIZATION v0.10.0

Unity **6000.6.7f1**용 2D 도트 액션 어드벤처 소스 프로젝트입니다. 기존 v0.7을 바탕으로 도시 다섯 층, 입자 장비, 수사와 두 번의 추격전을 이어 만드는 프로토타입입니다. 실행 EXE가 아닙니다.

## 열기

1. ZIP을 새 폴더에 압축 해제합니다.
2. Unity Hub → Add project from disk → `AncientCivilization` 폴더 → **6000.6.7f1**으로 엽니다.
3. `Assets/Scenes/Main.unity`를 열고 Play → 시작하기 또는 이어하기를 선택합니다.
4. 권장 Game 뷰는 16:9 / 1920×1080입니다. 월드는 실행 중 생성하므로 Play 전 씬은 비어 보일 수 있습니다.

외부 서버·유료 에셋·추가 패키지는 필요하지 않습니다. 한국어 픽셀 글꼴 Neo둥근모의 라이선스는 `Assets/Resources/Fonts/LICENSE.txt`에 있습니다. 고그래픽 블레이드/와이어 시안 원본은 ZIP의 `ArtReferences`에 보관했습니다.

## 이번 변경

- 고정 배경 장식을 텍스처·표시 순서·층별 메시로 묶고, 현재 층의 묶음만 표시합니다. 지형 충돌과 움직이는 장치는 별도로 유지합니다.
- 투척물 64개, 타격 링 24개, 적 베기 궤적 12개를 미리 만들어 재사용합니다. 살아 있는 적 투척물을 재활용 때문에 다른 위치로 옮기지 않습니다.
- 직선 와이어 중심은 점 두 개로 표시합니다. 이중 나선은 길이에 따른 샘플 수와 각도 점화식을 사용하고, 재사용 버퍼로 한 번에 전달합니다. 흐르는 와이어 입자도 단일 메시로 표시합니다. 시야 밖 앵커 검색과 반복 지면 검사를 줄였습니다.
- F8 프레임 목표, F9 실제 프레임 시간·P95·GC·묶음 수, F10 최근 240프레임 CSV 기록을 추가했습니다. 기본 목표는 240이며 실제 240FPS 보장은 아닙니다.
- 보스는 공격 후 금색 빈틈에 멈춥니다. 빈틈 중 피해는 기본의 1.25배, 그 밖에는 0.6배입니다. 보스 와이어 저항과 전조 유지 규칙도 적용합니다.
- 피해 숫자, 정밀 투척물 파괴 보너스, 레이저 준비 완료 안내, 보스전 전체 구역 카메라를 추가했습니다.
- 보스 직전 재도전 지점, 정비 메뉴의 즉시 재도전, 저장 후 재개를 정리했습니다.
- 높은 이동 경로에 층당 보급품 두 개, 총 열 개를 배치했습니다. 한 번만 보상받으며 수집 현황을 저장합니다.
- Tab 순찰 기록에서 발견한 단서·층별 보급품·조작을 확인합니다. 미발견 단서 본문은 가립니다.
- 생활구 전력 복구, 행정구 원본 대조, 거주구 경비 단말의 선택 수사 세 개를 추가했습니다. 각 임무의 보상은 한 번만 지급합니다.
- 회장실의 노트/회수 계획 → 1분 작전 개시 → 최상층에서 최하층까지 마지막 트럭 추격 → 옛 동료 지원 사격 → 코어 폭주·추락 종료를 연결했습니다. 고대 문명 플레이 맵은 만들지 않았습니다.

실제 Unity Play Mode·빌드·기기 FPS는 이 환경에서 검증하지 못했습니다. `VALIDATION.txt`는 에셋/문법 검사와 독립 규칙 검사, 보조 타입 검사의 범위를 구분합니다. **9시간은 완성판의 제작 목표이며 현재 구현 분량이 아닙니다.**

## 플레이 흐름

1. 하층 순찰에서 이동·점프·Ctrl 달리기를 확인합니다.
2. 와이어를 걸고 주차된 오토바이에 E로 탑승합니다.
3. 휠 위 공격 모드에서 훈련 물체를 베고, 나온 입자를 우클릭으로 모아 레이저 훈련을 마칩니다.
4. 상층 출신 용의자가 하층의 에너지 코어를 트럭에 싣고 도주합니다. 추격 후 코어 세 개를 회수하면 화물 수호기 미니 보스가 등장합니다.
5. 검거 뒤 시민 포인트와 첫 윗층 통행 권한을 받습니다. 승진은 자동 이동이 아닙니다. 동쪽의 실제 엘리베이터에서 E로 목적 층을 고릅니다.
6. 생활구 → 행정구 → 거주구는 이동 기믹·범죄자·패턴 보스를 돌파해 다음 권한을 얻습니다. 입구 엘리베이터로 해금된 층을 왕복합니다.
7. 최상층은 포인트로 열리지 않습니다. 거주구 보스 뒤 동쪽 외벽 샛길에서 E로 침입합니다.
8. 최상층 저격수와 싸운 뒤 옛 친구임을 알아보고 헤어집니다. 동쪽 회장실 책상에서 E로 노트와 작전 계획을 읽습니다.
9. 대화를 읽는 동안 작전 시간은 흐르지 않습니다. 회장실에서 E로 먼저 추격을 시작하거나, 60초 후 자동으로 이어집니다.
10. 마지막 하강 도로의 배치된 오토바이와 와이어로 트럭을 따라갑니다. 트럭이 끝에서 멈추면 지붕에 올라타세요. 지원 사격과 코어 폭주 연출 뒤 1회차 임시 종료 화면을 표시합니다.

초반과 마지막 외에 추격전을 추가하지 않았습니다. 현재는 짧은 맵 블록아웃과 사건 연결을 구현한 단계입니다. 장편 수사·인물 관계·구역별 다수의 새 맵은 후속 제작 범위이며 `STORY_KO.md`에 설계와 구현을 구분했습니다.

## 입자 장비

좌클릭을 0.22초 미만에 놓으면 8프레임 블레이드 베기가 나갑니다. 실제 타격은 0.15초 지점이며, 다음 베기를 짧게 미리 입력할 수 있습니다. 벽은 근접 공격과 레이저를 막습니다. 공중 부유체·투척물·드론을 베면 가로 속도를 유지하면서 한 번 튀어 오릅니다.

0.22초 이상 유지하면 조준하고, 총 0.85초 뒤 준비가 끝납니다. 금색 조준선에서 버튼을 놓으면 최대 24유닛의 흰 중심광/푸른 외곽광 레이저가 즉시 나타납니다. 날아가는 입자탄이 아닙니다. 0.22~0.85초에 놓으면 소모 없이 취소합니다. 모드 전환·메뉴·대화·포커스 상실도 준비 입력을 취소합니다.

우클릭은 온전한 적 투척물을 흡수하지 않습니다. 블레이드 등으로 부순 물체의 입자를 최대 7유닛에서 수집합니다. 저장 상한은 100이며 40 미만 1단계, 40 이상 2단계, 80 이상 3단계입니다. 3단계와 100%는 다릅니다. 캡처 세 번이 풀 충전을 뜻하지 않습니다. 피해는 `30 + 저장량 × 1.6`이며 저장량이 많을수록 빔이 굵어집니다.

와이어는 곧은 중심선과 반대 위상으로 회전하는 두 푸른 DNA 나선입니다. 적에게 좌클릭하면 명중·견인·충돌 피해와 약한 밀림을 줍니다. 해당 대상의 접촉 피해만 견인 중/충돌 직후 보호하며, 다른 적과 물체 공격은 보호하지 않습니다. 보스 피해/밀림은 작고 보스 전조를 취소하지 않습니다.

## 저장과 검증

퀘스트·훈련·코어·포인트·강화·현재 층·해결 구역·보스 재도전 지점·탐색 보급품·선택 수사·마지막 추격 구간을 저장합니다. 차량 위치/체력과 현재 저장 입자는 앱 재실행 후 유지하지 않습니다. 사망하면 차량 배치와 체력을 복구하고 저장 입자를 초기화합니다. 이미 회수한 코어와 수사 진행은 유지합니다.

새 게임은 진행을 지우며 소리·효과·프레임 목표 설정은 유지합니다. v0.7의 원래 코어/보스 키 대신 별도 스토리 키를 쓰므로 오래된 업그레이드는 이어받을 수 있습니다.

- `python Tools/validate_project.py`: PNG·투명 여백·분할·스프라이트 특징·메타 GUID·씬 참조·C# 문법 검사. C# 구문 검사에는 tree-sitter 패키지가 필요합니다.
- `dotnet run --project Tools/RulesChecks.csproj`: .NET 8 SDK로 순수 전투·저장·권한·맵·와이어 수학 규칙을 검사합니다. 게임 실행에는 .NET SDK가 필요하지 않습니다.
- `PLAYTEST_KO.md`: Unity에서 직접 확인해야 할 조작·진행·저장·성능 절차입니다.
- `PERFORMANCE_KO.md`: F9/F10 지표의 해석과 같은 기기에서 비교하는 방법입니다.

에셋/독립 규칙/보조 참조 DLL 검사는 실제 Unity 6000.6.7f1 임포트, 셰이더, Play Mode, 애니메이션 조작감과 플레이어 빌드를 대신하지 않습니다.
