# PLUGIN — ANCIENT CIVILIZATION v0.20.1

한국인 하층 치안경찰 **백 경위**의 도시 수사를 플레이하는 Unity **6000.6.7f1**용 2D 도트 액션 소스 프로젝트입니다. 설정상 본명은 내부 데이터에 유지하며 초반 화면과 대화에서는 백 경위로 부릅니다.

v0.20.1은 고해상도 화면에서 트럭 승선 고리의 중심과 클릭 판정을 맞추는 패치입니다. 승선 고리에는 최소 0.5단위 선택 반경을 적용하며, 실제 4K 화면의 가장자리 클릭은 실기 확인 대상입니다.

와이어 모드의 **좌클릭은 충돌을 검사하는 즉시 직선 견인**, 가운데 클릭은 기존 스윙입니다. 공격 모드에서는 짧은 좌클릭으로 세로 → 가로 → 사선의 전용 48프레임 연격, 길게 눌러 조준한 뒤 놓으면 굵은 연속 레이저를 사용합니다. 파괴된 물체에서 나온 파란 입자는 두 모드에서 우클릭으로 모읍니다.

일반 적을 경직시키면 그동안 접촉 피해가 멈추고 HUD에 「경직 · 공격」을 표시합니다. 일반 적의 새 공격 준비는 화면 안이나 가까운 바깥에서 시작하며, 이미 진행 중인 공격과 보스 패턴은 계속됩니다. 입자는 긴 프레임 뒤에도 플레이어를 지나쳐 왕복하지 않도록 수집 이동을 제한하고 도착 즉시 모읍니다.

대화는 인게임 캐릭터 곁의 작은 말풍선으로 표시합니다. 한국어가 한 글자씩 나오고 긴 대사는 페이지로 나눕니다. 통신관의 무전에는 무전기 아이콘이 붙습니다. 캐릭터를 가리는 큰 초상화나 화면 전체를 어둡게 만드는 대화 덮개는 사용하지 않습니다.

검거 후 하층 수사로는 무전 지시로 바로 열립니다. 이후 층은 담당자에게 **한 번 임무를 듣고 긴 연속 맵의 동쪽 목적지까지 이동**합니다. 도입부 128단위, 수사 이정표 네 곳(각 624), 연결 통로 세 곳(각 64), 목적지 96을 합쳐 층당 2,912단위입니다. 각 이정표의 세 목표와 적 여섯 명을 해결하고 동쪽 끝에 도달하면 다음으로 이어집니다. 위치·속도·와이어를 초기화하거나 소장에게 되돌아가 보고하지 않습니다. 결과·주민 반응·단서는 움직이는 동안 순차 무전으로 전달합니다.

일반 경로는 지상 통로이며, 지정된 다섯 이정표의 두 번째 구간에 층별 점프·와이어 기믹을 유지합니다. 구간별 적 최대 2명, 거점 저장·재도전과 입자 재채취를 유지합니다. 주민은 도입부·연결 통로·목적지에서 선택적으로 대화할 수 있습니다. 뒤처진 보호 대상은 확보한 지상 통로에서만 빠르게 따라오며, 입자가 빈 전력 수광부는 재채취 패널로 안내합니다. 자세한 경로는 [FIELD_EXPANSION_KO.md](FIELD_EXPANSION_KO.md)에 있습니다.

오토바이는 초반·마지막 추격전에서만 배치하고 구간 종료 때 정리합니다. 초반 보스전은 자동주행·Space 점프·접근 시 와이어 승선, 최종 추격전은 기존 수동 주행을 사용합니다. 메뉴는 보관한 블레이드 시안과 수정된 주인공·대치·베기 그림, 도시 배경을 포함한 9종 중 실행별로 하나를 선택합니다. 부드러운 색 변화·빛 이동과 한국어 글자 대비를 적용하며, 인게임 도트 디자인과 보관한 아트 원본은 유지합니다. 메뉴로 돌아올 때는 같은 실행의 배경을 유지합니다. 메인 화면 전 Hwasan Games → HG 로고는 Space/Esc로 건너뛸 수 있습니다.

저격수 4페이즈와 비서실장 시계 최종보스를 유지합니다. 비서실장은1회차에서 1페이즈만 싸운 뒤 살아서 퇴장하며2회차에 돌아옵니다. 친구 공개와 고대 문명 맵도2회차 범위입니다. 실제 Unity 실행·빌드·FPS·전체 완주 시간은 아직 확인하지 못했습니다.

## 실행

ZIP을 새 폴더에 풀고 Unity Hub에서 `AncientCivilization` 폴더를 6000.6.7f1으로 여세요. `Assets/Scenes/Main.unity` → Play → 시작하기를 선택합니다. 월드는 실행 중 생성하며 Play 전 씬은 비어 보일 수 있습니다. 권장 화면은 16:9 / 1920×1080입니다.

새 생산구 도입과 새로 구성한 조사 순서를 처음부터 보려면 **새 게임**으로 시작하세요. v0.10.0 이전 세이브는 진행·권한을 보존하며 신규 현장에 들어갈 수 있지만, 이미 얻은 통행 권한을 새 조사로 다시 잠그지 않습니다. 따라서 새 진행의 조사→보스 순서를 확인하려면 신규 세이브가 필요합니다.

## 이번에 실제 추가한 내용

v0.20.0은 하층 개선본입니다. 움직이는 트럭에 도착해도 풀리지 않던 와이어, 긴 프레임에 빠지던 베기 피해와 추격 카메라를 수정했습니다. 전용 작업자·운송대장 도트, 빈 트럭과 분리되는 코어 세 개, 움직이는 공장 설비를 추가했습니다. 검거 뒤 무전 지시로 수사로를 바로 이어 가며, 와이어 고리 빛은 화면 주변64개 풀로 표시합니다. 생산장 훈련·선택 스윙 경로·두 차례 차량/갑판 전투와 마지막 회수 컷신을 유지하며, 이동과 다음 행동을 가리던 HUD를 줄였습니다. 자세한 내역은 CHANGELOG.md에 있습니다.

- 생산장까지362단위의 쉬운 재고 점검 경로를 새로 만들었습니다. 교대 통로·벨트·검수 회랑·재고 관리실과 낮은 점프 화물·완만한 경사로·선택 와이어 발판을 사용합니다. 지상 경로는 안전하게 이어집니다.
- 재고 단말 E로120기/117기 불일치를 보고하면, 세 번째 말풍선이 나오던 도중 옆 격벽이 터지고 코어 적재 트럭이 도주합니다.
- 초반 보스전은 별도1,600단위 수송 터널입니다. 자동 전진 중 Space로 잔재·폭탄을 피하고, 일정 시간 뒤 적 공격이 멈추며 트럭이 접근합니다. 점등된 높은 고리에 좌클릭 와이어를 걸어 지붕으로 올라갑니다.
- 운송대장 체력65%·30%에서 급가속으로 밀려나 자동주행 오토바이에 돌아옵니다. 두 번의 갑판 전투 뒤 세 번째 탑승은 회수 컷신입니다. 노란 블레이드로 코어 짐칸을 안전 분리 → 높은 백덤블링 → 굵은 입자 레이저 → 트럭 폭파 순서이며 운송대장은 생존 검거합니다.
- 사고로 승선에 실패해도 접근 기회가 유지됩니다. 재도전·재접속은 현재 추격 회차를 복구합니다. 검거 뒤 포인트를 한 번 지급하고 인계 암전 뒤 동부 운송로로 이동하며, 이후 층별 연속 수사와 실제 엘리베이터 진행을 잇습니다.
- [생산구 구조도](ProductionMapOverview.svg)는 좌표 설계도입니다. 컷신은 현재 게임 스프라이트·카메라·광선으로 연출하며 고화질 영상 파일과는 별개입니다.

- 기존 보스 승리 뒤 남은 투척물 정리를 유지합니다. 일반 범죄자 전투와 비서실장 생존 퇴장은 유지합니다.

- 움직이는 와이어 앵커의 실제 클릭 지점을 보존하고, 파괴된 적을 향한 빈 견인을 해제합니다.
- 레이저는 발사 방향을 유지하며 팔을 따라가고, 같은 대상은 한 발에 한 번만 맞습니다. 모드 전환·피격·대화·포커스 상실 때 발사를 정리합니다.
- 착지 직전 짧게 누른 점프를 짧은 점프로 보존하고, 물리 갱신에서 착지와 경사면·움직이는 발판을 확인합니다.
- 양방향 바닥 공격의 예고를 실제 위험 높이에 맞추고, 비서실장의 각 시계 범위 공격이 연속 피해로 중첩되지 않게 했습니다.
- 새 거점은 체력 최대20, 일회용 높은 샛길 보급은 체력 최대18·TECH4·파란 입자24를 제공합니다. 입자는 우클릭으로 수집하며 거점 반복 이용으로 회복을 쌓을 수 없습니다.

- 초반 주인공 화면 표시와 대화 호칭은 백 경위로 통일합니다. 설정상 본명은 내부 데이터에 보존합니다.
- 도시 다섯 층을 **층당 하나의 연속 챕터**로 연결했습니다. 주요 사건 20개는 이제 경로상의 수사 이정표이며, 각각 폭 624단위·3구간·세 목표·확보 자료를 사용합니다. 사건 사이 64단위 통로도 실제 이동합니다.
- 주민 **25명**을 배치했습니다. E로 대화하며 캐릭터 말풍선에서 한국어가 한 글자씩 표시됩니다. 사건 전후 대사와 인물별 도트 외형을 넣었습니다. 구조 대상 네 명은 이동 거리에 맞춘 걷기 동작을 사용합니다.
- 조사·증언, 블레이드 봉인 해제, 주민 구조/동행, 입자 레이저 전력 복구로 사건 방식을 구분했습니다.
- 새 게임은 하층 조사 네 사건을 마친 뒤 첫 윗층으로 갑니다. 윗층은 조사 뒤 보스전, 보스 제압 뒤 다음 층 권한을 얻습니다. 승진으로 자동 이동하지 않습니다.
- 최상층은 첫 세 이정표 → 실제 연결 다리의 저격수 4페이즈 대치 → 마지막 자료 이정표 → 별도 비서실장 전투장 → 회장실 노트 → 마지막 추격으로 이어집니다. 비서실장은 1페이즈 뒤 살아서 퇴장합니다.
- 최상층에서 저격수가 옛 친구임을 알아보는 대사와 기록을 제거했습니다. 1회차에서는 포인트 동결·출입 거부라는 같은 처지만 확인합니다.
- 조커는 주민 다섯 명의 대화에서 드물게 언급합니다. 저격수의 정체와 친구 관계를 직접 설명하지 않습니다. 친구 공개는 2회차로 남깁니다.
- Tab → 사건/주민에서 완료 사건의 확보 자료와 **실제 들은** 주민 대화를 다시 읽을 수 있습니다. 모르는 내용은 가립니다.
- 이정표별 목표·거점·제압 기록을 따로 저장해 층 왕복과 재접속 뒤에도 부분 진행을 보존합니다. 안전 단말 E는 현재 자리에서 저장합니다. 낙하·재도전·저장 복원은 확보한 거점으로 회수할 수 있습니다. 기존 완료 기록과 구버전 진행은 저장 버전 2로 이관합니다.
- 배경·조명·이동 기믹은 실제 카메라 위치와 인접 구간을 기준으로 표시합니다. 완료한 구간으로 돌아가도 기믹이 남고, 이정표 전환 때 패럴랙스를 다시 시작하지 않습니다. 기존 와이어·풀·FPS 설정은 유지합니다.
- 회장실 창밖의 트럭 탑승을 간단한 도트 인물 이동으로 보완했습니다. 고대 문명 플레이 맵은 만들지 않았습니다.

**현재 버전을 9시간·90% 완성으로 표시하지 않습니다.** 기존보다 사건과 주민 상호작용을 크게 확장한 플레이용 블록아웃이며, 목표 9시간에 필요한 콘텐츠·전용 아트·전체 완주와 실제 Unity 빌드 검증이 남아 있습니다. 구현 수량은 플레이타임이나 완성 비율이 아닙니다. 정확한 범위는 COMPLETION_KO.md에 있습니다.

## 주요 진행

| 층 | 새 사건 | 담당자 |
| --- | --- | --- |
| 하층 생산구 | 야간 배정 → 작업장 전력 → 작업자 구조 → 사본 보관 | 검거 뒤 순찰소장 |
| 하부 생활구 | 진료소 → 배달원 → 위조 심사 → 수령처 원장 | 간호사 윤서 |
| 중층 행정구 | 신고 연결 → 보관소 → 원본 대조 → 직원 보호 | 기록원 다인 |
| 상층 거주구 | 전력 분기 → 재배치 계약 → 이송 예정자 → 승진 보류 | 설비사 지완 |
| 최상층 통제구 | 감시 회선 → 삭제 신청 → 미승인 통로 → 대치 후 회장실 자료 | 정비 노동자 노을 / 대치 뒤 보관실 관리인 유담 |

초반 훈련·추격·검거 뒤 생산구의 순찰소장에게 한 번 임무를 받으면 동쪽 수사로가 열립니다. 다음 층에서도 담당자에게 한 번 브리핑을 듣고 그 층을 끝까지 진행합니다. 세 목표·구간별 위협은 해결해야 하지만, 사건마다 별도 방으로 들어가거나 복귀 대화를 반복하지 않습니다. 안전 단말 E는 그 자리에서 저장하고, 동쪽 이정표 완료는 자동으로 처리합니다.

층 입구와 동쪽 목적지의 실제 엘리베이터로 해금된 층을 왕복합니다. 끝낸 층으로 돌아가면 동쪽 출구, 진행 중인 층은 입구에 도착하며 확보한 이정표 진행은 남습니다. 최상층은 거주구 동쪽 외벽 샛길로 침입합니다. 선택 주민 대화와 일곱 자료 대조 선택은 경로에서 계속 이용할 수 있습니다.

초반과 마지막에만 추격전이 있습니다. 중간 층은 수사·이동·범죄자·패턴 보스 중심입니다. 마지막에는 정체를 설명하지 않는 지원 사격이 백명을 구하고, 같은 총탄이 코어 보호부를 파손해 폭주·추락으로 이어집니다.

Shift로 전환하지 않으며 오토바이를 소환하지 않습니다. 차량은 초반·마지막 추격전 안에만 배치됩니다. 좌클릭 0.22초 미만은 베기, 총 0.85초부터 레이저 준비 완료, 그 사이는 취소입니다. 레이저는 최대 24단위의 전체 빔이 즉시 나타나 0.38초간 유지됩니다. 저장량에 따라 본체 폭 1–2.2단위, 흰 중심 0.28–0.7단위, 푸른 외곽 빛 2.1–4단위로 표시합니다. 본체 폭으로 벽을 검사하고 그 폭에 맞춰 적·물체·목표를 판정합니다. 방향과 위력은 발사 순간 고정하고 유지 시간에는 빔이 현재 팔 끝을 따라가며 벽을 다시 검사합니다. 같은 대상은 한 발에 한 번만 맞습니다. 외곽 빛은 피해 폭이 아니며, 발사구가 막혀 유효한 빔을 만들 수 없으면 입자를 소비하지 않습니다.
