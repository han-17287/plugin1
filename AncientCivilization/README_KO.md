# PLUGIN — ANCIENT CIVILIZATION v0.26.0

한국인 하층 치안경찰 **백 경위**가 코어 절도와 지워진 배정 기록을 수사하는 Unity **6000.6.7f1**용 2D 도트 액션 소스 프로젝트입니다.

이번 버전은 평지 위주였던 하층 지형을 바꿉니다. 일반 구간 16곳에 하역 단차·배관 아래길·지붕·폐차 더미를 배치하고, 그중 네 곳에는 위로 올라 건너 내려오는 수직 정비실을 넣었습니다. 호송 구간 6곳은 주민이 따라올 수 있는 평지를 유지합니다. 기존 대화·수사·보스 진행은 이어집니다. **플레이 시간과 실제 조작감은 아직 Unity 완주로 검증하지 않았습니다.** [지형 변경과 확인할 점](MAP_REDESIGN_KO.md)

## 실행

1. ZIP을 풀고 `AncientCivilization` 폴더를 Unity Hub에서 프로젝트로 추가합니다. `ArtReferences`는 프로젝트 옆에 보관합니다.
2. Unity **6000.6.7f1**로 열고 임포트가 끝날 때까지 기다립니다.
3. `Assets/Scenes/Main.unity`를 연 뒤 Play를 누릅니다. 월드와 주민·전투 장치는 실행 중 생성됩니다.
4. 처음부터 튜토리얼과 추격을 확인하려면 메인 화면의 새 게임을 사용합니다. 이어하기는 기존 수사·보스 기록을 복구합니다.

이 ZIP은 소스 프로젝트입니다. 실행 EXE나 WebGL 플레이어 빌드는 포함하지 않습니다. 현재 환경에는 Unity Editor가 없어 네이티브 임포트·Play·빌드를 실행하지 못했습니다.

## 두 구역의 진행

**생산구:** 기본 조작 훈련 → 코어 재고 120기/117기 불일치 보고 → 벽을 뚫고 도주하는 코어 운송 트럭 → 자동주행 오토바이와 트럭 갑판 전투 두 차례 → 세 번째 탑승의 짐칸 분리·백덤블링·레이저 컷신 → 운송대장 생존 검거. 코어는 트럭 폭파 전에 확보합니다. 검거 뒤에는 이미 받은 무전 지시로 동쪽 수사로가 열립니다.

**생산구 수사로:** 야간 출고 장부 → 주민 전력 복구 → 재하 구조 → 수정 전 기록 사본 보관. 작업장·연결 통로·목적지는 한 맵이며, 별도 임무 방에 들어가거나 소장에게 돌아가는 보고 루프가 없습니다. 확보한 통로에서는 보호 대상이 빠르게 따라옵니다.

**생활부:** 코어를 든 도둑이 지나갔다는 길을 따라 주거 골목 → 폐차장 → 감시 외벽 → 밀매 창고로 이동합니다. 차량 추격은 없습니다. 상자·자동차의 와이어 투척, 탐조등 엄폐, 경비 로봇, 천장 와이어·블레이드 반동 구간을 거쳐 조직원을 먼저 제압하고 거대 로봇 두목과 싸웁니다. 제압 뒤 기계 잔해와 조종사가 남고, 진술과 장부는 다음 행정구 수사로 이어집니다.

일반 경로 16곳에는 오르내리는 구조물과 낮은 배관로, 상부 정비 지름길을 배치했습니다. 생산구 `교체 승인실`과 생활부 `경비 로봇 구역`에 발판·중간 착지대·상부 접속대와 숙련자 경로를 묶었습니다. 생산구는 이동 크레인, 생활부는 공중 부유체 반동을 사용합니다. [경로 구조도](LowerDistrictOverview.svg) · [도트 배경 소스 미리보기](LowerDistrictWalls.png)

현장별로 브리핑·행동 성공·결과 확인을 따로 저장합니다. 장치를 해결하거나 경비를 제압한 뒤 결과 대화 전에 종료해도 행동을 반복하지 않습니다. 필수 현장을 확인하면 길이 열리고, 선택 현장은 지나쳐도 됩니다. 완료한 구간에 돌아와 선택 현장을 해결하거나 주민과 다시 대화할 수 있습니다. 구버전에서 수사를 끝냈어도 보스가 남아 있다면 전투 입구 앞에서 이어집니다.

승진은 출입 권한을 엽니다. 실제 층 이동은 입구·동쪽 목적지의 엘리베이터에서 합니다. 생활부에는 보스전 직전에도 엘리베이터가 있습니다. 생활부 수사를 끝내고 보스를 남겨 둔 채 다른 층에 다녀오면 이 터미널로 돌아옵니다. 고대 문명 플레이 구역과 저격수의 친구 정체 공개는 2회차에 남겨 두었습니다.

대시·오토바이 소환·Shift 전환·F 직접 흡수는 없습니다. 오토바이는 초반과 마지막 추격전에만 배치됩니다. 생활부 투척은 한 바퀴 회전하는 동안 마우스로 조준하면 자동 발사합니다. 로봇이 흡입할 때 천장·벽에 와이어를 걸면 일반 스윙 자동 해제 없이 버티며, 점프나 모드 전환으로 풀 수 있습니다.

좌클릭 0.22초 미만은 베기, 총 0.85초부터 레이저 준비 완료이며 그 사이는 취소입니다. 레이저는 최대 24단위의 굵은 빔이 즉시 이어져 0.38초간 유지됩니다. 발사 순간 방향과 위력을 고정하고 팔의 현재 위치에서 벽을 다시 검사합니다. 같은 대상은 한 발에 한 번만 맞으며, 유효한 빔을 만들 수 없을 정도로 발사구가 막히면 입자를 소비하지 않습니다.

입자 저장 상한은 100, 단계 상한은 3입니다. 40/80에서 단계가 오르고 실제 저장량 100에서 완충됩니다. 수집 세 번이 풀 충전을 뜻하지 않습니다. 우클릭으로 온전한 투척물을 흡수하지 않으며, 먼저 블레이드로 부숩니다. 로봇의 총알·포탄은 파괴 불가, 미사일은 파괴 가능합니다. 배리어는 풀게이지 레이저 1발·물체 투척 10회·근접 7회로 깨지고, 부분 게이지 레이저와 혼합 공격은 누적됩니다.

## 대화·기록·저장

대화는 캐릭터 곁의 작은 말풍선에서 한국어가 한 글자씩 표시됩니다. 긴 대사는 페이지로 나누며, 사령관·통신관은 무전기 아이콘으로 말합니다. 현장 결과는 이동 중 순차 무전으로 전달합니다. 초반에는 본명 대신 백 경위로 부릅니다.

`Tab → 사건/주민 → 하층 현장 증언`에서 실제로 들은 대화와 확인한 결과를 다시 읽습니다. 미방문 현장의 내용을 미리 공개하지 않습니다. 같은 주민은 대화 뒤 그 자리에 남고, 다음 대화 위치로 옮길 때는 이전 위치가 화면 밖인지 확인합니다.

`Tab → 구역/탐색`은 생산구·생활부의 실제 플레이·대화·보스 시간과 재도전 수를 기록합니다. 메뉴·기록 창·포커스 이탈·엘리베이터 이동 시간은 제외합니다. 창을 켜고 자리를 비운 시간은 포함되므로 메뉴를 열어 주세요. 첫 완료 뒤 재방문은 기록을 늘리지 않습니다. 구버전 저장은 이번 버전 이후의 부분 기록으로 표시합니다.

## 다음 층과 보관 자료

행정구·상층 거주구·최상층의 기존 연속 경로는 각 2,912단위로 유지합니다. 최상층은 저격수 4페이즈 → 자료 이정표 → 비서실장 시계 보스 1페이즈 → 빈 회장실 → 마지막 추격으로 이어집니다. 저격수와는 같은 처지만 확인하며, 비서실장은 살아서 퇴장합니다.

고그래픽 블레이드·와이어 시안 원본은 ZIP의 `ArtReferences`에 보관합니다. 별도 [블레이드 콘셉트 MP4](https://raw.githubusercontent.com/han-17287/plugin1/ancient-civilization-prototype/Video/Officer_Blade_Concept_60fps.mp4)는 12초·1080p·60fps의 정지 이미지 기반 애니매틱입니다. 게임 플레이 녹화가 아니며 Unity 소스 ZIP과 별도로 제공합니다.
