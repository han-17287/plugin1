# PLUGIN — Ancient Civilization · Chapter 0 v0.2

Unity **6000.6.7f1**용 2D 액션 어드벤처 소스 프로젝트입니다. EXE가 아닙니다.
기존 Rift of the Sky와 별도 프로젝트이며, 시안 분위기를 반영한 실제 PNG 그래픽을 포함합니다.

## 실행
1. 새 ZIP을 별도 폴더에 압축 해제합니다. 이전 버전 위에 덮어쓰지 않는 편이 안전합니다.
2. Unity Hub → Add project from disk → `AncientCivilization` 선택 → Unity 6000.6.7f1으로 엽니다.
3. `Assets/Scenes/Main.unity`를 열고 Play → Game 뷰를 클릭합니다. 권장 화면비는 16:9입니다.
4. 높은 옥상의 코어 3개를 회수하고 동쪽으로 이동합니다. 코어로 기술을 해금하고 수호자를 쓰러뜨려 게이트에 도착하세요.

시작 씬의 런타임 부트스트랩이 월드와 캐릭터를 생성합니다. Play 전 씬이 비어 보이는 것은 정상입니다.
외부 서버나 유료 에셋이 필요하지 않습니다. 기본 내장 렌더 파이프라인을 사용합니다.
`Packages/manifest.json`에는 Unity 기본 Physics2D / IMGUI / Audio 모듈만 들어 있습니다.

## 조작
| 입력 | 동작 |
| --- | --- |
| A / D 또는 좌우 방향키 | 이동 |
| Space | 점프 / 공중 발걸음 해금 후 두 번째 점프 |
| Ctrl 짧게 | 달리기 토글 |
| Ctrl 0.45초 이상 | 오토바이 생성·탑승 (해금 필요, 입자 30) |
| Shift | 무적 시간이 있는 짧은 대시, 재사용 0.8초 |
| J 또는 마우스 왼쪽 | 기계팔 3연타, 세 번째 공격 범위·피해 증가 |
| F 유지 | 원거리 입자 흡수, 이동속도 감소 없음 |
| Q | 입자 25로 전방 범위 방출 공격 |
| E 또는 마우스 오른쪽 | 커서 가까운 앵커로 즉시 가속하는 자동 와이어 이동 |
| X | 탑승 중 오토바이 자폭, 범위 피해와 도약 |
| K 또는 Esc | 일시정지·업그레이드 화면 |
| H | 하단 조작 도움말 표시/숨기기 |

### 흡수와 전투
- 물리 근접 공격은 흡수할 수 없습니다. 주황색 예고를 보고 대시·점프·거리 벌리기로 피합니다.
- 에너지탄은 F로 흡수합니다. 금속 투척물도 파괴하며 흡수합니다.
- 흡수 시작 후 0.18초 안에 흡수하면 PERFECT 보너스 입자를 얻습니다. 계속 누르고 있어도 일반 흡수는 가능합니다.
- 흡수 범위는 7 유닛이고 벽을 통과하지 않습니다. 공격하지 않고 흡수만 해서는 적이 죽지 않습니다.
- J 3연타로 근접 공격하거나, Q의 범위 방출·오토바이 폭발로 입자를 공격에 활용하세요.
- 일반 이동/달리기/오토바이 속도는 5/9/15입니다. 흡수 중에도 같은 속도를 유지합니다.

### 이동과 오토바이
- 와이어는 20 유닛 이내의 보이는 청록색 앵커에 연결되자마자 가속합니다. 약 0.95초 뒤 자동 해제됩니다.
- 별도 놓기 입력 없이 다음 앵커로 연속 이동할 수 있고, 공중에서 관성을 유지합니다.
- 와이어는 고정 앵커 기반의 아케이드 이동입니다. 모든 임의의 물체에 붙거나 실제 로프의 길이 제약을 계산하지는 않습니다.
- 오토바이는 체력 80으로 피해를 대신 받으며, 체력 소진 또는 X로 폭발합니다.
- 폭발은 주변 피해 85와 도약을 만듭니다. 곧바로 와이어로 연결할 수 있습니다.

### 성장과 진행
기술 조각(TECH)은 적 처치·입자 캐시·코어에서 얻습니다. 입자와 별도의 재화입니다.

| 업그레이드 | 기술 조각 | 필요한 코어 |
| --- | --- | --- |
| 오토바이 제작 | 8 | 1 |
| 공중 발걸음 / 더블 점프 | 10 | 1 |
| 입자 저장량 150 | 12 | 2 |
| 최대 체력 125 | 12 | 2 |

중간 두 곳의 체크포인트는 체력을 회복하고 진행을 저장합니다. 코어도 체력·입자를 보충합니다.
사망하면 체크포인트로 복귀하며 코어·업그레이드를 유지합니다. 진행 중이던 보스전은 초기화됩니다.
코어 3개를 모아 동쪽 성소에 도착하면 수호자가 등장합니다. 수호자는 근접 공격과 탄막을 예고 후 사용하며,
체력이 절반 아래가 되면 이동·공격이 빨라지고 탄막이 늘어납니다. 전투 중에는 성소 영역에 머물게 됩니다.
수호자를 처치하고 오른쪽 게이트로 들어가면 다음 작품으로 이어지는 짧은 결말 문구가 나옵니다.

진행은 로컬 Unity PlayerPrefs의 `PLUGIN.Ancient.v2.*` 키에 저장됩니다. 다른 프로젝트의 키를 삭제하지 않습니다.
K 화면에서 **N을 누른 채 초기화 버튼을 클릭**하면 이 프로토타입의 저장만 지우고 새 게임을 시작합니다.
종료 시에도 진행을 저장하지만, 실행 시간은 현재 실행의 시간만 집계합니다. 일반 적·캐시는 다시 실행하면 재생성됩니다.

## 그래픽 변경
- `Assets/Resources/Art/City.png`: 고대 석상·도시·주황빛 창문이 있는 패럴랙스 배경
- `Hero.png`: 주인공 8포즈 아틀라스, 달리기 프레임·스윙·흡수·탑승 자세
- `World.png`: 금속 옥상, 앵커, 게이트, 적·수호자·오토바이 실제 이미지
- 텍스처는 Point 필터와 비압축·읽기 가능 설정을 사용합니다. `AncientArt.cs`에서 투명 경계를 기준으로 슬라이스합니다.
- 별도 PNG를 실제 렌더링에 사용합니다. 이전 버전의 12픽셀 임시 캐릭터와 사각형 도시를 교체했습니다.
- 타격 곡선, 청록색 잔상, 픽셀 파편, 화면 흔들림과 기본 합성 효과음을 추가했습니다.

이 아트는 AI 생성 이미지를 게임용 배경·아틀라스로 구성한 것입니다. 생성 이미지에 불균일한 픽셀 크기·동작 간 차이가 남아 있습니다.
처음 제시한 3분할 시안은 실제 게임 캡처가 아니며, 그 화면과 완전히 동일한 그래픽을 보장하지 않습니다.

## 검증과 남은 작업
- C# 구문 파싱, PNG 형식·투명도·슬라이스 범위, Unity 리소스 연결·메타데이터·씬 GUID, 패키지 JSON, ZIP 무결성을 검사했습니다.
- **현재 클라우드에 Unity 에디터가 없어 Unity 컴파일, 에디터 임포트, Play Mode, 실행 빌드 검증은 미실행입니다.**
- 구문 검사는 Unity API 타입 검사나 게임 플레이 검증을 대신하지 않습니다.
- 전투 난이도, 플랫폼 도달 가능성, 보스와 카메라·애니메이션의 최종 모습은 Unity에서 확인하고 조정해야 합니다.
- 이 버전은 짧은 챕터 프로토타입입니다. 긴 스토리·정식 대화·완성된 사운드트랙·풍부한 콘텐츠는 포함하지 않습니다.
- 입력 오류가 발생하면 Active Input Handling을 Input Manager (Old) 또는 Both로 설정하세요.

Unity 확인 순서: 이동/점프 → 흡수 중 속도 유지 → 근접 공격 흡수 불가 → 콤보/Q/대시 → 코어/스킬 →
오토바이 체력·수동/자동 폭발 → 와이어 연결 → 체크포인트 사망 복귀 → 보스 패턴/승리 → 재실행 저장 복원.

파일 검사: Python 3으로 `Tools/validate_project.py` 실행. C# 구문 파서는 별도 설치가 필요한 선택 검사입니다.
