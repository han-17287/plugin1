# PLUGIN — Ancient Civilization · Chapter 0 v0.7

Unity **6000.6.7f1**용 2D 액션 어드벤처 소스 프로젝트입니다. EXE가 아닙니다.
기존 Rift of the Sky와 별도 프로젝트이며, 시안 분위기를 반영한 실제 PNG 그래픽을 포함합니다.

## 실행
1. 새 ZIP을 별도 폴더에 압축 해제합니다. 이전 버전 위에 덮어쓰지 않는 편이 안전합니다.
2. Unity Hub → Add project from disk → `AncientCivilization` 선택 → Unity 6000.6.7f1으로 엽니다.
3. `Assets/Scenes/Main.unity`를 열고 Play → Game 뷰를 클릭합니다. 메인 화면에서 START GAME 또는 CONTINUE를 선택합니다. 권장 Game 뷰는 1920×1080, 화면비 16:9입니다.
4. 높은 옥상의 코어 3개를 회수하고 동쪽으로 이동합니다. 코어로 기술을 해금하고 수호자를 쓰러뜨려 게이트에 도착하세요.

시작 씬의 런타임 부트스트랩이 월드와 캐릭터를 생성합니다. Play 전 씬이 비어 보이는 것은 정상입니다.
외부 서버나 유료 에셋이 필요하지 않습니다. 기본 내장 렌더 파이프라인을 사용합니다.
`Packages/manifest.json`에는 Unity 기본 Physics2D / IMGUI / Audio 모듈만 들어 있습니다.

## 스토리 배경
위로 갈수록 상류층이 사는 수직 도시이며, 사람들은 포인트를 모으면 더 높은 곳에 거주할 수 있습니다. 주인공은 아래층의 안전을 지키는 치안경찰입니다. 위층의 도둑이 **자신이 이용하는 트럭으로 아래층 생산 에너지 코어를 훔쳐 도주**하면서 추격이 시작됩니다. 트럭 자체를 훔치는 설정이 아닙니다.

자세한 설정과 현재 구현 범위는 `STORY_KO.md`에 정리했습니다. 이번 변경에는 주차 차량 탑승과 시작 안내를 반영했으며, 움직이는 트럭 추격전은 아직 구현되지 않았습니다.

## 메인 화면
- 실행하면 도시 배경·캐릭터·움직이는 입자가 있는 타이틀 화면을 표시합니다. 메뉴에서는 적·투사체·물리·플레이 시간이 정지합니다.
- **START GAME**: 저장 기록이 없을 때 첫 게임을 시작합니다.
- **CONTINUE**: 기존 저장의 체크포인트·코어·업그레이드로 시작합니다. 기록이 없으면 비활성화됩니다.
- **RESUME**: 플레이 중 메인 화면에 돌아왔다면 현재 상태를 그대로 재개합니다.
- **NEW GAME**: 저장 기록 교체 확인 후 처음부터 시작합니다. 소리·그래픽 설정은 유지합니다.
- **CONTROLS**: 현재 와이어·캡처·오토바이 조작 안내를 엽니다. Esc 또는 BACK으로 닫습니다.
- **QUIT**: 빌드에서는 게임을 종료하며 Unity Editor에서는 Play 모드를 종료합니다.
- 플레이 중 K/Esc → **Save and return to main menu**로 저장 후 메인 화면에 돌아옵니다. 다음 실행의 CONTINUE는 저장된 체크포인트 기준이며, 현재 위치·투사체·캡처 에너지를 파일에 저장하는 기능은 아닙니다.
- 메인 화면에서 게임을 시작하지 않고 종료하면 기존 진행을 덮어쓰지 않습니다.

### 사슬 윈치 사이보그 장치
- 사람 팔의 어깨·상완·팔꿈치·손 형태 대신, 몸통에 고정되는 비대칭 중장비 사슬 윈치로 다시 디자인했습니다.
- 검은 강철 하우징·각진 장갑판·노출 사슬·권취 스프로킷·주황색 경고 무늬·청록색 동력창·앵커 헤드가 보입니다.
- 이동·공격·와이어·캡처·점프·탑승과 메인 화면 캐릭터에 같은 방향을 적용했습니다. 자세별 이미지의 투명 여백과 기준점을 다시 맞췄습니다.
- 실제 연결선도 금속 고리가 교차하는 사슬로 표시합니다. 링크를 미리 만들고 재사용하며 Enhanced 최대 48개 / Light 최대 24개입니다.
- 적 투사체는 기존 금속탄·회전 원반·중량탄·금속 덩어리를 유지합니다. 캡처 단계·피해량은 기존 규칙입니다.

### 빠른 전환·주행·성능
- 휠을 위로 돌리면 공격, 아래로 돌리면 와이어 모드입니다. 같은 방향을 계속 스크롤해도 모드가 반복해서 뒤집히지 않으며 Shift는 모드 전환에 사용하지 않습니다.
- 우클릭 캡처는 두 모드 공통입니다. 와이어 좌클릭 견인·가운데 클릭 스윙 / 공격 좌클릭 발사입니다. 전환 시 저장된 캡처 에너지는 유지하고 현재 사슬 연결만 해제합니다.
- 지상 오토바이에서 주행 반대 방향을 누르면 바로 뒤집히지 않고 짧게 미끄러지며 제동한 뒤 방향을 바꿉니다. 차체 쏠림·기울기·바퀴 헛돎·타이어 자국·먼지·작은 스파크를 추가했습니다. S/↓는 기존 강한 제동입니다.
- 렌더링 목표는 144FPS이며 VSync 대기를 해제했습니다. 실제 FPS는 HUD에 표시합니다. 이 환경에는 Unity 실행기가 없어 실제 성능 향상·144FPS 달성은 측정하지 않았으며 하드웨어·에디터 설정에 따라 다릅니다.
- 빗줄기 72개를 하나의 동적 메시로 묶고, 화면 밖 발광 갱신·메인 화면 뒤 배경 효과·Light의 불필요한 후처리를 줄였습니다. 투사체의 매 프레임 적 배열 복사를 제거하고, 포인터 근처 후보만 와이어 시야 판정합니다.

### 적 배치·천장 변경
- 일반 적을 11명에서 6명으로 줄이고 구간별로 나누었습니다. 캡처용 원거리 적과 마지막 보스는 유지합니다.
- 맵 위쪽 전체를 높이 10의 연속된 천장으로 막았습니다. 천장은 맵 양끝 너머까지 이어지는 하나의 두꺼운 충돌 지형이며, 중간에 틈이 없습니다.
- 청록색 천장 아래면 전체를 조준해 좌클릭 직선 견인·가운데 클릭 스윙을 사용할 수 있습니다. 아래면의 청록색 노드는 쉽게 조준할 수 있는 연결 지점입니다.
- 기존 22유닛 사거리와 시야 제한을 따릅니다. 천장 너머의 목표를 잡거나 지형을 통과하지 않습니다.

### 맵 배치 오토바이
- 시작 구간과 두 체크포인트 근처의 지상에 오토바이 3대를 배치했습니다. 근처에 가면 `E / RIDE` 안내가 표시됩니다.
- 지상에서 E로 탑승하고, 탑승 중 지상에서 E로 내려 현재 위치에 주차합니다. 가능한 경우 지형에 막히지 않은 옆 공간으로 내립니다. 공중 하차는 제한합니다.
- Ctrl 소환·입자 30 비용·오토바이 제작 해금·조립 연출을 제거했습니다. 달리기는 R입니다.
- 주차 차량의 위치·방향·남은 체력을 현재 실행 중 유지합니다. 다시 탈 때 차량을 복제하거나 체력을 채우지 않습니다.
- 최대 체력 80, 체력 28 이하 손상 외형, X 자폭·체력 소진 시 파괴, 방향 전환 스키드·S/↓ 제동·바퀴 회전·엔진음은 유지합니다.
- 차량이 파괴되면 그 자리에 새 차량을 소환할 수 없습니다. 다른 주차 차량을 찾거나, 플레이어 사망 시 원래 배치 지점에 차량이 복구됩니다.
- 저장 파일에는 차량별 위치·체력을 추가로 저장하지 않습니다. 게임을 다시 열거나 새 게임을 시작하면 원래 배치로 초기화됩니다. 메인 화면에서 현재 세션을 RESUME할 때는 유지됩니다.
- 탑승에는 넓은 차량 충돌 상자를 사용하고, 탈 공간이 막혀 있으면 탑승을 거절합니다. 입자를 소모하지 않습니다.

### 포인터·와이어 조작
- 시작은 와이어 모드입니다. 좌클릭은 직선 견인, 가운데 클릭은 자동 스윙입니다. 휠 위는 공격, 휠 아래는 와이어 모드이며 전환 시 현재 사슬을 해제합니다.
- 우클릭을 유지하면 두 모드 모두 7유닛 안의 시야가 트인 적 투사체를 캡처합니다. 공격 모드 좌클릭으로 포인터 방향에 발사합니다.
- 캡처 에너지는 적 탄의 피해량(탄당 8~25)에 비례해 누적하며 최대 100입니다. 40 미만은 1단계, 40 이상은 2단계, 80 이상은 3단계입니다. 단계는 최대 3이며 100% 충전과는 별개입니다. 예를 들어 피해 15 탄을 세 번 캡처하면 45%, 2단계입니다.
- 에너지가 쌓일수록 보관 고리, 발사체 폭·궤적·피격 범위·파편이 커지고 피해는 `20 + 에너지 × 1.4`입니다. 발사하면 저장 에너지를 전부 사용합니다. 80% 이상에서는 방패도 파괴합니다.
- 최대 충전에서는 더 캡처할 수 없고 캡처 간격은 0.12초입니다. 근접 공격은 캡처할 수 없으며 사망하면 저장 에너지가 사라집니다.
- F는 기존 입자 자원 흡수 기능이며 캡처 에너지와 별개입니다. 캡처한 탄을 발사한 것은 다시 캡처할 수 없습니다.
- SWING: 위쪽 앵커·높은 지형에 붙어 원호를 그리다가 자동 해제합니다.
- ZIP: 포인터로 선택한 고정 지형·앵커를 향해 곧바로 견인합니다. 아래쪽·옆쪽 고정 지형도 선택할 수 있습니다.
- ZIP은 접근 완료 또는 최장 1.25초 후 자동 해제하며, 짧은 전방·상승 속도를 남깁니다. 순간이동은 하지 않습니다.
- Tab 모드 전환은 제거했습니다. 와이어 종류는 클릭한 버튼으로 정합니다.
- 포인터 근처에 있는 목표만 선택합니다. 목표가 청록색으로 표시되는 것을 보고 클릭하세요.
- 조준점이 회색이면 유효한 목표가 없으며, 짧은 재발사 대기 중에는 주황색으로 표시합니다.
- SWING 조준점은 다이아몬드·십자형, ZIP은 회전된 사각형 형태입니다. 오른쪽 HUD에도 모드를 표시합니다.
- 포인터는 메뉴에서는 화살표 모양으로 바뀝니다. Game 뷰 밖·포커스 상실·종료 시 기본 포인터로 복원합니다.
- 마우스를 화면 안에 가두지 않습니다. Windows 단축키와 겹치는 것이 불편하면 Alt 대신 C로 대시하세요.
- 대시 이동 중에도 V 공격과 와이어를 별도로 입력할 수 있습니다.

### 동작·연출 개선
- 공격 준비→주먹이 뻗는 타격→회복 자세를 추가했습니다. 피해는 실제 타격 시점에 들어갑니다.
- 0.16초의 다음 공격 입력 버퍼를 넣었습니다. 세 번째 공격은 준비·회복 시간이 더 길고 방패를 부술 수 있습니다.
- 공격 중 이동 방향을 바꾸더라도 해당 공격 자세와 판정 방향은 타격이 끝날 때까지 일치합니다.
- 전용 점프·피격 자세, 착지 파편·짧은 눌림, 대시/와이어 잔상을 추가했습니다.
- 타격 시 짧은 전역 시간 강조(약 0.02~0.05초)가 있습니다. 흡수 동작 자체는 이동속도를 낮추지 않습니다.
- 적의 공격 준비 중 머리 위에 EVADE(물리 근접) / ABSORB(원거리)와 준비 게이지를 표시합니다.
- UI 버튼·패널 테마, 체력 감소 잔상, 대시/방출 재사용 표시와 가까운 코어 안내를 추가했습니다.
- 효과 파편은 최대 96개(가벼운 그래픽 48개), 잔상은 8개를 순환 재사용합니다. 모든 효과가 풀링되는 것은 아닙니다.
- 화면 흔들림을 카메라 추적 위치와 분리하고 화면 픽셀 단위로 정렬해 누적 흔들림을 줄였습니다.
- 효과음의 파형 위상을 정리하고 짧은 음성 재생 제한을 넣었습니다. 작은 합성 도시 배경음을 추가했습니다.
- F7 소리 설정은 진행 초기화와 별개로 유지됩니다.

### 흡수와 전투
- 물리 근접 공격은 흡수할 수 없습니다. 주황색 예고를 보고 대시·점프·거리 벌리기로 피합니다.
- 적의 금속탄·원반·금속 투척물은 F로 파괴·흡수할 수 있고, 두 모드의 우클릭으로 캡처할 수 있습니다.
- 흡수 시작 후 0.18초 안에 흡수하면 PERFECT 보너스 입자를 얻습니다. 계속 누르고 있어도 일반 흡수는 가능합니다.
- 흡수 범위는 7 유닛이고 벽을 통과하지 않습니다. 공격하지 않고 흡수만 해서는 적이 죽지 않습니다.
- V 3연타로 근접 공격하거나, Q의 범위 방출·오토바이 폭발로 입자를 공격에 활용하세요.
- 일반 이동/달리기/오토바이 최고 속도는 5/9/17입니다. 흡수 중에도 같은 속도를 유지합니다.

### 이동과 오토바이
- **22 유닛 이내**의 앵커·고정 지형 표면을 포인터로 조준합니다. SWING은 위쪽 앵커와 높은 옥상 표면, ZIP은 방향 제한 없는 표면을 선택할 수 있습니다. 선택 가능한 곳에는 청록색 표식이 보입니다.
- SWING은 연결 즉시 앞으로·위로 가속하고 ZIP은 목표 방향으로 가속합니다. 입력을 누른 채 기다리거나 별도로 놓을 필요가 없습니다.
- SWING은 `DistanceJoint2D.maxDistanceOnly`의 최대 길이 제약과 자동 감기로 연결점을 축으로 원호를 그립니다.
- 충분히 돌아 상승 방향이 되면 자동으로 줄을 놓고 날아갑니다. 최장 연결 시간은 1.35초입니다.
- 다른 앵커로 곧바로 다시 연결하면 CHAIN이 이어집니다. 연속 연결과 발사 속도에는 상한이 있습니다.
- 자동 해제 후 0.7초 동안 같은 방향 공중 입력이 기존의 빠른 속도를 즉시 줄이지 않습니다. 반대 방향으로는 제동할 수 있습니다.
- 줄이 지형에 막히면 연결을 끊습니다. 벽을 뚫거나 물체 위치로 순간이동하지 않습니다.
- 대시·점프·오토바이 폭발·사망 시 줄이 해제됩니다. 폭발 도약 직후 연결할 수 있습니다.
- 사슬 링크·발사 잔물결·청록색 동력선·육각 연결부와 연결·해제 파편을 표시합니다.
- 현재 붙잡을 수 있는 물체는 고정 앵커와 높은 고정 지형입니다. 적·투사체·움직이는 물체에 붙는 기능은 미구현입니다.
- 오토바이는 체력 80으로 피해를 대신 받으며, 체력 소진 또는 X로 폭발합니다.
- 폭발은 주변 피해 85와 도약을 만듭니다. 곧바로 와이어로 연결할 수 있습니다.

### 성장과 진행
기술 조각(TECH)은 적 처치·입자 캐시·코어에서 얻습니다. 입자와 별도의 재화입니다.

| 업그레이드 | 기술 조각 | 필요한 코어 |
| --- | --- | --- |
| 오토바이 제작 | 8 | 1 |
| 공중 발걸음 / 더블 점프 | 10 | 1 |
| 입자 저장량 150 | 12 | 2 |
| 최대 체력 125 | 12 | 2 |

중간 두 곳의 체크포인트는 체력을 회복하고 진행을 저장합니다. 코어도 체력·입자를 보충합니다.
사망하면 체크포인트로 복귀하며 코어·업그레이드를 유지합니다. 진행 중이던 보스전은 초기화됩니다.
코어 3개를 모아 동쪽 성소에 도착하면 수호자가 등장합니다. 수호자는 근접 공격과 탄막을 예고 후 사용하며,
체력이 절반 아래가 되면 이동·공격이 빨라지고 탄막이 늘어납니다. 전투 중에는 성소 영역에 머물게 됩니다.
수호자를 처치하고 오른쪽 게이트로 들어가면 다음 작품으로 이어지는 짧은 결말 문구가 나옵니다.

진행은 로컬 Unity PlayerPrefs의 `PLUGIN.Ancient.v2.*` 키에 저장됩니다. 다른 프로젝트의 키를 삭제하지 않습니다.
K 화면에서 **N을 누른 채 초기화 버튼을 클릭**하면 이 프로토타입의 저장만 지우고 새 게임을 시작합니다.
종료 시에도 진행을 저장하지만, 실행 시간은 현재 실행의 시간만 집계합니다. 일반 적·캐시는 다시 실행하면 재생성됩니다.

일반 적 5종과 보스는 별도 실루엣을 사용합니다. 단순한 색 변경으로 구분하지 않습니다.
투척물은 플레이어 위치를 예고 시점에 고정해서 날아가며, 적의 공격은 회피와 반격 시간을 갖도록 구성했습니다.
방패병은 공격 중·공격 직후 방향이 잠겨 뒤잡기가 가능합니다. 보스는 일반 적처럼 경직으로 공격을 취소하지 않습니다.
최종 난이도와 적 조합의 공정성은 Unity에서 직접 플레이하며 조정해야 합니다.

## 검증과 남은 작업
- C# 구문 파싱, 셰이더 리소스 참조, PNG 형식·투명도·슬라이스 범위, Unity 리소스 연결·메타데이터·씬 GUID, 패키지 JSON, ZIP 무결성을 검사했습니다.

- 구문 검사는 Unity API 타입 검사나 게임 플레이 검증을 대신하지 않습니다.
- 전투 난이도, 공격 입력 버퍼·타격 시점, 플랫폼 도달 가능성, 보스와 카메라·애니메이션의 최종 모습은 Unity에서 확인하고 조정해야 합니다.
- 이 버전은 짧은 챕터 프로토타입입니다. 긴 스토리·정식 대화·완성된 사운드트랙·풍부한 콘텐츠는 포함하지 않습니다.
- 입력 오류가 발생하면 Active Input Handling을 Input Manager (Old) 또는 Both로 설정하세요.

Unity 확인 순서: 이동/점프 → 흡수 중 속도 유지 → 근접 공격 흡수 불가 → 콤보/Q/대시 → 코어/스킬 →
오토바이 체력·수동/자동 폭발 → 와이어 연결 → 체크포인트 사망 복귀 → 보스 패턴/승리 → 재실행 저장 복원.
