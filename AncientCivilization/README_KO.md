# PLUGIN — Ancient Civilization · 2D 프로토타입

Unity **6000.6.7f1**용 소스 프로젝트입니다. 완성 게임이나 빌드된 EXE가 아닙니다.
기존 Rift of the Sky 프로젝트와 독립적이며, 외부 유료 에셋 없이 작은 픽셀 텍스처를 코드에서 생성합니다.
시안 이미지를 그대로 게임 배경으로 쓰지는 않았습니다. 실제 그래픽은 단순화된 프로토타입입니다.

## 열기
1. ZIP을 압축 해제합니다. Unity Hub → Add project from disk에서 `AncientCivilization` 폴더를 선택합니다.
2. Unity 6000.6.7f1으로 열고 최초 임포트가 끝날 때까지 기다립니다.
3. `Assets/Scenes/Main.unity`를 열어 Play를 누르고 Game 뷰를 클릭합니다.
4. 시작 위치는 왼쪽 옥상입니다. 주황·청록색 코어 3개를 모아 맨 오른쪽 게이트에 도착하세요.

Play 중 런타임 부트스트랩이 카메라·지형·주인공·적을 생성합니다. 따라서 Play 전에는 씬이 비어 보이는 것이 정상입니다.
외부 서버, 계정, 추가 에셋 다운로드가 필요하지 않습니다. 기본 내장 렌더 파이프라인을 사용합니다.

## 조작
| 입력 | 동작 |
| --- | --- |
| A / D 또는 좌우 방향키 | 좌우 이동 |
| Space | 점프 |
| Ctrl 짧게 누르기 | 달리기 토글 |
| F 누르고 있기 | 입자 흡수 — 이동속도 감소 없음 |
| J 또는 마우스 왼쪽 | 기계팔 근접 공격 |
| E 또는 마우스 오른쪽 | 커서 근처의 청록색 앵커에 와이어 연결 |
| K | 스킬 패널 열기/닫기 |
| Ctrl 0.45초 이상 누르기 | 해금 후 오토바이 생성·탑승 (입자 30) |
| X | 오토바이 폭발, 범위 공격과 도약 |
| R | 현재 스테이지 전체 재시작 |

와이어는 연결 즉시 주인공을 당기며 전방으로 가속합니다. 약 0.95초 뒤 자동으로 풀립니다.
커서를 다음 앵커로 옮겨 다시 연결할 수 있습니다. 별도 놓기 입력은 필요 없습니다.
앵커는 20 유닛 안에 있고 지형에 가려지지 않아야 합니다. 고정 앵커 기반의 아케이드 이동이며,
모든 임의의 벽이나 물체를 붙잡거나 실제 로프 물리를 계산하는 구현은 아닙니다.

## 입자와 오토바이
- 물리 근접 공격은 흡수 불가능합니다. 주황색 예고 후 공격하므로 피하세요.
- 에너지탄은 F로 흡수합니다. 금속 투척물은 파괴하며 입자로 흡수합니다.
- 흡수 범위는 7 유닛이며 벽 너머의 투사체는 흡수하지 않습니다.
- 입자는 최대 100입니다. 캐시·적 처치 후 드롭·코어로도 보충합니다.
- K 패널에서 입자 20을 사용해 오토바이를 해금합니다. 처음부터 해금되어 있지는 않습니다.
- 오토바이는 체력 80이며 탑승 시 피해를 대신 받습니다. 체력 소진 또는 X로 폭발합니다.
- 폭발은 주변 적에게 피해 80을 주고 탑승자를 위로 발사합니다. 곧바로 와이어로 이어갈 수 있습니다.
- 일반 이동/달리기/오토바이 속도는 각각 5/9/15입니다.

## 포함된 내용
작은 횡스크롤 스테이지, 픽셀 캐릭터와 야경, 플랫폼·낙사 구간·앵커,
근접병·에너지 사수·투척병, 피격/무적 시간, 입자 캐시, 코어 3개,
중간 체크포인트, 오토바이 스킬 해금, 체력·입자 HUD, 마지막 게이트와 복선 문구.
낙사·사망 시 체크포인트로 돌아오며 코어와 해금은 유지됩니다.
이 정보는 실행 중 메모리에만 존재하며 디스크 저장은 구현하지 않았습니다.
스킬 패널을 열어도 게임은 일시정지하지 않습니다.

## 직접 확인할 플레이 항목
1. Ctrl을 짧게 눌러 달리기를 켜고 끕니다. F를 누른 상태에서도 속도가 유지되는지 확인합니다.
2. 에너지 사수와 투척병의 공격을 F로 흡수하고 입자 증가 및 투사체 제거를 확인합니다.
3. 근접병 앞에서 F를 누르고 있어도 피해를 받는지 확인합니다.
4. K에서 해금 후 Ctrl을 길게 눌러 생성합니다. 짧은 입력으로 오토바이가 생성되지 않는지 확인합니다.
5. X 폭발과 체력 소진 폭발, 범위 피해, 도약을 확인합니다.
6. 청록색 앵커를 가리켜 E를 누릅니다. 즉시 가속·스윙하고 자동 해제되는지 확인합니다.
7. 폭발 도약 → 와이어 이동을 연결하고, 코어 3개를 모아 오른쪽 게이트로 갑니다.
8. 낙사 후 체크포인트 복귀와 R 전체 재시작을 확인합니다.

## 검증 범위와 한계
이 클라우드에는 Unity 에디터가 없으므로 실제 Unity 컴파일, Play Mode, 빌드는 **미실행**입니다.
파일 구조, JSON, C# 구문, 픽셀 그리드, 씬 GUID 및 ZIP 무결성은 별도 검사합니다.
전투 난이도, 이동 거리와 카메라 감각은 Unity에서 조정해야 합니다.
할로우 나이트·실크송 수준의 완성도나 산나비 수준의 그래픽/물리를 보장하지 않습니다.
사운드, 보스, 정식 스킬트리, 대화, 영구 저장과 최종 아트는 미구현입니다.
기존 Input API를 사용하므로 입력 관련 오류 시 Active Input Handling을 Input Manager (Old) 또는 Both로 설정하세요.
