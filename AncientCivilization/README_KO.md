# PLUGIN — ANCIENT CIVILIZATION v0.15.0

한국인 하층 치안경찰 **백 경위**의 도시 수사를 플레이하는 Unity **6000.6.7f1**용 2D 도트 액션 소스 프로젝트입니다. 설정상 본명은 내부 데이터에 유지하며 초반 화면과 대화에서는 백 경위로 부릅니다.

와이어 모드의 **좌클릭은 충돌을 검사하는 즉시 직선 견인**, 가운데 클릭은 기존 스윙입니다. 공격 모드에서는 짧은 좌클릭으로 세로 → 가로 → 사선의 전용 48프레임 연격, 길게 눌러 조준한 뒤 놓으면 굵은 연속 레이저를 사용합니다. 파괴된 물체에서 나온 파란 입자는 두 모드에서 우클릭으로 모읍니다.

대화는 인게임 캐릭터 곁의 작은 말풍선으로 표시합니다. 한국어가 한 글자씩 나오고 긴 대사는 페이지로 나눕니다. 통신관의 무전에는 무전기 아이콘이 붙습니다. 캐릭터를 가리는 큰 초상화나 화면 전체를 어둡게 만드는 대화 덮개는 사용하지 않습니다.

일반 도시와 현장은 지상 통로를 중심으로 이동합니다. 현장 20개는 각각 폭 624단위·208단위씩 3구간이며, 지정된 다섯 현장의 두 번째 구간에 층별 점프·와이어 기믹을 넣었습니다. 구간별 적 최대 2명, 거점 저장·재도전과 입자 재채취를 유지합니다. 자세한 경로는 [FIELD_EXPANSION_KO.md](FIELD_EXPANSION_KO.md)에 있습니다.

오토바이는 초반·마지막 추격전에서만 배치하고 구간 종료 때 정리합니다. 메뉴는 고화질 블레이드 시안 원본과 도시 배경을 포함한6종 중 실행별로 하나를 선택합니다. 메뉴로 돌아올 때는 같은 실행의 배경을 유지합니다. 메인 화면 전 Hwasan Games → HG 로고는 Space/Esc로 건너뛸 수 있습니다.

저격수 4페이즈와 비서실장 시계 최종보스를 유지합니다. 비서실장은1회차에서 1페이즈만 싸운 뒤 살아서 퇴장하며2회차에 돌아옵니다. 친구 공개와 고대 문명 맵도2회차 범위입니다. 실제 Unity 실행·빌드·FPS·전체 완주 시간은 아직 확인하지 못했습니다.

## 실행

ZIP을 새 폴더에 풀고 Unity Hub에서 `AncientCivilization` 폴더를 6000.6.7f1으로 여세요. `Assets/Scenes/Main.unity` → Play → 시작하기를 선택합니다. 월드는 실행 중 생성하며 Play 전 씬은 비어 보일 수 있습니다. 권장 화면은 16:9 / 1920×1080입니다.

새로 구성한 조사 순서를 처음부터 보려면 **새 게임**으로 시작하세요. v0.10.0 이전 세이브는 진행·권한을 보존하며 신규 현장에 들어갈 수 있지만, 이미 얻은 통행 권한을 새 조사로 다시 잠그지 않습니다. 따라서 새 진행의 조사→보스 순서를 확인하려면 신규 세이브가 필요합니다.

## 이번에 실제 추가한 내용

- 초반 주인공 화면 표시와 대화 호칭은 백 경위로 통일합니다. 설정상 본명은 내부 데이터에 보존합니다.
- 도시 다섯 층에 주요 사건 **20개**, 별도 현장 구역 **20개**를 추가했습니다. 각 현장은 폭 624단위·3구간과 세 가지 목표·확보 자료를 사용합니다.
- 주민 **25명**을 배치했습니다. E로 대화하며 캐릭터 말풍선에서 한국어가 한 글자씩 표시됩니다. 사건 전후 대사와 인물별 도트 외형을 넣었습니다. 구조 대상 네 명은 이동 거리에 맞춘 걷기 동작을 사용합니다.
- 조사·증언, 블레이드 봉인 해제, 주민 구조/동행, 입자 레이저 전력 복구로 사건 방식을 구분했습니다.
- 새 게임은 하층 조사 네 사건을 마친 뒤 첫 윗층으로 갑니다. 윗층은 조사 뒤 보스전, 보스 제압 뒤 다음 층 권한을 얻습니다. 승진으로 자동 이동하지 않습니다.
- 최상층은 세 사건→저격수 4페이즈 대치→회장실 자료 대조→비서실장 1페이즈·생존 퇴장→노트 확인→마지막 추격으로 연결합니다.
- 최상층에서 저격수가 옛 친구임을 알아보는 대사와 기록을 제거했습니다. 1회차에서는 포인트 동결·출입 거부라는 같은 처지만 확인합니다.
- 조커는 주민 다섯 명의 대화에서 드물게 언급합니다. 저격수의 정체와 친구 관계를 직접 설명하지 않습니다. 친구 공개는 2회차로 남깁니다.
- Tab → 사건/주민에서 완료 사건의 확보 자료와 **실제 들은** 주민 대화를 다시 읽을 수 있습니다. 모르는 내용은 가립니다.
- 현장 중단/재도전/재접속 때 확보한 목표를 보존합니다. 전력 복구용 입자가 소실돼도 패널에서 다시 채취할 수 있습니다.
- 현장별 배경·조명·이동 기믹을 현재 구역에서만 표시/갱신하도록 묶었습니다. 기존 와이어·풀·FPS 설정은 유지합니다.
- 회장실 창밖의 트럭 탑승을 간단한 도트 인물 이동으로 보완했습니다. 고대 문명 플레이 맵은 만들지 않았습니다.

**현재 버전을 9시간·90% 완성으로 표시하지 않습니다.** 기존보다 사건과 주민 상호작용을 크게 확장한 플레이용 블록아웃이며, 목표 9시간에 필요한 콘텐츠·전용 아트·전체 완주와 실제 Unity 빌드 검증이 남아 있습니다. 구현 수량은 플레이타임이나 완성 비율이 아닙니다. 정확한 범위는 COMPLETION_KO.md에 있습니다.

## 주요 진행

| 층 | 새 사건 | 담당자 |
| --- | --- | --- |
| 하층 생산구 | 야간 배정 → 작업장 전력 → 작업자 구조 → 사본 보관 | 검거 뒤 순찰소장 |
| 하부 생활구 | 진료소 → 배달원 → 위조 심사 → 수령처 원장 | 간호사 윤서 |
| 중층 행정구 | 신고 연결 → 보관소 → 원본 대조 → 직원 보호 | 기록원 다인 |
| 상층 거주구 | 전력 분기 → 재배치 계약 → 이송 예정자 → 승진 보류 | 설비사 지완 |
| 최상층 통제구 | 감시 회선 → 삭제 신청 → 미승인 통로 → 대치 후 회장실 자료 | 정비 노동자 노을 / 대치 뒤 보관실 관리인 유담 |

담당자에게 E로 브리핑을 듣고 같은 층의 현장 연결로로 들어갑니다. 획득한 안전 거점 근처에서 E는 중단/복귀, 동쪽 출구 E는 세 목표와 위협을 해결한 뒤 보고입니다. 현장 출입은 층간 이동이 아니며, 실제 다른 층으로 갈 때는 입구 엘리베이터를 이용합니다. 일반 이동은 지상 통로이며, 점프·와이어 구간은 지정 현장의 가운데에 따로 배치합니다. 최상층은 거주구 동쪽 외벽 샛길로 침입합니다.

초반과 마지막에만 추격전이 있습니다. 중간 층은 수사·이동·범죄자·패턴 보스 중심입니다. 마지막에는 정체를 설명하지 않는 지원 사격이 백명을 구하고, 같은 총탄이 코어 보호부를 파손해 폭주·추락으로 이어집니다.

| 탈취한 저격수 포탑에서 E / 좌클릭 | 탑승·하차 / 마우스로 조준해 압축 발사 |
| 저격수 레이저 충돌 중 Space + 좌클릭 | 두 입력을 각각 연타해 충돌 게이지 밀기 |

대시는 없습니다. Shift로 전환하지 않으며 오토바이를 소환하지 않습니다. 차량은 초반·마지막 추격전 안에만 배치됩니다. 좌클릭 0.22초 미만은 베기, 총 0.85초부터 레이저 준비 완료, 그 사이는 취소입니다. 레이저는 즉시 전체 빔이 나타나며 날아가는 입자탄이 아닙니다.

입자 저장 상한 100, 단계 상한 3입니다. 40/80에서 단계가 올라가며 캡처 세 번이 풀 충전을 뜻하지 않습니다. 우클릭은 온전한 적 투척물을 흡수하지 않습니다. 와이어의 곧은 중심선과 두 DNA 나선, 긴 노란 블레이드와 기존 오토바이 원본은 유지했습니다. 고그래픽 시안 두 원본은 ZIP의 ArtReferences에 해시가 같은 상태로 보관합니다.

## 문서와 검증

- SNIPER_BOSS_KO.md: 저격수 4페이즈·포탑·레이저 힘겨루기와 비서실장 생존 퇴장.
- STORY_KO.md: 확정 설정·1회차/2회차 경계·9시간 제작 목표.
- CAMPAIGN_SCRIPT_KO.md: 런타임 데이터 기준 주요 사건/주민 대사 전문.
- COMPLETION_KO.md: 요청한 90% 목표와 현재 구현/미완성 범위.
- PLAYTEST_KO.md: 실제 Unity 확인 절차.
- PERFORMANCE_KO.md: F9/F10 측정 방법과 한계.
- VALIDATION.txt: 실행한 검사 결과.

`python Tools/validate_project.py`는 PNG·GUID·분할·C# 문법·관계 공개 금지를 검사합니다. 선택 의존성은 Pillow, tree-sitter, tree-sitter-c-sharp입니다. `dotnet run --project Tools/RulesChecks.csproj`는 .NET 8 SDK에서 독립 규칙을 검사합니다. `dotnet run --project Tools/SniperChecks.csproj`는 저격수 전용 순수 규칙을 검사합니다. 게임 실행에 Python/.NET SDK는 필요하지 않습니다.

실제 Unity 6000.6.7f1의 컴파일·임포트·셰이더·Play Mode·전체 완주·FPS·플레이어 빌드는 이 환경에서 실행하지 못했습니다. 보조 구버전 참조 DLL 타입 검사는 실제 Unity 6 검증을 대신하지 않습니다. 한국어 폰트 Neo둥근모의 SIL OFL 라이선스는 Assets/Resources/Fonts/LICENSE.txt에 있습니다.
