# v0.8.7 — 하층·상층별 이동 기믹

현재 구현된 두 층 모두에 이동 경로를 넣었습니다. 하층은 공장 운송 장치, 상층은 공중 반동을 중심으로 서로 다르게 구성합니다.

- 하층 공장 옥상: 움직이는 크레인 고리 3개와 운송 벨트 두 곳. 와이어가 움직이는 고리를 따라가며 견인·스윙합니다. 정방향 벨트는 가속하고 역방향 벨트는 지상 이동을 방해합니다. 높은 금색 발판으로 우회할 수 있습니다.
- 순찰·장비 훈련 후 x=24 부근에서 E로 옥상 경로 진입. 종료 지점은 x=96 부근입니다. 도로에 내려오면 기록을 초기화하고 안전 경로로 돌아갑니다. 입구/완주 지점에서 E로 재도전합니다.
- 오토바이와 추격 트럭은 기존 도로를 이용합니다. 벨트는 옥상에서 보행 중인 주인공에게만 작동합니다.
- 상층: 기존 부유체 반동·연속 와이어·추락 회수를 유지합니다. 하층과 상층의 최고 기록은 별도로 저장합니다.
- 중층·최상층 등 후속 지역은 아직 플레이 맵이 없습니다. 각 층의 다른 기믹과 기존 스토리 연결 계획은 FLOOR_DESIGN_KO.md에 구분했습니다.

규칙·정적 맵 검사 224개와 문법·에셋 검사 통과. Unity Play/완주·빌드는 미실행입니다.

# v0.8.6 — 와이어 정비 통로와 블레이드 반동

상층 이동 엘리베이터 오른쪽에 약 120유닛 길이의 정비 통로를 추가했습니다. 엘리베이터 해금 후 상층에서 접근합니다. 추격전이나 새 보스를 추가한 구간은 아닙니다.

- 청록 기본 경로: 넓은 착지 발판과 짧은 간격으로 견인·스윙·재연결 연습.
- 금색 숙련 경로: 높은 좁은 발판, 천장 앵커 연속 연결과 공중 반동을 활용해 착지를 줄이는 지름길.
- 천장은 전 구간 연결되며 와이어를 걸 수 있습니다. 이동 속도를 임의로 제한하는 구간이나 문 대기는 없습니다.
- 떠 있는 노란 핵/푸른 외곽의 부유체를 공격 모드 좌클릭 블레이드로 맞히면 위로 반동합니다. 적 투척물을 파괴하거나 공중 드론을 타격해도 반동합니다. 레이저·F 분해·지상 공격은 반동을 주지 않습니다.
- 한 번의 베기로 여러 물체를 맞혀도 반동은 한 번만 적용됩니다. 부유체는 0.85초 후 재활성화합니다. 가로 속도는 유지하고, 일반 반동 상승 속도는 6~9유닛/초입니다. 이미 더 빠르게 상승 중이면 감속시키지 않습니다.
- 휠 위로 공격 모드 → 짧은 좌클릭 반동 → 휠 아래로 와이어 → 다음 앵커 연결. 별도 반동 키는 없습니다.
- 추락하면 피해 없이 마지막 안전 발판으로 회수합니다. 중간 안전 지점 두 곳을 배치했습니다.
- 입구 또는 완주 지점에서 E로 재도전합니다. 구간 시간과 회수 횟수가 표시되고, 추락 없는 완주의 최고 기록만 저장합니다. 최고 기록은 새 게임 시 초기화됩니다.

검증: 순수 C# 규칙·맵 구조 검사 224개, C# 문법·에셋 구조 검사 통과. 발판 폭·높이·간격 검사는 정적 검사이며 실제 Unity 점프·스윙 완주나 조작감 측정을 대신하지 않습니다. Unity Play/빌드는 미실행입니다.

# v0.8.5 — 적 와이어 견인·충돌

와이어 모드에서 적을 겨냥해 좌클릭하면 와이어가 명중한 뒤 주인공이 적에게 돌진합니다. 적은 작은 거리를 밀려나며, 견인 중과 충돌 직후 0.3초 동안 해당 적과의 접촉 피해를 받지 않습니다. 다른 적의 접촉, 투사체, 별도 공격은 보호 대상이 아닙니다. 일반 적은 몸 접촉 피해 8, 보스는 14입니다.

일반 적: 와이어 명중 12 + 충돌 18, 밀림 최대 0.65유닛. 보스: 명중 3 + 충돌 4, 밀림 최대 0.18유닛. 방패 적은 기존 방어 판정을 유지하고, 보스 공격 전조·패턴은 와이어로 취소되지 않습니다. 밀림은 벽·지면·기존 이동 범위에 제한됩니다. 지형 가림과 22유닛 사거리도 적용됩니다.

적 견인은 좌클릭 전용이고, 가운데 클릭 지형 스윙은 유지합니다. 적을 겨냥하면 주황색 조준 표시가 나타납니다. 고속 돌진이 한 물리 프레임에 적을 통과하는 경우도 선분 충돌 검사로 처리합니다.

1. ZIP을 새 폴더에 압축 해제합니다.
2. Unity Hub → Add project from disk → `AncientCivilization` → Unity 6000.6.7f1으로 엽니다.

4. 권장 화면비는 16:9 / 1920×1080입니다. 시작 씬은 런타임에 월드와 캐릭터를 생성하므로 Play 전에는 비어 보일 수 있습니다.

스토리 대화와 초반 지역 표지판은 한국어이며, 대사는 한 글자씩 표시됩니다. 별도 서버·유료 에셋·외부 Unity 패키지가 필요하지 않습니다. 한국어 픽셀 글꼴 Neo둥근모를 포함하며, SIL OFL 라이선스는 Assets/Resources/Fonts/LICENSE.txt에 있습니다.

## 이번 버전의 플레이 순서

1. **순찰 훈련:** 이동, 점프, Ctrl 달리기를 확인합니다.
2. **장비 훈련:** 천장에 입자 와이어를 연결하고 주차된 오토바이에 E로 탑승합니다.
3. **블레이드 훈련:** 휠 위로 공격 모드를 선택합니다. 훈련 투사체를 좌클릭 짧게로 부수고 입자를 모은 다음, 길게 눌러 조준하고 준비 후 놓아 레이저를 발사합니다.
4. **도난 신고·추격:** 위층 출신 도둑이 아래층 생산 에너지 코어를 트럭에 싣고 도주합니다. 실제로 이동하고 물체를 던지는 트럭을 오토바이·와이어·블레이드로 추격합니다.
5. **코어 회수:** 동쪽에서 트럭이 멈추면 떨어진 코어 3개를 회수합니다.
6. **미니 보스:** 훈련과 추격·회수 조건을 모두 마친 뒤에만 화물 수호 장치가 등장합니다. 체력은 240입니다.
7. **검거와 의문:** 주인공은 검거에 성공하지만, 위층 주민이 왜 아래층의 에너지 코어를 훔쳤는지 의문을 갖습니다. 범행 동기를 이 장에서 확정하지 않습니다.
8. **포인트·상층 허가:** 시민 포인트 1,000점을 받고 한 단계 위 도시의 거주·통행 허가를 얻습니다. 동쪽 승강기 근처에서 오토바이를 주차한 뒤 E로 상층 구역에 이동합니다. 상층에서는 이동·탐색할 수 있으며 다음 사건은 후속 범위입니다.

초반에는 적과 보스를 바로 배치하지 않습니다. 훈련 구간 밖으로 먼저 넘어갈 수 없으며, 체크리스트를 마쳐야 다음 단계가 열립니다. 추격 구간의 일반 적은 3명입니다.

## 블레이드·입자·레이저

- 좌클릭을 **0.22초 미만** 눌렀다 놓으면 블레이드가 나갑니다. 조준 방향으로 약 3유닛 안의 적과 투사체를 공격하며 벽 너머를 치지 않습니다.
- 물체를 부수면 실제 입자 조각이 흩어집니다. 우클릭 유지 중에는 시야가 트인 7유닛 안의 입자를 끌어당겨 수집합니다. 조각은 풀링해 재사용하고 지형에 닿으면 반사됩니다.
- 좌클릭을 길게 누르면 준비 상태로 들어가며 **총 0.85초** 후 조준선이 금색으로 바뀝니다. 이때 마우스로 목표를 정하고 버튼을 놓으면 발사합니다.
- 0.22~0.85초 사이에 놓으면 취소합니다. 입자는 소모되지 않으며, 원치 않는 근접 공격이나 미완성 레이저가 나가지 않습니다.
- 레이저는 최대 24유닛, 첫 지형에서 멈춥니다. 경로에 있는 적을 공격하고 트럭의 투척 장치를 잠깐 억제할 수 있습니다. 발사할 때 저장 입자를 전부 사용합니다.
- 입자는 최대 100, 단계는 최대 3입니다. 40 미만 1단계 / 40 이상 2단계 / 80 이상 3단계입니다. 3단계와 100% 충전은 별개이며 캡처 3회가 풀충전을 뜻하지 않습니다.
- 레이저 피해는 `30 + 저장 입자 × 1.6`입니다. 입자가 많을수록 굵기와 충격 효과가 커집니다.
- 모드 전환·일시정지·대화·포커스 상실은 준비 입력을 취소합니다. 메뉴를 닫거나 다른 창에서 돌아왔을 때 자동 발사하지 않습니다.
- `PARTICLES` 게이지와 `CAPTURE` 게이지는 레이저에 사용하는 실제 저장량을 표시합니다. TECH는 업그레이드 재화, CIVIC POINTS는 거주·통행 등급용 포인트입니다.
- 기존 입자 용량 업그레이드는 입자 획득량 +25% 효과로 정리했습니다. 저장 상한과 단계 상한은 유지합니다.

## 대화·주인공 디자인

- 작은 머리·긴 팔다리·흰색과 검은색의 분명한 색면·얼굴이 완전히 가려진 성인형 도트 비율로 이동·공격·탑승 자세를 다시 구성했습니다.
- 고대 기계팔은 얇고 각진 흰색·검은색 장갑판과 푸른 발광 회로, 입자 흡입구와 와이어 발사구로 표현합니다. 특정 게임의 캐릭터나 문양을 그대로 복제하지 않은 별도 디자인입니다.
- 블레이드는 노란빛 필라멘트와 발광 궤적으로 표시합니다.
- 주인공·통신 지휘관·용의자의 대화 초상화, 하단 대화창, 이름표와 타자식 문장 표시를 추가했습니다. 대화 중에는 게임이 멈추고 대화 종료 입력이 점프나 공격으로 이어지지 않도록 보호합니다.

## 오토바이·와이어·성능

- 시작과 두 체크포인트 근처에 주차 오토바이 3대가 있습니다. E로 타고 내려 현재 위치에 주차하며 남은 차량 체력을 유지합니다. 소환·입자 비용·제작 해금은 없습니다.
- 차량 체력 80, 방향 전환 스키드·차체 기울기·바퀴 회전·타이어 자국·먼지·제동·폭발은 유지합니다. 공중에서는 타거나 내릴 수 없습니다.
- 맵 위쪽은 하나의 연속 천장으로 막혀 있으며 아래면에 견인·스윙 와이어를 걸 수 있습니다. 중앙 직선 코어 주변에 두 가닥의 입자 나선이 회전합니다.
- 144FPS는 목표 설정이며 HUD에 실제 FPS를 표시합니다. 빗줄기 단일 메시, 화면 밖 효과 생략, 투사체 배열 생성 제거 등 기존 최적화를 유지했습니다. 실제 성능은 이 환경에서 측정하지 않았습니다.

## 저장과 이전 버전

- 퀘스트 단계·훈련 체크리스트·회수 코어·미니 보스 검거·시민 포인트·상층 허가를 저장합니다. 코어 회수·체크포인트·업그레이드·퀘스트 전환·종료 시 진행을 기록합니다.
- v0.7의 코어·보스·체크포인트 키를 덮어쓰지 않고 스토리용 별도 키를 사용합니다. 이전 버전에서 CONTINUE하면 새 순찰 스토리를 시작하고 기존 업그레이드·TECH는 유지합니다.
- 차량별 이동 위치·체력과 저장 입자는 파일에 저장하지 않습니다. 현재 세션을 메인 화면에서 재개할 때는 유지하지만, 앱을 다시 실행하면 원래 차량 배치와 저장 체크포인트로 시작합니다.
- 사망하면 차량은 원래 배치로 복구되고 저장 입자는 초기화됩니다. 완료한 훈련과 회수 코어는 유지합니다.
- NEW GAME 확인은 진행을 초기화합니다. 소리·그래픽 설정은 유지합니다.

## 검증

`Tools/validate_project.py`는 PNG 무결성·크기·알파 여백·이미지 분할·메타데이터·GUID·씬 빌드 참조와 C# 구문을 검사합니다.

`dotnet run --project Tools/RulesChecks.csproj`는 .NET 8 SDK로 게임이 실제 사용하는 `AncientRules.cs`를 검사합니다. 클릭 경계·취소·빈 입자·훈련 선행 조건·미니 보스 게이트·보상 중복·상층 진입 조건 **224개**를 통과했습니다. Unity 게임 실행에는 이 SDK가 필요하지 않습니다.

**Unity 타입/API·셰이더 컴파일, 에셋 임포트, Play Mode, 추격전 조작감과 빌드 실행은 이 환경에서 검증하지 못했습니다.** 최신 결과는 `VALIDATION.txt`에 포함했습니다. 아트는 생성 이미지를 게임용으로 구성한 것으로, 프레임 간 세부 모양 차이는 남아 있을 수 있습니다.
