# PLUGIN — ANCIENT CIVILIZATION v0.13.0

한국인 치안경찰 **백명**의 도시 수사를 플레이하는 Unity **6000.6.7f1**용 2D 도트 액션 소스 프로젝트입니다. 실행 EXE가 아닙니다.

이번 중간본은 저격수전을 조커 가면·반쯤 가리는 모자·긴 저격소총과 4페이즈로 바꿉니다. 2초 조준/5발 후 재장전, 파괴되는 지면과 수류탄, 푸른 에너지 분신, 탈취 가능한 압축 포탑, 마지막 입자 수집과 레이저 연타 힘겨루기를 연결했습니다. 자세한 조작과 구현 기준은 [SNIPER_BOSS_KO.md](SNIPER_BOSS_KO.md)에 있습니다.

메인 화면 전에는 검은 바탕에서 Hwasan Games → HG 로고가 나옵니다. Space/Esc로 건너뛸 수 있으며 메뉴 복귀 때 반복하지 않습니다. 제공된 로고 시안을 참고해 정리한 텍스처입니다.

저격수전과 마지막 자료 대조 후 비서실장전이 시작됩니다. **비서실장은 1회차에서 1페이즈만 싸우고 살아서 퇴장하며, 2회차에 다시 등장합니다.** 세 번째 대형 시계는 비서실장 바로 아래의 청록 안전 표시를 이용하세요. 바닥에 박힌 침은 블레이드로 부숴 나온 입자를 우클릭으로 모읍니다.

현재 파일은 총 10시간 개발 도중의 중간본입니다. Unity 실기와 9시간 플레이 시간은 확인하지 못했습니다. 이전 Unity 6000.6 GetInstanceID/FindFirstObjectByType 수정은 유지하며 HOTFIX_0.11.1_KO.md에 기록했습니다.

## 실행

ZIP을 새 폴더에 풀고 Unity Hub에서 `AncientCivilization` 폴더를 6000.6.7f1으로 여세요. `Assets/Scenes/Main.unity` → Play → 시작하기를 선택합니다. 월드는 실행 중 생성하며 Play 전 씬은 비어 보일 수 있습니다. 권장 화면은 16:9 / 1920×1080입니다.

새로 구성한 조사 순서를 처음부터 보려면 **새 게임**으로 시작하세요. v0.10.0 이전 세이브는 진행·권한을 보존하며 신규 현장에 들어갈 수 있지만, 이미 얻은 통행 권한을 새 조사로 다시 잠그지 않습니다. 따라서 새 진행의 조사→보스 순서를 확인하려면 신규 세이브가 필요합니다.

## 이번에 실제 추가한 내용

- 주인공 이름을 백명, 통상 호칭을 백 경위로 반영했습니다.
- 도시 다섯 층에 주요 사건 **20개**, 별도 현장 구역 **20개**를 추가했습니다. 각각 세 가지 목표와 확보 자료가 있습니다.
- 주민 **25명**을 배치했습니다. E로 대화하며 한국어가 한 글자씩 표시됩니다. 사건 전후 대사와 인물별 도트 외형을 넣었습니다. 구조 대상 네 명은 이동 거리에 맞춘 걷기 동작을 사용합니다.
- 조사·증언, 블레이드 봉인 해제, 주민 구조/동행, 입자 레이저 전력 복구로 사건 방식을 구분했습니다.
- 새 게임은 하층 조사 네 사건을 마친 뒤 첫 윗층으로 갑니다. 윗층은 조사 뒤 보스전, 보스 제압 뒤 다음 층 권한을 얻습니다. 승진으로 자동 이동하지 않습니다.
- 최상층은 세 사건→저격수 4페이즈 대치→회장실 자료 대조→비서실장 1페이즈·생존 퇴장→노트 확인→마지막 추격으로 연결합니다.
- 최상층에서 저격수가 옛 친구임을 알아보는 대사와 기록을 제거했습니다. 1회차에서는 포인트 동결·출입 거부라는 같은 처지만 확인합니다.
- 조커는 주민 다섯 명의 대화에서 드물게 언급합니다. 저격수의 정체와 친구 관계를 직접 설명하지 않습니다. 친구 공개는 2회차로 남깁니다.
- Tab → 사건/주민에서 완료 사건의 확보 자료와 **실제 들은** 주민 대화를 다시 읽을 수 있습니다. 모르는 내용은 가립니다.
- 현장 중단/재도전/재접속 때 확보한 목표를 보존합니다. 전력 복구용 입자가 소실돼도 패널에서 다시 채취할 수 있습니다.
- 현장별 배경·조명·이동 기믹을 현재 구역에서만 표시/갱신하도록 묶었습니다. 기존 와이어·풀·FPS 설정은 유지합니다.
- 회장실 창밖의 트럭 탑승을 간단한 도트 인물 이동으로 보완했습니다. 고대 문명 플레이 맵은 만들지 않았습니다.

**현재 버전을 9시간·90% 완성으로 표시하지 않습니다.** 기존보다 사건과 주민 상호작용을 크게 확장한 플레이용 블록아웃이며, 목표 9시간에 필요한 콘텐츠·전용 아트·전체 완주와 실제 Unity 빌드 검증이 남아 있습니다. 구현 수량은 플레이타임이나 완성 비율이 아닙니다. 정확한 범위는 COMPLETION_KO.md에 있습니다.

## 주요 진행

| 층 | 새 사건 | 담당자 |
| --- | --- | --- |
| 하층 생산구 | 야간 배정 → 작업장 전력 → 작업자 구조 → 사본 보관 | 검거 뒤 순찰소장 |
| 하부 생활구 | 진료소 → 배달원 → 위조 심사 → 수령처 원장 | 간호사 윤서 |
| 중층 행정구 | 신고 연결 → 보관소 → 원본 대조 → 직원 보호 | 기록원 다인 |
| 상층 거주구 | 전력 분기 → 재배치 계약 → 이송 예정자 → 승진 보류 | 설비사 지완 |
| 최상층 통제구 | 감시 회선 → 삭제 신청 → 미승인 통로 → 대치 후 회장실 자료 | 정비 노동자 노을 / 대치 뒤 보관실 관리인 유담 |

담당자에게 E로 브리핑을 듣고 같은 층의 현장 연결로로 들어갑니다. 현장 입구 E는 중단/복귀, 동쪽 출구 E는 세 목표와 위협을 해결한 뒤 보고입니다. 현장 출입은 층간 이동이 아니며, 실제 다른 층으로 갈 때는 입구 엘리베이터를 이용합니다. 최상층은 거주구 동쪽 외벽 샛길로 침입합니다.

초반과 마지막에만 추격전이 있습니다. 중간 층은 수사·이동·범죄자·패턴 보스 중심입니다. 마지막에는 정체를 설명하지 않는 지원 사격이 백명을 구하고, 같은 총탄이 코어 보호부를 파손해 폭주·추락으로 이어집니다.

| 저격수 레이저 충돌 중 Space + 좌클릭 | 두 입력을 각각 연타해 충돌 게이지 밀기 |

대시는 없습니다. Shift로 전환하지 않으며 오토바이를 소환하지 않습니다. 차량은 맵에 배치됩니다. 좌클릭 0.22초 미만은 베기, 총 0.85초부터 레이저 준비 완료, 그 사이는 취소입니다. 레이저는 즉시 전체 빔이 나타나며 날아가는 입자탄이 아닙니다.

입자 저장 상한 100, 단계 상한 3입니다. 40/80에서 단계가 올라가며 캡처 세 번이 풀 충전을 뜻하지 않습니다. 우클릭은 온전한 적 투척물을 흡수하지 않습니다. 와이어의 곧은 중심선과 두 DNA 나선, 긴 노란 블레이드와 기존 오토바이 원본은 유지했습니다. 고그래픽 시안 두 원본은 ZIP의 ArtReferences에 해시가 같은 상태로 보관합니다.
