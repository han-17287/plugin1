# 도시 자유 순찰

메인 화면 **도시 자유 순찰 · 5개 층**을 선택하면 마지막으로 방문한 방에서 시작합니다. 캠페인에서도 각 층 입구의 청록색 순찰 안내소나 생산구 튜토리얼 초입 안내소에 가까이 가서 **P**를 누르면 그 층의 첫 방으로 들어갑니다. 순찰 중 **P**를 누르면 본편으로 돌아갑니다.

50개 방은 왼쪽과 오른쪽 길로 이어집니다. 윗길에서는 직선 와이어의 관성으로 발판을 건너고, 아랫길에서는 정비사와 이야기하거나 지름길의 반대편 문을 열 수 있습니다. 보스는 본편 캠페인에서 만납니다.

| 조작 | 기능 |
| --- | --- |
| A/D, Space, S+Space | 이동, 점프 높이 조절, 한 층 아래로 내려가기 |
| 갈고리 모드 좌클릭, Q 또는 휠 | 고리·표면으로 직선 돌진, 모드 전환 |
| 공격 모드 좌클릭, 우클릭 홀드 | 파손 가능한 시설물 치기, 흩어진 입자 회수 |
| E, F 홀드 후 릴리즈 | 스위치·대화·문 사용, 조준한 수광부로 레이저 발사 |
| T | 지나간 정방향 구간의 시험 주행. 직전 주행이 반투명 잔상으로 재생되며 개인 최고 기록은 따로 남습니다. |
| P, Esc | 본편 복귀, 순찰 일시정지 |
| 0 후 17287 | 개발자 이동. 시작할 방이나 본편 목적지를 선택합니다. |

처음에는 생산구 하역 도크의 아랫길을 걸어 보세요. 돌아올 때 세 번째 고리에 닿자마자 점프하면 같은 도크를 위로 건넙니다. 빨래골목에서는 달리는 대신 창틀 앞에서 반대 방향을 눌러 멈춰 보세요. 안쪽 세탁소에서 들렸던 가락은 상층 세탁실에서도 들립니다. 야시장과 전산탑, 두 세탁소를 잇는 문에는 개방 상태를 보여 주는 안내등이 있습니다.
