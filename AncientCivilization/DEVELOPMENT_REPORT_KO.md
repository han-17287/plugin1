# 총 10시간 개발 — 중간 확인본 v0.12.0

작업은 진행 중이며 이 문서는 최종 10시간 완료 보고가 아니다. 대화 사이 대기 시간은 작업 시간에서 제외한다. 앞서 완료한 2시간과 이번 도시 수사 확장 작업을 합산한다.

이번 단계는 백명 이름, 20개 주요 현장과 60개 목표/증거, 주민 25명의 전후 대화와 개별 외형, 구조 대상 4명의 걷기, 실제 청취 대화 기록, 조사→보스→권한의 흐름을 연결했다. 1회차 친구 인지 대사/기록을 제거하고, 조커 단서 다섯 개를 주민의 선택 대화로 배치했다. 같은 처지만 확인하는 저격수 대치 이후 회장실 자료를 대조하고 마지막 추격으로 이어진다.

현장 중단/사망/재접속과 자원 소실 뒤 전력 복구를 보완했다. 현재 구역의 메시·조명·움직이는 기믹만 갱신한다. 인물 PNG는 원본을 보존하고 런타임 고정 픽셀 팔레트와 측정한 발 기준으로 표시한다. 기존 주인공·오토바이·보관한 3D 시안 원본은 변경하지 않았다.

현재 독립 규칙 검사 2310개, PNG/메타/구문/스포일러 검사와 보조 참조 DLL 타입 검사를 통과했다. 실제 Unity Play/빌드/FPS와 9시간 완주는 확인하지 못했다. 90%나 완벽한 완성으로 표시하지 않는다. 현재 남은 범위는 COMPLETION_KO.md에 공개하고 이후 단계에서 계속 작업한다.

이번 추가 단계에서 사용자 요청한 로고 순차 도입과 최종보스 변경을 반영했다. Hwasan Games와 HG는 제공된 시안을 참고해 정리한 텍스처로, 파일 원본을 그대로 복사한 로고는 아니다. 근거 대조 선택지를 7개 사건에 연결했고, 구역별 보스 패턴과 36포즈를 준비 단계에서 캐시한다. 마지막 자료 대조 뒤 비서실장이 회장실 앞을 막으며, 저격수의 기존 신원 비공개 대화와 이후 회장 부재·노트·1분·하강 추격은 유지했다. 시계 창 24개는 전용 풀, 문자판은 단일 메시와 12개 시각 눈금으로 표시한다. 시계 벡터의 합성 방향과 광역 아래 안전 범위는 순수 규칙으로 검증했으나 실제 충돌·타이밍·보스 난도는 Unity에서 확인해야 한다. 2페이즈는 사용자 요청에 따라 아직 제작하지 않았다.
