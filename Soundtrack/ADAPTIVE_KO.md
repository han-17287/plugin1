# 게임에서 들리는 음악

| 장면 | 본편 재생 |
|---|---|
| 타이틀과 승강기 | 처음 열면 204 BPM의 〈봉인된 하늘 너머〉가 흐른다. 플레이 중 메뉴로 돌아오면 85 BPM의 〈점등〉, 층을 옮기는 동안은 78 BPM의 〈층과 층 사이〉가 나온다. |
| 첫 트럭 | 첫 추격 218 BPM → 지붕 위 대장전 212 → 재탑승 236. 짐칸 절단과 검거 컷신은 198 BPM 원샷이다. |
| 생활구 | 창고 경비전 208 BPM. 거대 슈트를 착용한 뒤에는 208 → 228 → 250으로 올라가며 마지막에 G단조에서 A단조로 조옮김한다. |
| 행정구 | 집행관 앞에서는 85 BPM으로 기다린다. 집행관전의 D단조 동기는 214 → 232로 이어지고, 3페이즈에서 E단조 252 BPM으로 올라간다. |
| 상층 거주구 | 궤도 봉쇄기 1차전은 페이즈 1·2에서 210 BPM, 3·4에서 230, 5·6에서 250이다. 외벽 재대결에서는 본편의 분노 진입과 남은 체력 25%가 같은 세 편곡의 전환점이다. |
| 최상층 | 저격수의 조준, 분신, 포탑, 레이저 충돌에 204 → 222 → 238 → 258 BPM을 배정했다. 비서실장전은 234 BPM 한 곡으로 끝까지 간다. |
| 회수 작전과 엔딩 | 〈회수 명령까지 60초〉는 120 BPM의 4/4 30마디다. 중간에 시작하면 남은 시간에 맞는 재생 위치로 들어간다. 하강 추격은 248 BPM이고 추락 장면과 크레디트에서 속도를 낮춘다. |

## 게임의 재생 방식

본편은 Unity 리소스 폴더에서 곡별 스테레오 완성 믹스를 불러온다. 배경곡이 바뀔 때 나가는 곡의 음량을 75ms에 걸쳐 내린다. 짧은 이동 경계를 오가는 동안은 약 0.28초간 다음 지역 선택이 유지될 때 전환한다. 전투 단계의 변화는 지역 이동 대기를 거치지 않는다. 사망·승진·퇴각·체크포인트 신호는 우선순위에 따라 한 번 재생한다. 같은 배경으로 돌아올 때는 보존한 재생 위치를 사용한다. 저체력일 때는 음악의 저역 통과 필터가 1.8kHz로 내려간다. 공격 전조와 게임 입력은 실시간으로 작동한다.

## DAW와 Unity에서 스템을 쓸 때

15개 전투곡의 `Stems/<곡 ID>/`에는 해당 곡에 등장하는 악기군이 들어 있다. 폴더 안의 Ogg를 모두 같은 0초에서 시작하면 킥과 베이스의 강세, 피아노에서 기타로 넘어가는 마지막 음의 위치를 따로 들을 수 있다. 전체 합주를 점검할 때는 완성 믹스를 솔로로 듣거나 해당 스템들만 합산한다. 스템별 크기 정규화는 앨범의 상대 밸런스를 바꾼다.

밴드룸 스템에는 악기 위치에서 좌우 마이크까지 돌아오는 짧은 벽 반사음이 이미 들어 있다. Unity에서는 같은 판의 스템들을 원래 음량과 패닝으로 먼저 들어 보자. 집행관 3페이즈 25마디에서 `drums`와 `bass`만 켜면 킥 뒤로 남는 베이스를, 여기에 `guitars`를 더하면 짧은 피크 소리 뒤에 붙는 앰프의 울림을 확인할 수 있다.

충전 게이지나 블레이드 상태에 맞춘 연출을 추가한다면 레벨만 조절하면 각 스템의 진행 위치가 유지된다. 예를 들어 블레이드를 던진 동안 기타를 줄여도 킥과 베이스가 함께 치는 강박은 남길 수 있다. 회수할 때는 잠금 소리를 즉시 울리고 선율을 다음 악구에서 복귀시키면 된다. `Accents/`의 북·현·피아노 음원은 별도로 편집에 쓸 수 있다.

집행관 전환용 `enforcer-to-2`는 214 BPM의 한 마디(약 1.1215초), `enforcer-to-3`는 232 BPM의 한 마디(약 1.0345초)다. 별도 소스를 동기화할 때는 `AudioSettings.dspTime` 기준으로 출발점을 잡고, 현재 BPM의 n번째 마디 위치를 `원점 + n × 240 / BPM`으로 계산한다. 샘플 번호는 마지막에 한 번 반올림한다.
