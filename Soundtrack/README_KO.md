# 도시의 악보 · PLUGIN 1회차 사운드트랙

**[메인 테마 〈봉인된 하늘 너머〉 MP3](Main-Theme.mp3)** · [보스와 엔딩 하이라이트 MP3](City-Score-Preview.mp3) · [50곡 전체 플레이리스트](City-Score.m3u8)

한 번씩 재생하면 **36:58**다. 기존 음악 열 곡에 마흔 곡을 새로 작곡했다. 기존 집행관 음악도 이번 판의 템포와 국악 편성에 맞췄다. 4/4 기준으로 집행관전은 160 → 175 → 190 BPM이며 마지막에 D단조에서 E단조로 올라간다. 최초 타이틀 〈점등〉과 이번 메인 테마는 별도 곡이다. 메인 테마의 기타 선율은 1회차 엔딩에 피아노로 돌아온다.

| 폴더·파일 | 쓰임 |
|---|---|
| `Mixes/` | 완성 믹스 50곡, 44.1kHz 스테레오 Ogg Vorbis. 41곡은 루프, 9곡은 한 번 재생한다. |
| `MIDI/` | 동일 이름의 50개 다중 트랙 악보. 템포, 악기 이름, 노트 및 루프 표식을 갖고 있다. |
| `Stems/` | 보스전 15곡을 악기군별로 나눈 동기화 음원. 같은 페이즈의 파일들은 시작점과 길이가 같다. |
| `Accents/` | 집행관 전환용 한 마디 피아노 2개, 제압 가야금, 폭발 회수 북, 돌진 도착 가야금. |
| `LoopParts/` | 〈교대 전류〉의 4마디 인트로와 44마디 반복부. 게임에서 전주를 한 번만 들려줄 때 사용한다. |

전체 재생은 ZIP을 풀고 VLC 등 상대경로를 지원하는 플레이어에서 `City-Score.m3u8`을 연다. 목록 아래 곡명 링크는 완성 음원을, 옆의 악보 링크는 같은 이름의 MIDI를 연다. 코어 보안 병기의 세 버전은 음악의 강도 변주이며, 저격수의 네 번째 곡은 레이저 충돌과 재수집에 맞춰 반복된다. 비서실장에게는 단 한 번의 전투 테마를 배정했다.

## 음색과 사용 범위

국악 파트는 악보의 음마다 농현, 술대의 짧은 타격, 갈대 리드와 대금의 숨, 활 마찰, 장구 두 면의 어택을 합성해 연주했다. 실연 녹음은 포함하지 않았다. 서양 악기 파트에는 FluidR3 GM 사운드폰트를 사용했고 전구와 코일 음색은 별도로 합성했다. 표준 MIDI에서는 재생하는 기기의 악기에 따라 음색이 달라진다. [FluidR3 크레딧](FluidR3-Credits.txt)

이 배포판의 음원은 Unity로 가져와 사용할 수 있다. 본편 `Main`의 음악 재생 코드는 별도다. 이전 열 곡 판의 믹스와 미리듣기는 [첫 사운드트랙 릴리스](https://github.com/han-17287/plugin1/tree/field-score-gugak-1/Soundtrack)에 있다.
