**v0.14.1 Unity 소스:** [다운로드 ZIP](https://github.com/han-17287/plugin1/raw/refs/heads/ancient-civilization-prototype/PLUGIN_v0.14.1_PolishedCombat_Districts_Unity_6000.6.7f1.zip)

- 세로 → 가로 → 사선의 전용 48프레임 블레이드 연격, 칼끝을 따르는 노란 잔광과 파란 수집 입자.
- 20개 수사 현장을 각각 폭432·3구간으로 확장. 구간별 적 최대2명, 높은 와이어 지름길과 안전 거점 저장/재도전.
- 보이는 베기 구간의 물체 파괴, 한 번의 공중 반동, 화면 밖 목표 안내와 다섯 층의 닫힌 실내 배경.
- 가운데 클릭 스윙, 굵은 연속 레이저, 주민25명과 한국어 순차 대사, 저격수4페이즈·비서실장 시계 최종보스.

ZIP의 `AncientCivilization` 폴더를 Unity **6000.6.7f1**에서 열고 `Assets/Scenes/Main.unity`를 실행하세요. 월드는 Play 중 생성됩니다. 실행 EXE가 아닌 소스 프로젝트입니다.

실제 Unity Play/빌드/FPS·완주 시간은 미검증입니다. 9시간 플레이·90%·완벽한 완성으로 표시하지 않습니다. 1회차의 저격수는 같은 처지만 확인하며 친구 공개는2회차, 비서실장은1페이즈 뒤 살아서 퇴장합니다.
