# 백 경위 — 블레이드 콘셉트 영상

[MP4 영상](Officer_Blade_Concept.mp4)

기존 고퀄리티 기계팔 참고 이미지의 백 경위를 바탕으로 제작한 **12초 콘셉트 애니매틱**입니다. 새로 생성한 다섯 장의 3D 스타일 이미지에 카메라 이동, 블레이드 발광, 베기 궤적, 불꽃·충격파, 카메라 흔들림과 효과음을 합성했습니다. 게임 플레이 녹화나 캐릭터 동작 전체를 연속 생성한 영상은 아닙니다.

## 장면

| 시간 | 구성 |
| --- | --- |
| 0.0–2.4초 | 수납된 고대 기계팔의 입자 코어 충전, 손목에서 노란 빛 전개 |
| 2.4–4.5초 | 카메라를 낮춰 길고 두꺼운 샤프심 전구 블레이드 공개 |
| 4.5–6.9초 | 낮은 시점에서 경위와 경비 로봇 대치 |
| 6.9–8.5초 | 옆 시점으로 전환, 블레이드 베기와 금속 불꽃 |
| 8.5–12.0초 | 어깨 너머 시점, 로봇 폭발·파편·충격파 |

얼굴을 가린 검은 제모, 검정·흰색 제복, 붉은 스카프, 청록색 고대 기계팔과 노랗게 빛나는 흑연 코어 블레이드를 유지했습니다. 적은 완전한 기계 로봇입니다.

## 파일

- `Officer_Blade_Concept.mp4`: H.264/AAC, 1920×1080, 30fps. 브라우저 재생을 위한 fast-start MP4.
- `Stills/shot01.png`–`shot05.png`: 영상에 사용한 생성 이미지 원본. 수정 없이 복사해 보관.
- `Preview/frame01.png`–`frame04.png`: 완성된 MP4에서 추출한 확인용 프레임.
- `source_manifest.json`: 참고 이미지·생성 이미지 경로, 원본 보존 확인용 SHA-256.
- `technical_metadata.json`: 완성된 MP4의 실제 FFprobe 검사 결과.
- `render_concept.py`: 이미지 원본을 변경하지 않고 카메라·영상 효과·소리를 합성하는 재현 스크립트.

효과음은 외부 음원 없이 사인파와 필터링한 잡음으로 직접 합성했습니다. 음악과 대사는 넣지 않았습니다.

## 다시 렌더링

Python 3, NumPy, SciPy, FFmpeg, FFprobe가 필요합니다. 저장소 루트에서 실행합니다.

```sh
python Video/render_concept.py
```

임시 카메라 영상·효과 레이어·WAV는 `work/video/`에 생성되며 최종 MP4와 확인 프레임은 이 폴더에 저장됩니다. 원본 참고 이미지: `ArtReferences/RelicArm_LongFilamentBlade_3D_Reference.png`.
